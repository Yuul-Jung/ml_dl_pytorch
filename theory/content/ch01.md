## 이 장의 목표

공부 시간으로 시험 점수를 맞히는 것처럼, 입력으로 ⟪b⟫연속적인 실수⟪/b⟫를 예측하는 문제를 Regression(리그레션, 회귀)이라고 합니다. 이 장은 가장 단순한 회귀 모델인 선형회귀로 머신러닝 학습의 뼈대 세 가지를 세웁니다.

1. **가설** `$H$` — 입력을 예측값으로 바꾸는 식
2. **손실함수** `$L$` — 예측이 정답에서 얼마나 벗어났는지 재는 식
3. **최적화** — 손실을 줄이는 방향으로 파라미터를 고치는 방법(경사하강법)

뒤에 나오는 분류·MLP·CNN도 이 세 가지 중 가설과 손실함수의 모양만 바뀔 뿐, 학습 절차는 같습니다.

⟪box:쉽게 이해하기⟫

점 몇 개를 가장 잘 지나는 직선 하나를 긋는 일입니다. "잘 지난다"를 숫자 하나(손실)로 바꾸면, 그 숫자가 가장 작아지는 기울기와 절편을 찾는 문제가 됩니다. 손실이라는 골짜기에서 가장 낮은 곳으로 조금씩 걸어 내려가는 방법이 경사하강법입니다.

⟪/box⟫

⟪box:꼭 기억할 점⟫

- 학습의 목적은 손실을 최소로 만드는 파라미터 `$W, b$`를 찾는 것입니다.
- 경사하강법은 "기울기 반대 방향으로, 학습률만큼" 이동하는 규칙을 반복합니다.
- 입력이 여러 개면 행렬곱 `$H(X)=XW+b$` 한 번으로 모든 샘플을 동시에 계산합니다.

⟪/box⟫

## 회귀 문제와 데이터

![슬라이드 2 · 시험 점수 예측 데이터](img/ch01_slide02.jpg)

공부 시간 `$x$`(hours)와 점수 `$y$`(score)처럼, 정답이 범위 안의 어떤 실수든 될 수 있으면 회귀입니다. 학습에 쓰는 데이터는 입력과 정답의 쌍 `$(x^{(i)}, y^{(i)})$`의 모음이고, 위첨자 `$(i)$`는 `$i$`번째 샘플이라는 뜻입니다.

![슬라이드 3 · 설명용 데이터 (1,1) (2,2) (3,3)](img/ch01_slide03.jpg)

원리를 손으로 따라가기 위해 이 장은 세 점 `$(1,1), (2,2), (3,3)$`을 계속 사용합니다. 정답 직선이 `$y=x$`라는 것을 미리 알고 있으므로, 계산 결과가 맞는지 바로 확인할 수 있습니다.

## 가설: 직선 하나로 예측하기

![슬라이드 4 · 선형 가설과 여러 후보 직선](img/ch01_slide04.jpg)

선형 가설은 입력에 가중치를 곱하고 편향을 더한 식입니다.

```math
H(x)=Wx+b
```

- `$W$` — Weight(웨이트, 가중치). 직선의 기울기이며 입력이 예측에 얼마나 영향을 주는지 정합니다.
- `$b$` — Bias(바이어스, 편향). 직선의 절편이며 입력이 0일 때의 기본값입니다.

`$W$`와 `$b$`를 바꾸면 그림처럼 서로 다른 직선(가설)이 생깁니다. 학습은 이 수많은 후보 가운데 데이터에 가장 잘 맞는 하나를 고르는 일입니다.

## 손실함수: 예측이 얼마나 틀렸는가

![슬라이드 6 · 예측과 정답 사이의 거리](img/ch01_slide06.jpg)

각 점에서 예측 `$H(x^{(i)})$`와 정답 `$y^{(i)}$`의 차이(빨간 세로선)가 오차입니다. 오차는 양수도 음수도 될 수 있어 그냥 더하면 서로 지워지므로, ⟪b⟫제곱해서 평균⟪/b⟫합니다. 이것이 MSE(Mean Squared Error, 평균 제곱 오차)입니다.

![슬라이드 8 · 세 점의 오차 제곱 평균](img/ch01_slide08.jpg)

```math
\mathrm{cost}(W,b)=\frac{1}{m}\sum_{i=1}^{m}\left(H(x^{(i)})-y^{(i)}\right)^2
```

`$m$`은 샘플 수입니다. 제곱을 쓰는 이유는 두 가지입니다. 부호와 상관없이 오차를 양수로 만들고, 큰 오차에 더 큰 벌점을 줍니다. 또 매끄럽게 미분되므로 다음 절의 경사하강법을 바로 적용할 수 있습니다.

![슬라이드 10 · 학습의 궁극적인 목적](img/ch01_slide10.jpg)

학습의 목적은 한 문장으로 정리됩니다. **손실 `$\mathrm{cost}(W,b)$`를 최소로 만드는 `$W$`와 `$b$`를 찾는다.**

## 손으로 계산하는 비용 곡선

원리를 단순하게 보기 위해 편향을 빼고 `$H(x)=Wx$`로 둡니다.

```math
\mathrm{cost}(W)=\frac{1}{m}\sum_{i=1}^{m}\left(Wx^{(i)}-y^{(i)}\right)^2
```

![슬라이드 17 · W=0일 때의 비용 계산](img/ch01_slide17.jpg)

| `$W$` | 계산 | 비용 |
|---|---|---|
| 1 | `$\frac{1}{3}[(1-1)^2+(2-2)^2+(3-3)^2]$` | 0 |
| 0 | `$\frac{1}{3}[(0-1)^2+(0-2)^2+(0-3)^2]=\frac{14}{3}$` | 약 4.67 |
| 2 | `$\frac{1}{3}[(2-1)^2+(4-2)^2+(6-3)^2]=\frac{14}{3}$` | 약 4.67 |

![슬라이드 20 · W에 따른 비용 곡선](img/ch01_slide20.jpg)

여러 `$W$`에 대해 비용을 그리면 `$W=1$`에서 바닥이 0인 아래로 볼록한 포물선이 나옵니다. 실제로 식을 정리하면 `$\mathrm{cost}(W)=\frac{14}{3}(W-1)^2$`입니다. 그래프에서 `$W=-3$`과 `$W=5$`의 비용이 모두 약 74.7로 같은 것도 이 식으로 설명됩니다.

## 경사하강법

![슬라이드 21 · 경사하강법의 역할](img/ch01_slide21.jpg)

Gradient Descent(그레이디언트 디센트, 경사하강법)는 손실을 줄이는 범용 최소화 알고리즘입니다. 선형회귀뿐 아니라 뒤에 나올 모든 신경망이 같은 방식으로 학습합니다.

![슬라이드 23 · 경사하강법의 동작 순서](img/ch01_slide23.jpg)

```flow
초기값에서 시작 (예: `W=0, b=0` 또는 임의의 값)
현재 위치의 기울기 계산
기울기 반대 방향으로 조금 이동해 `W, b` 갱신
손실이 더 줄지 않을 때까지 반복
```

기울기(미분값)가 양수면 오른쪽이 오르막이므로 왼쪽으로, 음수면 오른쪽으로 이동합니다. 이것을 식 하나로 쓰면 다음과 같습니다.

```math
W\mathrel{:=} W-\alpha\frac{\partial}{\partial W}\mathrm{cost}(W)
```

`$\alpha$`(알파)는 Learning Rate(러닝 레이트, 학습률)로, 한 번에 얼마나 이동할지 정합니다.

## 갱신식 유도

![슬라이드 27 · 미분을 적용한 갱신식](img/ch01_slide27.jpg)

강의는 미분을 깔끔하게 하려고 비용 앞의 `$\frac{1}{m}$`을 `$\frac{1}{2m}$`으로 바꿉니다. 상수배는 최솟값의 위치를 바꾸지 않으므로 최적의 `$W$`는 그대로입니다.

```math
\begin{array}{rcl}
W&\mathrel{:=}&W-\alpha\frac{\partial}{\partial W}\frac{1}{2m}\sum_{i=1}^{m}\left(Wx^{(i)}-y^{(i)}\right)^2\\
&=&W-\alpha\frac{1}{2m}\sum_{i=1}^{m}2\left(Wx^{(i)}-y^{(i)}\right)x^{(i)}\\
&=&W-\alpha\frac{1}{m}\sum_{i=1}^{m}\left(Wx^{(i)}-y^{(i)}\right)x^{(i)}
\end{array}
```

마지막 식은 "오차 × 입력"의 평균만큼 `$W$`를 고친다는 뜻입니다. 오차가 크고 그 오차에 기여한 입력이 클수록 크게 고칩니다.

⟪box:고급 해설 · 학습률의 안전 범위⟫

이 예제에서 `$\frac{1}{m}$` 평균 비용의 기울기는 `$\frac{2}{m}\sum(Wx-y)x=\frac{28}{3}(W-1)$`입니다. 따라서 한 번 갱신하면 `$W-1$`이 `$\left(1-\frac{28}{3}\alpha\right)$`배가 됩니다. 이 배율의 절댓값이 1보다 작아야 수렴하므로 `$0<\alpha<\frac{3}{14}\approx0.214$`입니다. `$\alpha=0.1$`이면 몇 번 만에 수렴하고, `$\alpha=0.25$`이면 매번 반대편으로 더 크게 튀어 발산합니다. 아래 코드 결과가 이것을 그대로 보여 줍니다. 이 범위는 비용 곡선의 곡률(2차 미분)이 클수록 좁아집니다.

⟪/box⟫

## 비용 지형과 시작점

![슬라이드 29 · 두 가지 비용 지형](img/ch01_slide29.jpg)

파라미터가 둘 이상이면 비용은 곡선이 아니라 곡면입니다. 왼쪽처럼 골짜기가 여러 개인 곡면에서는 시작점에 따라 서로 다른 Local Minimum(로컬 미니멈, 지역 최솟값)에 도착할 수 있습니다.

선형회귀의 MSE는 오른쪽처럼 ⟪b⟫그릇 모양(볼록 함수)⟪/b⟫입니다. 바닥이 하나뿐이므로 학습률만 적당하면 어디서 시작해도 같은 최솟값(전역 최솟값)에 도착합니다. 시작점 문제는 은닉층이 있는 신경망(3장 이후)에서 실제로 중요해집니다.

## 여러 입력의 선형회귀

![슬라이드 32 · 퀴즈 두 번과 중간고사로 기말 점수 예측](img/ch01_slide32.jpg)

입력이 여러 개면 입력마다 가중치를 하나씩 둡니다.

```math
H(x_1,x_2,x_3)=w_1x_1+w_2x_2+w_3x_3+b
```

![슬라이드 35 · 입력 n개로 일반화](img/ch01_slide35.jpg)

```math
H(x_1,\dots,x_n)=w_1x_1+w_2x_2+\cdots+w_nx_n+b
```

손실함수는 예측식만 바뀌고 형태는 같습니다.

```math
\mathrm{cost}(W,b)=\frac{1}{m}\sum_{i=1}^{m}\left(H(x_1^{(i)},x_2^{(i)},x_3^{(i)})-y^{(i)}\right)^2
```

## 행렬로 가설 표현하기

![슬라이드 37 · 행렬곱의 계산 방법](img/ch01_slide37.jpg)

행렬곱은 앞 행렬의 ⟪b⟫행⟪/b⟫과 뒤 행렬의 ⟪b⟫열⟪/b⟫을 원소별로 곱해 더합니다(내적, Dot Product). `$[1,2,3]\cdot[7,9,11]=7+18+33=58$`처럼 계산합니다.

![슬라이드 38 · 입력 벡터와 가중치 벡터의 곱](img/ch01_slide38.jpg)

`$w_1x_1+w_2x_2+w_3x_3$`는 행벡터 `$(x_1,x_2,x_3)$`와 열벡터 `$(w_1,w_2,w_3)^T$`의 곱과 같습니다.

![슬라이드 41 · 샘플 5개를 한 번에 계산](img/ch01_slide41.jpg)

샘플을 행으로 쌓은 행렬 `$X$`를 쓰면 모든 샘플의 예측을 한 번에 구합니다.

```math
\underbrace{X}_{[5,3]}\;\underbrace{W}_{[3,1]}=\underbrace{H(X)}_{[5,1]}
```

![슬라이드 43 · 샘플 수가 n개일 때](img/ch01_slide43.jpg)

샘플 수는 몇 개든 상관없으므로 `$[n,3]\cdot[3,1]=[n,1]$`입니다. 행렬곱이 성립하려면 **앞 행렬의 열 수와 뒤 행렬의 행 수가 같아야** 하고, 결과는 `$[\text{앞의 행 수},\ \text{뒤의 열 수}]$`가 됩니다.

![슬라이드 44 · 출력이 2개일 때 W의 모양은?](img/ch01_slide44.jpg)

슬라이드의 물음표 `$[?,?]$`의 답은 `$[3,2]$`입니다. 입력 특성 3개를 받아 출력 2개를 내야 하므로 `$[n,3]\cdot[3,2]=[n,2]$`입니다. 일반적으로 ⟪b⟫W의 모양은 [입력 개수, 출력 개수]⟪/b⟫입니다.

## 이론의 Wx와 구현의 XW

![슬라이드 45 · WX vs XW](img/ch01_slide45.jpg)

강의나 교과서는 샘플 하나를 열벡터 `$x$`로 두고 `$H(x)=Wx+b$`라고 씁니다. 구현에서는 샘플을 행으로 쌓은 `$X$`를 쓰므로 `$H(X)=XW$`가 자연스럽습니다. 두 식은 전치(transpose) 관계일 뿐 같은 계산입니다.

PyTorch의 `nn.Linear(in_features, out_features)`는 가중치를 `[out, in]` 모양으로 저장하고 `$XW^T+b$`를 계산합니다. 그래서 `nn.Linear(3, 1).weight.shape`는 `[1, 3]`입니다. 모양이 헷갈릴 때는 "입력 특성 수가 마지막 축에서 맞물린다"만 확인하면 됩니다.

## 코드로 확인하기

강의 슬라이드의 수치를 NumPy로 다시 계산해 이론과 맞는지 확인합니다.

코드 박스: theory/code/ch01_linear_regression.py 핵심 발췌 · 실행 통과(Python 3.13, NumPy 2.5)

```python
import numpy as np

x = np.array([1.0, 2.0, 3.0])
y = np.array([1.0, 2.0, 3.0])


def cost(w):
    # 평균 제곱 오차(MSE): 오차를 제곱해 평균한다
    return np.mean((w * x - y) ** 2)


for w in [0.0, 1.0, 2.0, -3.0, 5.0]:
    print(f"W={w:+.1f}  cost={cost(w):.4f}")

# 경사하강법: cost(W) = (1/m)Σ(Wx-y)² 의 기울기는 (2/m)Σ(Wx-y)x
w, lr = 5.0, 0.1
for step in range(1, 11):
    grad = 2 * np.mean((w * x - y) * x)
    w = w - lr * grad
    if step in (1, 2, 3, 5, 10):
        print(f"step {step:2d}  W={w:.4f}  cost={cost(w):.6f}")

# 학습률이 너무 크면 발산한다
for lr in [0.01, 0.1, 0.25]:
    w = 5.0
    for _ in range(5):
        w -= lr * 2 * np.mean((w * x - y) * x)
    print(f"lr={lr:<5} W={w:.4f}")
```

실행 결과: 이번 정리에서 직접 실행

```text
W=+0.0  cost=4.6667
W=+1.0  cost=0.0000
W=+2.0  cost=4.6667
W=-3.0  cost=74.6667
W=+5.0  cost=74.6667
step  1  W=1.2667  cost=0.331852
step  2  W=1.0178  cost=0.001475
step  3  W=1.0012  cost=0.000007
step  5  W=1.0000  cost=0.000000
step 10  W=1.0000  cost=0.000000
lr=0.01  W=3.4507
lr=0.1   W=1.0000
lr=0.25  W=-15.8560
```

⟪box:코드 풀이⟫

- `cost(w)` — 슬라이드의 `$\frac{1}{m}\sum(Wx^{(i)}-y^{(i)})^2$`를 그대로 옮겼습니다. `np.mean`이 `$\frac{1}{m}\sum$`입니다.
- `grad = 2 * np.mean((w * x - y) * x)` — 평균 비용을 미분한 값입니다. 강의의 `$\frac{1}{2m}$` 버전에서는 앞의 2가 사라지고, 그만큼 학습률이 절반인 것과 같습니다.
- `w = w - lr * grad` — 경사하강법 갱신식 `$W\mathrel{:=} W-\alpha\,\partial\mathrm{cost}/\partial W$`입니다.
- 결과 해석 — `$W=5$`에서 출발해 두세 번 만에 정답 1에 다가갑니다. `lr=0.01`은 너무 느리고, `lr=0.25`는 안전 범위(약 0.214)를 넘어 발산합니다.

⟪/box⟫

다변수 데이터는 행렬곱 한 번으로 계산합니다.

코드 박스: theory/code/ch01_linear_regression.py 핵심 발췌 (이어서) · 실행 통과(Python 3.13, NumPy 2.5)

```python
X = np.array([[73, 80, 75],
              [93, 88, 93],
              [89, 91, 90],
              [96, 98, 100],
              [73, 66, 70]], dtype=float)
Y = np.array([[152], [185], [180], [196], [142]], dtype=float)
W = np.array([[1.0], [0.5], [0.5]])   # 설명용 임의 가중치
H = X @ W + 0.0
print("X shape", X.shape, "W shape", W.shape, "H shape", H.shape)

# 정답에 가장 가까운 W, b: 최소제곱해로 확인
X1 = np.hstack([X, np.ones((5, 1))])          # 편향 b를 위한 1 열 추가
theta, *_ = np.linalg.lstsq(X1, Y, rcond=None)
pred = X1 @ theta
print("W =", np.round(theta[:3].ravel(), 4), " b =", round(float(theta[3, 0]), 4))
print("예측 =", np.round(pred.ravel(), 2))
print("MSE =", round(float(np.mean((pred - Y) ** 2)), 4))
```

실행 결과: 이번 정리에서 직접 실행

```text
X shape (5, 3) W shape (3, 1) H shape (5, 1)
W = [0.7955 0.4084 0.7546]  b = 4.4021
예측 = [151.74 184.5  180.27 196.25 142.25]
MSE = 0.1043
```

⟪box:코드 풀이⟫

- `X @ W` — `@`는 행렬곱 연산자입니다. `[5,3] @ [3,1]`이 `[5,1]`이 되어 샘플 5개의 예측이 한 번에 나옵니다.
- `np.hstack([X, np.ones((5, 1))])` — 모든 행에 1을 붙이면 편향 `$b$`를 가중치 하나처럼 다룰 수 있습니다.
- `np.linalg.lstsq` — MSE를 최소로 만드는 해를 공식으로 바로 구하는 최소제곱법입니다. 경사하강법이 반복해서 찾아가는 목적지를 미리 확인하는 용도입니다.
- 결과 해석 — 세 시험 점수로 기말 점수를 거의 정확히 맞힙니다(MSE 0.10). 다만 샘플 5개에 파라미터 4개이므로 새 데이터에도 잘 맞는다는 보장은 없습니다. 이 문제는 3장의 검증 데이터에서 다룹니다.

⟪/box⟫

## PyTorch로 옮기기

같은 학습을 PyTorch로 쓰면 다음 형태가 됩니다. 기울기 계산은 `loss.backward()`가 자동으로 하고, 갱신은 `optimizer.step()`이 합니다.

코드 박스: PyTorch 예시 · Python · 미검증(이 환경에 PyTorch 미설치)

```python
import torch
import torch.nn as nn

x = torch.tensor([[1.0], [2.0], [3.0]])   # [N, 입력 1개]
y = torch.tensor([[1.0], [2.0], [3.0]])   # [N, 출력 1개]

model = nn.Linear(1, 1)                   # H(x) = Wx + b
loss_fn = nn.MSELoss()                    # 평균 제곱 오차
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

for epoch in range(200):
    optimizer.zero_grad()                 # 이전 기울기 지우기
    loss = loss_fn(model(x), y)           # 순전파와 손실
    loss.backward()                       # 역전파: dL/dW, dL/db 계산
    optimizer.step()                      # W, b 갱신

print(model.weight.item(), model.bias.item())
```

⟪box:코드 풀이⟫

- `nn.Linear(1, 1)` — 입력 1개, 출력 1개인 선형 가설입니다. 가중치와 편향을 무작위 값으로 만들어 둡니다.
- `nn.MSELoss()` — `$\frac{1}{m}\sum(H-y)^2$`입니다. 강의의 `$\frac{1}{2m}$`이 아니라 `$\frac{1}{m}$` 평균을 씁니다.
- `optimizer.zero_grad()` — PyTorch는 기울기를 누적하므로 매 반복 시작에 0으로 지웁니다.
- 기대 결과 — `$W\approx1, b\approx0$`에 가까워집니다. 초기값이 무작위이므로 소수점 아래 값은 실행마다 조금 다릅니다.

⟪/box⟫

## 스스로 점검

1. 오차를 제곱하지 않고 그냥 더하면 어떤 문제가 생기나요? → 양수 오차와 음수 오차가 서로 지워져, 크게 틀려도 손실이 0이 될 수 있습니다.
2. 기울기가 음수일 때 `$W$`는 어느 방향으로 움직이나요? → `$W\mathrel{:=} W-\alpha\cdot(\text{음수})$`이므로 커지는 방향(오른쪽)입니다.
3. 입력 특성 4개, 출력 1개인 선형회귀에서 `$W$`의 모양은? → `$[4,1]$`이고, PyTorch `nn.Linear(4, 1).weight`는 `[1, 4]`입니다.
4. 학습률을 10배로 올렸더니 손실이 점점 커졌습니다. 이유는? → 한 번의 이동이 골짜기 폭보다 커서 반대편으로 넘어가며 발산합니다.
