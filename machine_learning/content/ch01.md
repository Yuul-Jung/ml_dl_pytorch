## 배경 개념

머신러닝 모델은 입력·가중치·출력을 모두 **다차원 배열**로 다룹니다. NumPy의 `ndarray`와 PyTorch의 `Tensor`는 모양(`shape`)·자료형(`dtype`)·인덱싱 규칙이 거의 같으므로, 같은 예제로 두 도구를 나란히 비교하며 시작합니다.

Tensor에는 NumPy에 없는 두 가지 능력이 있습니다. 계산을 GPU로 옮기는 **장치 이동**(`device`)과, 계산 과정을 기록해 기울기를 자동으로 구하는 **자동 미분**(Autograd)입니다. 이 두 기능이 다음 장의 경사하강법 학습을 가능하게 합니다.

### 4. Shape, 인덱싱, Reshape

- `shape`(셰이프, 데이터 모양)의 `(2, 3)`은 **2행 3열**을 의미합니다.
- 인덱스는 `0`부터 시작합니다.
- `reshape`는 데이터의 값과 개수는 유지하고 모양만 바꿉니다.
- 원소가 6개이므로 `(3, 2)`, `(1, 6)`, `(6, 1)` 등으로 변경할 수 있습니다.

코드 박스: ch01_1_numpy_torch.ipynb · 셀 4 · 미검증

```python
# 2행 3열 데이터
data = [[1, 2, 3],
        [4, 5, 6]]

np_matrix = np.array(data)
torch_matrix = torch.tensor(data)

print("NumPy shape :", np_matrix.shape)
print("PyTorch shape:", torch_matrix.shape)

# 첫 번째 행, 두 번째 열의 값
print("NumPy 값 :", np_matrix[0, 1])
print("PyTorch 값:", torch_matrix[0, 1])

# 2행 3열을 3행 2열로 변경
print("\nNumPy reshape")
print(np_matrix.reshape(3, 2))

print("\nPyTorch reshape")
print(torch_matrix.reshape(3, 2))
```

⟪box:코드 풀이⟫

2행 3열 데이터를 만들어 모양(shape), 인덱싱, 모양 바꾸기를 확인합니다.
- `.shape` — `(행, 열)` 크기. PyTorch는 `torch.Size([2, 3])`로 표시합니다.
- `[0, 1]` — 0번째 행, 1번째 열(번호는 0부터 시작).
- `reshape(3, 2)` — 원소 6개는 그대로 두고 3행 2열로 다시 배치합니다.

⟪/box⟫

### 5. 원소별 곱셈과 행렬곱 구분

- `*` : Element-wise multiplication(원소별 곱셈)
- `@` : Matrix multiplication(행렬곱)

두 연산은 결과가 다르므로 반드시 구분해야 합니다.

코드 박스: ch01_1_numpy_torch.ipynb · 셀 5 · 미검증

```python
a_np = np.array([[1, 2],
                 [3, 4]])

b_np = np.array([[5, 6],
                 [7, 8]])

a_torch = torch.tensor(a_np)
b_torch = torch.tensor(b_np)

# 원소별 곱셈: 같은 위치의 원소끼리 곱합니다.
print("NumPy 원소별 곱셈")
print(a_np * b_np)

print("\nPyTorch 원소별 곱셈")
print(a_torch * b_torch)

# 행렬곱: 행과 열을 곱하여 새로운 행렬을 만듭니다.
print("\nNumPy 행렬곱")
print(a_np @ b_np)

print("\nPyTorch 행렬곱")
print(a_torch @ b_torch)
```

⟪box:코드 풀이⟫

같은 위치끼리 곱하는 **원소별 곱셈**(`*`)과 **행렬곱**(`@`)의 차이를 비교합니다.
- `a * b` — 결과의 각 원소는 `a[i, j] × b[i, j]`입니다.
- `a @ b` — 결과의 각 원소는 `a`의 행과 `b`의 열을 곱해 더한 값입니다. 신경망의 `Linear` 층이 이 연산을 씁니다.

⟪/box⟫

### 6. NumPy와 PyTorch 사이의 변환

- `torch.tensor(np_data)`는 NumPy 배열의 값을 이용해 새 텐서를 만듭니다.
- CPU 텐서는 `.numpy()`로 NumPy 배열로 변환할 수 있습니다.
- `.copy()`를 붙이면 원본 텐서와 독립된 NumPy 배열을 만들 수 있어 초보 실습에서 혼선을 줄일 수 있습니다.

코드 박스: ch01_1_numpy_torch.ipynb · 셀 6 · 미검증

```python
# NumPy 배열 → PyTorch 텐서
np_data = np.array([10, 20, 30], dtype=np.float32)
tensor_data = torch.tensor(np_data)

# PyTorch 텐서 → NumPy 배열
back_to_numpy = tensor_data.numpy().copy()

print("원본 NumPy :", np_data)
print("PyTorch 변환:", tensor_data)
print("다시 NumPy :", back_to_numpy)
```

⟪box:코드 풀이⟫

NumPy 배열과 Tensor를 서로 변환합니다.
- `torch.tensor(np_data)` — 배열 내용을 복사해 새 Tensor를 만듭니다.
- `.numpy().copy()` — Tensor를 NumPy 배열로 바꾼 뒤 복사본을 만들어, 한쪽을 바꿔도 다른 쪽이 변하지 않게 합니다.

⟪/box⟫

### 7. PyTorch의 자동 미분

함수는 다음과 같습니다.


```math
y = x^2 + 2x
```


미분 결과는 다음과 같습니다.


```math
\frac{dy}{dx} = 2x + 2
```


`x = 3`을 대입하면 기울기는 `8`입니다. PyTorch는 `backward()`를 실행하여 이 값을 자동으로 계산합니다.

> **자동 미분은 신경망 학습에 필요한 기울기를 자동으로 계산합니다.**

코드 박스: ch01_1_numpy_torch.ipynb · 셀 7 · 미검증

```python
# x에 대한 계산 과정을 추적하도록 설정합니다.
x = torch.tensor(3.0, requires_grad=True)

# y = x² + 2x
y = x**2 + 2*x

# y를 x로 미분합니다. dy/dx
y.backward()

print("x =", x.item())
print("y =", y.item())
print("dy/dx =", x.grad.item())
```

⟪box:코드 풀이⟫

`y = x² + 2x`를 PyTorch가 자동으로 미분하게 합니다.
- `requires_grad=True` — 이 Tensor로 하는 계산 과정을 기록하라는 표시입니다.
- `y.backward()` — 기록된 계산을 거꾸로 따라가며 `dy/dx`를 계산합니다.
- `x.grad` — 계산된 기울기. `x = 3`이면 `2·3 + 2 = 8`입니다.

⟪/box⟫

### 8. 미니 실습: 센서 데이터 정규화

코드 박스: ch01_1_numpy_torch.ipynb · 셀 8 · 미검증

```python
# 센서 측정값을 0~1 범위로 변환합니다.
sensor_values = [20.0, 30.0, 40.0, 50.0]

# NumPy
np_sensor = np.array(sensor_values, dtype=np.float32)
np_normalized = (np_sensor - np_sensor.min()) / (np_sensor.max() - np_sensor.min())

# PyTorch
torch_sensor = torch.tensor(sensor_values, dtype=torch.float32)
torch_normalized = (
    (torch_sensor - torch_sensor.min())
    / (torch_sensor.max() - torch_sensor.min())
)

print("NumPy 결과 :", np_normalized)
print("PyTorch 결과:", torch_normalized)

# 두 결과가 같은지 확인합니다.
print("결과 일치:", np.allclose(np_normalized, torch_normalized.numpy()))
```

⟪box:코드 풀이⟫

센서 값을 0~1 범위로 바꾸는 Min-Max 정규화를 두 라이브러리로 계산하고 결과가 같은지 확인합니다.
- `(값 − 최솟값) / (최댓값 − 최솟값)` — 가장 작은 값은 0, 가장 큰 값은 1이 됩니다.
- `np.allclose()` — 두 배열이 오차 범위 안에서 같은지 `True`/`False`로 알려 줍니다.

⟪/box⟫

### 2. Python 리스트와 NumPy 배열 비교

Python 리스트에서 `+`는 두 리스트를 이어 붙입니다.

# Python 리스트
list_a = [1, 2, 3]

array_a = np.array([1, 2, 3])

- 배열 `+` — 같은 위치의 원소끼리 더합니다(`[11, 22, 33]`). 수치 계산에 배열을 쓰는 이유입니다.

### 3. Scalar·Vector·Matrix 구분

| 구분 | 의미 | 예시 shape |
|---|---|---|
| Scalar(스칼라) | 값 1개 | `()` |
| Vector(벡터) | 1차원 데이터 | `(3,)` |
| Matrix(매트릭스) | 2차원 데이터 | `(2, 2)` |
| Tensor(텐서) | 3차원 이상의 데이터까지 포함 | `(2, 3, 4)` |

- `ndim`은 차원의 개수입니다.
- `shape`는 각 차원에 몇 개의 값이 있는지를 나타냅니다.

코드 박스: ch01_2_numpy_and_tensor.ipynb · 셀 3 · 미검증

```python
scalar = np.array(7)
vector = np.array([1, 2, 3])
matrix = np.array([[1, 2], [3, 4]])

print("Scalar → ndim:", scalar.ndim, ", shape:", scalar.shape)
print("Vector → ndim:", vector.ndim, ", shape:", vector.shape)
print("Matrix → ndim:", matrix.ndim, ", shape:", matrix.shape)
```

⟪box:코드 풀이⟫

차원 수(`ndim`)와 모양(`shape`)으로 스칼라·벡터·행렬을 구분합니다.
- 스칼라는 `ndim 0`, `shape ()` / 벡터는 `ndim 1` / 행렬은 `ndim 2`입니다.

⟪/box⟫

### 2. Tensor 생성 함수

ones_tensor = torch.ones(2, 3)
range_tensor = torch.arange(0, 6).reshape(2, 3)
random_tensor = torch.rand(2, 3)

print("zeros:")

print()
print("ones:")
print(ones_tensor)

print()
print("arange + reshape:")
print(range_tensor)

print()
print("rand:")
print(random_tensor)

- `zeros`, `ones` — 0 또는 1로 채운 Tensor / `arange(0, 6)` — 0~5 연속 정수 / `rand` — 0~1 균등 난수.

### 3. NumPy 배열과 Tensor의 메모리 공유

`torch.from_numpy()`로 만든 Tensor는 원본 NumPy 배열과 메모리를 공유할 수 있습니다.

따라서 NumPy 배열의 값을 바꾸면 Tensor의 값도 함께 바뀔 수 있습니다.

독립된 복사본이 필요할 때는 `clone()`을 사용합니다.

코드 박스: ch01_3_tensor_operations.ipynb · 셀 3 · 미검증

```python
numpy_data = np.array([[10, 20], [30, 40]], dtype=np.float32)

shared_tensor = torch.from_numpy(numpy_data)
copied_tensor = shared_tensor.clone()

# NumPy 배열의 첫 번째 값을 변경합니다.
numpy_data[0, 0] = 99

print("변경된 NumPy 배열:")
print(numpy_data)

print()
print("메모리를 공유하는 Tensor:")
print(shared_tensor)

print()
print("미리 복사한 독립 Tensor:")
print(copied_tensor)
```

⟪box:코드 풀이⟫

`from_numpy()`로 만든 Tensor는 원본 배열과 메모리를 공유한다는 점을 확인합니다.
- 배열의 값을 99로 바꾸면 `shared_tensor`도 함께 바뀝니다.
- `.clone()`으로 미리 복사한 `copied_tensor`는 영향을 받지 않습니다.

⟪/box⟫

### 4. CPU와 GPU 장치 선택

### 5. Tensor 모양 바꾸기

`reshape()`는 원소의 총개수를 유지하면서 Tensor의 모양을 바꿉니다.


```math
2 \times 3 = 3 \times 2 = 6
```


따라서 원소가 6개인 Tensor는 `(2, 3)`, `(3, 2)`, `(1, 6)` 등의 모양으로 변경할 수 있습니다.

`flatten()`은 여러 차원의 Tensor를 1차원으로 펼칩니다.

코드 박스: ch01_3_tensor_operations.ipynb · 셀 5 · 미검증

```python
tensor_a = torch.arange(1, 7).reshape(2, 3)

print("원래 Tensor:")
print(tensor_a)
print("shape:", tensor_a.shape)

print()
print("reshape(3, 2):")
print(tensor_a.reshape(3, 2))

print()
print("flatten():")
print(tensor_a.flatten())
```

⟪box:코드 풀이⟫

원소 수를 유지한 채 모양을 바꿉니다.
- `reshape(3, 2)` — 2×3을 3×2로 / `flatten()` — 모든 원소를 1차원으로 펼칩니다. 이미지를 MLP에 넣을 때 쓰는 연산입니다.

⟪/box⟫

### 6. `torch.cat()`으로 연결하기

`torch.cat()`은 **기존 차원을 따라** Tensor를 연결합니다.

두 Tensor의 shape가 모두 `(2, 3)`일 때:

- `dim=0`: 첫 번째 차원의 크기가 증가 → `(4, 3)`
- `dim=1`: 두 번째 차원의 크기가 증가 → `(2, 6)`

> `dim`은 단순히 행·열 이름보다 **어느 차원의 크기를 늘리는가**로 이해하는 것이 좋습니다.

코드 박스: ch01_3_tensor_operations.ipynb · 셀 6 · 미검증

```python
tensor_b = torch.tensor(
    [[10, 20, 30],
     [40, 50, 60]]
)

cat_dim0 = torch.cat([tensor_a, tensor_b], dim=0)
cat_dim1 = torch.cat([tensor_a, tensor_b], dim=1)

print("cat dim=0:")
print(cat_dim0)
print("shape:", cat_dim0.shape)

print()
print("cat dim=1:")
print(cat_dim1)
print("shape:", cat_dim1.shape)
```

⟪box:코드 풀이⟫

두 Tensor를 기존 차원 방향으로 이어 붙입니다.
- `dim=0` — 아래로 이어 붙여 행이 늘어납니다(2×3 + 2×3 → 4×3).
- `dim=1` — 옆으로 이어 붙여 열이 늘어납니다(→ 2×6).

⟪/box⟫

### 7. `torch.stack()`으로 쌓기

`torch.stack()`은 **새로운 차원을 추가하여** Tensor를 쌓습니다.

두 개의 `(2, 3)` Tensor를 `dim=0`으로 쌓으면 결과 shape는 `(2, 2, 3)`이 됩니다.

- 첫 번째 `2`: Tensor 묶음의 개수
- 두 번째 `2`: 각 Tensor의 행 개수
- 마지막 `3`: 각 Tensor의 열 개수

코드 박스: ch01_3_tensor_operations.ipynb · 셀 7 · 미검증

```python
stack_dim0 = torch.stack([tensor_a, tensor_b], dim=0)

print("stack dim=0:")
print(stack_dim0)
print("shape:", stack_dim0.shape)
```

⟪box:코드 풀이⟫

두 Tensor를 **새 차원**을 만들어 쌓습니다.
- `torch.stack(..., dim=0)` — 2×3 두 개가 `[2, 2, 3]`이 됩니다. 맨 앞 차원이 '몇 번째 Tensor인가'를 나타냅니다.

⟪/box⟫

### 8. `cat`과 `stack` 비교

| 함수 | 핵심 동작 | 예시 결과 |
|---|---|---|
| `torch.cat()` | 기존 차원을 따라 연결 | `(2, 3)` 두 개 → `(4, 3)` |
| `torch.stack()` | 새로운 차원을 만들어 쌓기 | `(2, 3)` 두 개 → `(2, 2, 3)` |

------------------------------------------------------------------------

> **`cat`은 Tensor를 연결하고, `stack`은 새로운 차원으로 묶습니다.**

### 9. 미니 실습: 센서 데이터 묶음 합치기

두 번에 나누어 측정한 온도·진동 데이터를 하나로 결합합니다.

각 행은 하나의 측정값이며, 각 열은 다음 의미를 가집니다.

- 첫 번째 열: 온도
- 두 번째 열: 진동

코드 박스: ch01_3_tensor_operations.ipynb · 셀 8 · 미검증

```python
# 첫 번째 측정 묶음
batch_1 = torch.tensor(
    [[22.0, 0.10],
     [25.0, 0.15]]
)

# 두 번째 측정 묶음
batch_2 = torch.tensor(
    [[31.0, 0.45],
     [36.0, 0.90]]
)

# 모든 측정값을 하나의 표로 연결합니다.
all_sensor_data = torch.cat([batch_1, batch_2], dim=0)

# 두 측정 묶음을 구분한 상태로 쌓습니다.
grouped_sensor_data = torch.stack([batch_1, batch_2], dim=0)

print("하나로 연결한 센서 데이터:")
print(all_sensor_data)
print("shape:", all_sensor_data.shape)

print()
print("측정 묶음별로 쌓은 센서 데이터:")
print(grouped_sensor_data)
print("shape:", grouped_sensor_data.shape)
```

⟪box:코드 풀이⟫

같은 두 측정 묶음을 `cat`과 `stack`으로 각각 합쳐 결과 모양을 비교합니다.
- `cat` 결과 `[4, 2]` — 묶음 구분 없이 측정 4건이 한 표가 됩니다.
- `stack` 결과 `[2, 2, 2]` — 묶음 단위가 유지됩니다. 여러 데이터를 배치로 묶을 때 쓰는 방식입니다.

⟪/box⟫

### 11. 핵심 정리

- `zeros`, `ones`, `arange`, `rand`로 Tensor를 쉽게 생성할 수 있습니다.
- `.to(device)`는 Tensor를 CPU 또는 GPU로 이동합니다.
- `torch.stack()`은 새로운 차원을 추가하여 쌓습니다.
