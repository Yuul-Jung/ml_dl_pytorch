## 배경 개념

Classification(클래시피케이션, 분류)은 정답이 실수가 아니라 **클래스**인 문제입니다. 이진분류는 Logit(로짓) 1개를 내보내고 `BCEWithLogitsLoss()`로 학습한 뒤, 추론할 때 Sigmoid(시그모이드)로 확률을 만들어 0.5 기준으로 0/1을 정합니다.

세 개 이상 클래스 중 하나를 고르는 다중분류는 클래스 수만큼 Logit을 내보내고 `CrossEntropyLoss()`로 학습합니다. 이 손실은 내부에서 Softmax를 계산하므로 모델 끝에 Softmax를 넣지 않고, 정답은 One-hot이 아닌 클래스 번호(`long`)를 씁니다.

마지막 노트북은 훈련·검증·테스트 분리, 표준화, 학습률, 과적합, L2 규제를 실험으로 비교해 **학습을 잘 시키는 방법**을 정리합니다.

### 2. 로짓과 확률

선형 계층은 먼저 하나의 로짓을 계산합니다.


```text
z=w_1x_1+w_2x_2+b
```


- **`(z)`**: Logit(로짓, 확률로 바꾸기 전 점수)

- 로짓의 범위: `(-\infty)`부터 `(+\infty)`

- 로짓은 아직 확률이 아닙니다.

로짓을 시그모이드 함수에 넣으면 0과 1 사이의 값이 됩니다.


```text
\sigma(z)=\frac{1}{1+e^{-z}}
```



```text
P(y=1|x)=\sigma(z)
```


![ch03_1 설명 그림](img/ch03_1_md3_image.png)
> **시그모이드 함수는 로짓을 확률로 변환합니다.**

### 5. BCE 손실의 의미

Binary Cross Entropy(이진 교차엔트로피)는 이진분류에서 사용하는 손실함수입니다.


```text
\mathrm{BCE}
=
-\frac{1}{n}
\sum_{i=1}^{n}
\left[
y_i\log(p_i)
+
(1-y_i)\log(1-p_i)
\right]
```


- 정답에 가까운 확률 → 손실이 작음
- 틀린 클래스를 높은 확률로 예측 → 손실이 큼

아래 예제는 실제값이 1일 때 예측 확률이 0.9인 경우와 0.1인 경우를 비교합니다.

코드 박스: ch03_1_logistic_classification.ipynb · 코드 셀 5 · 원본 · 실행 기록 있음 · 재실행 미검증

```python

target_one = torch.tensor([[1.0]])

wrong_probability = torch.tensor([[0.1]])

good_loss = bce(
    good_probability,
    target_one,

print("정답 1, 예측 확률 0.1의 Loss:", wrong_loss.item())
```

### 7. 모델 학습

학습 흐름은 와 같습니다.


```text
\text{순전파}
\rightarrow
\text{손실}
\rightarrow
\text{역전파}
\rightarrow
\text{갱신}
```


MSE 대신 `BCEWithLogitsLoss()`를 사용합니다.

코드 박스: ch03_1_logistic_classification.ipynb · 코드 셀 7 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
loss_function = nn.BCEWithLogitsLoss()

optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.1,
)

epochs = 2000
loss_history = []

model.train()

for epoch in range(epochs):
    # 1. 순전파: 로짓 계산
    logits = model(x_data)

    # 2. BCE 손실 계산
    loss = loss_function(
        logits,
        y_data,
    )

    # 3. 이전 기울기 초기화
    optimizer.zero_grad()

    # 4. 역전파
    loss.backward()

    # 5. 가중치와 편향 갱신
    optimizer.step()

    loss_history.append(loss.item())

print("처음 Loss:", loss_history[0])
print("마지막 Loss:", loss_history[-1])
```

실행 결과: 원본 노트북 기록 · 코드 셀 7

```text

마지막 Loss: 0.08368653804063797
```

### 10. TP·TN·FP·FN 확인

| 구분 | 의미 |
|---|---|
| TP(티피) | 실제 1을 1로 예측 |
| TN(티엔) | 실제 0을 0으로 예측 |
| FP(에프피) | 실제 0을 1로 잘못 예측 |
| FN(에프엔) | 실제 1을 0으로 잘못 예측 |

현재 데이터는 6개뿐이므로 일반화 성능이 아니라 학습 데이터 적합도를 확인하는 예제입니다.

```python
actual_bool = y_data.bool()
predicted_bool = predicted_classes.bool()

tp = torch.sum(
    predicted_bool & actual_bool
).item()

tn = torch.sum(
    (~predicted_bool) & (~actual_bool)
).item()

fp = torch.sum(
    predicted_bool & (~actual_bool)
).item()

fn = torch.sum(
    (~predicted_bool) & actual_bool
).item()

print("TP:", tp)
print("TN:", tn)
print("FP:", fp)
print("FN:", fn)
```

### 11. 분류 경계 확인

확률 0.5에 해당하는 로짓은 0입니다.


```text
w_1x_1+w_2x_2+b=0
```


이 직선이 클래스 0과 클래스 1을 나누는 Decision Boundary(디시전 바운더리, 분류 경계)입니다.

### 7. 연속형 특성 표준화

```text

=
\frac{x-\mu_{\mathrm{train}}}
{\sigma_{\mathrm{train}}}
```


- 평균과 표준편차는 훈련 데이터에서만 계산
- 테스트 데이터에는 훈련 데이터의 평균과 표준편차 적용
- 이진형과 원핫 인코딩된 열은 0과 1을 그대로 유지

테스트 데이터의 통계량을 미리 사용하면 Data Leakage(데이터 리키지, 데이터 누출)가 발생합니다.

### 10. 모델 학습

학습 순서는 와 같습니다.


```text
\text{로짓 계산}
\rightarrow
\text{손실 계산}
\rightarrow
\text{역전파}
\rightarrow
\text{가중치 갱신}
```

코드 박스: ch03_2_heart_disease_classification.ipynb · 코드 셀 9 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
epochs = 2000
loss_history = []

model.train()

for epoch in range(epochs):
    # 1. 로짓 계산
    logits = model(
        X_train_tensor
    )

    # 2. BCE 손실 계산
    loss = loss_function(
        logits,
        y_train_tensor,
    )

    # 3. 이전 기울기 초기화
    optimizer.zero_grad()

    # 4. 역전파
    loss.backward()

    # 5. 가중치 갱신
    optimizer.step()

    loss_history.append(
        loss.item()
    )

print("처음 Loss:", loss_history[0])
print("마지막 Loss:", loss_history[-1])
```

### 12. 혼동행렬과 평가지표

| 구분 | 의미 |
|---|---|
| TP(티피) | 실제 1을 1로 예측 |
| TN(티엔) | 실제 0을 0으로 예측 |
| FP(에프피) | 실제 0을 1로 잘못 예측 |
| FN(에프엔) | 실제 1을 0으로 잘못 예측 |


```text
\mathrm{Accuracy}
=
\frac{TP+TN}
{TP+TN+FP+FN}
```



```text
\mathrm{Precision}
=
\frac{TP}
{TP+FP}
```



```text
\mathrm{Recall}
=
\frac{TP}
{TP+FN}
```



```text
F1
=
2
\times
\frac{
\mathrm{Precision}
\times
\mathrm{Recall}
}{
\mathrm{Precision}
+
\mathrm{Recall}
}
```


의료 선별 문제에서는 실제 환자를 놓치는 FN을 줄이는 것이 중요하므로 Recall도 함께 확인합니다.

코드 박스: ch03_2_heart_disease_classification.ipynb · 코드 셀 12 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
def calculate_metrics(
    targets,
    predictions,
):
    targets = targets.reshape(-1)
    predictions = predictions.reshape(-1)

    tp = int(
        ((targets == 1) & (predictions == 1)).sum()
    )

    tn = int(
        ((targets == 0) & (predictions == 0)).sum()
    )

    fp = int(
        ((targets == 0) & (predictions == 1)).sum()
    )

    fn = int(
        ((targets == 1) & (predictions == 0)).sum()
    )

    accuracy = (
        tp + tn
    ) / len(targets)

    precision = tp / max(
        tp + fp,
        1,
    )

    recall = tp / max(
        tp + fn,
        1,
    )

    f1 = (
        2 * precision * recall
        / max(precision + recall, 1e-12)
    )

    return {
        "TP": tp,
        "TN": tn,
        "FP": fp,
        "FN": fn,
        "Accuracy": accuracy,
        "Precision": precision,
        "Recall": recall,
        "F1": f1,
    }


train_metrics = calculate_metrics(
    y_train_tensor,
    train_predictions,
)

test_metrics = calculate_metrics(
    y_test_tensor,
    test_predictions,
)

print("[훈련 데이터]")

for name, value in train_metrics.items():
    print(f"{name:9s}: {value:.4f}")

print()
print("[테스트 데이터]")

for name, value in test_metrics.items():
    print(f"{name:9s}: {value:.4f}")
```

### A·B·C 클래스 중 하나 예측하기

### 개요

### 4. 클래스별 로짓

다중분류 모델은 데이터마다 클래스 수만큼 로짓을 계산합니다.


```text
Z=XW^T+b
```


입력 특성이 4개이고 클래스가 3개이면 다음 구조가 됩니다.


```text
[x_1,x_2,x_3,x_4]
\rightarrow
[z_A,z_B,z_C]
```


- `z_A`: A 클래스의 로짓
- `z_B`: B 클래스의 로짓
- `z_C`: C 클래스의 로짓

로짓은 아직 확률이 아닙니다.

### 5. Softmax로 확률 계산

Softmax는 클래스별 로짓을 0과 1 사이의 확률로 변환합니다.


```text
P(y=k|x)
=
\frac{e^{z_k}}
{\sum_{j=1}^{K}e^{z_j}}
```


한 데이터의 모든 클래스 확률을 더하면 1이 됩니다.

코드 박스: ch03_3_softmax_classification.ipynb · 코드 셀 3 · 원본 · 실행 기록 있음 · 재실행 미검증

### 6. `dim=1`의 의미

`example_logits`의 shape는 `[2, 3]`입니다.

- `2`: 데이터 수
- `3`: A·B·C 클래스 수

Softmax는 **각 데이터 안에서 클래스끼리 비교**해야 하므로 `dim=1`을 사용합니다.


`dim=1`을 적용하면 각 행의 확률 합이 1이 됩니다.

### 7. 교차엔트로피 손실

정답 클래스의 예측 확률을 `p_{\mathrm{correct}}`라고 하면 데이터 하나의 손실은 다음과 같습니다.


```text
\mathrm{Loss}
=
-\log(p_{\mathrm{correct}})
```


- 정답 클래스 확률이 높음 → 손실이 작음
- 정답 클래스 확률이 낮음 → 손실이 큼
- 틀린 클래스를 높은 확률로 예측 → 큰 손실

아래에서는 첫 번째 데이터의 손실을 직접 계산하고 PyTorch 결과와 비교합니다.

코드 박스: ch03_3_softmax_classification.ipynb · 코드 셀 4 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
first_logit = example_logits[0:1]
first_target = torch.tensor([0])

first_probability = torch.softmax(
    first_logit,
    dim=1,
)

correct_probability = first_probability[0, 0]
manual_loss = -torch.log(correct_probability)

loss_function = nn.CrossEntropyLoss()
pytorch_loss = loss_function(
    first_logit,
    first_target,
)

print("정답 클래스 확률:", correct_probability.item())
```

### 8. `CrossEntropyLoss()` 사용 기준

`CrossEntropyLoss()`는 내부에서 다음 계산을 함께 처리합니다.

```text
LogSoftmax
→ Negative Log Likelihood
→ 평균 손실
```

따라서 학습할 때는 모델 출력 로짓에 Softmax를 먼저 적용하지 않습니다.

```python
# 올바른 사용
loss = loss_function(logits, targets)

# 사용하지 않음
loss = loss_function(torch.softmax(logits, dim=1), targets)
```

Softmax는 학습이 끝난 뒤 확률을 확인할 때 사용합니다.

### 10. 모델 학습

학습 흐름은 와 같습니다.


```text
\text{로짓 계산}
\rightarrow
\text{손실 계산}
\rightarrow
\text{역전파}
\rightarrow
\text{가중치 갱신}
```


`CrossEntropyLoss()`를 사용하고, 정답은 클래스 인덱스로 전달합니다.

코드 박스: ch03_3_softmax_classification.ipynb · 코드 셀 6 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
loss_function = nn.CrossEntropyLoss()

optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.1,
)

epochs = 2000
loss_history = []

model.train()

for epoch in range(epochs):
    # 1. 클래스별 로짓 계산
    logits = model(x_data)

    # 2. 교차엔트로피 손실 계산
    loss = loss_function(
        logits,
        y_data,
    )

    # 3. 이전 기울기 초기화
    optimizer.zero_grad()

    # 4. 역전파
    loss.backward()

    # 5. 가중치와 편향 갱신
    optimizer.step()

    loss_history.append(loss.item())

print("처음 Loss:", loss_history[0])
print("마지막 Loss:", loss_history[-1])
```

### 12. 확률·예측 클래스·정확도 확인

학습이 끝난 뒤 결과를 다음 순서로 해석합니다.


```text
\text{Logit}
\rightarrow
\text{Softmax Probability}
\rightarrow
\text{argmax}
\rightarrow
\text{Predicted Class}
```


`argmax(dim=1)`은 각 데이터에서 가장 큰 로짓의 클래스 번호를 반환합니다.

Softmax는 로짓의 순서를 바꾸지 않으므로 클래스 예측에는 로짓에 바로 `argmax()`를 적용할 수 있습니다.

코드 박스: ch03_3_softmax_classification.ipynb · 코드 셀 8 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
model.eval()

with torch.no_grad():
    trained_logits = model(x_data)

    trained_probabilities = torch.softmax(
        trained_logits,
        dim=1,
    )

    predicted_classes = torch.argmax(
        trained_logits,
        dim=1,
    )

    accuracy = (
        predicted_classes == y_data
    ).float().mean()

print(f"학습 데이터 정확도: {accuracy.item():.4f}")

print()
print("번호 | 확률 [A, B, C]               | 예측 | 실제")

for index in range(len(x_data)):
    probabilities = trained_probabilities[index]
    predicted = predicted_classes[index].item()
    actual = y_data[index].item()

    probability_list = [
        round(value, 4)
        for value in probabilities.tolist()
    ]

    print(
        f"{index:>4d} | "
        f"{str(probability_list):<29} | "
        f"{class_names[predicted]:>4s} | "
        f"{class_names[actual]:>4s}"
    )
```

### 6. 훈련 데이터 기준 표준화

네 특성의 평균과 표준편차는 훈련 데이터에서만 계산합니다.


```text
x_{\mathrm{scaled}}
=
\frac{x-\mu_{\mathrm{train}}}
{\sigma_{\mathrm{train}}}
```


테스트 데이터에도 훈련 데이터의 평균과 표준편차를 그대로 사용합니다.

### 9. 모델 학습

학습 순서는 와 같습니다.


```text
\text{로짓 계산}
\rightarrow
\text{손실 계산}
\rightarrow
\text{역전파}
\rightarrow
\text{가중치 갱신}
```

코드 박스: ch03_4_iris_multiclass_classification.ipynb · 코드 셀 9 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
epochs = 1500
loss_history = []

model.train()

for epoch in range(epochs):
    # 1. 클래스별 로짓(확률 변환 전 점수) 계산
    logits = model(
        X_train_tensor
    )
    print(logits)
    # 2. 교차엔트로피 손실 계산
    loss = loss_function(
        logits,
        y_train_tensor,
    )

    # 3. 이전 기울기 초기화 : 기울기 누적되므로
    optimizer.zero_grad()

    # 4. 역전파
    loss.backward()

    # 5. 가중치와 편향 갱신
    optimizer.step()

    loss_history.append(
        loss.item()
    )

print("처음 Loss:", loss_history[0])
print("마지막 Loss:", loss_history[-1])
```

```python
    train_logits = model(
        X_train_tensor
    )

    test_logits = model(
        X_test_tensor

        train_logits,
        dim=1,
```

노트북: `notebooks/ch03_5_heart_training_optimization.ipynb` · 원본 파일: `ch03_5_heart_training_optimization.ipynb` · 상태: 원본 · 실행 기록 없음 · 미검증

### 표준화·학습률·과적합·L2 규제 비교

### 개요

- Training Set(트레이닝 세트, 훈련 데이터), Validation Set(밸리데이션 세트, 검증 데이터), Test Set(테스트 세트, 테스트 데이터)의 역할을 구분합니다.
- 검증 데이터로 모델을 선택하고 테스트 데이터는 마지막에 한 번만 사용합니다.

### 1. 실습 흐름

```text
Heart 데이터 불러오기
→ Heart 데이터 전처리
→ 훈련·검증·테스트 분리
→ 기준 선형 모델
→ 표준화 적용 여부 비교
→ 학습률 비교
→ 복잡한 신경망의 과적합 관찰
→ L2 규제 적용
→ 검증 결과로 모델 선택
→ 테스트 데이터 최종 평가
```

| 실험 | 변경 조건 | 관찰 항목 |
|---|---|---|
| 기준 모델 | 표준화 + 선형 모델 | 비교 기준 |
| 표준화 제거 | 입력 크기만 변경 | 초기 손실과 학습 안정성 |
| 학습률 비교 | 학습률만 변경 | 느린 학습과 빠른 학습 |
| 복잡한 모델 | 은닉층 추가 | 훈련·검증 손실 차이 |
| L2 규제 | `weight_decay` 적용 | 과적합 완화 |

### 7. 공통 학습 함수

실험마다 학습 반복문을 복사하지 않도록 하나의 함수를 사용합니다.

함수의 역할:

1. 모델 학습
2. 매 Epoch의 훈련·검증 손실 기록
3. 검증 손실이 가장 낮았던 Epoch 저장
4. 가장 좋은 가중치 복원

코드는 길어 보이지만, 이후 실험 코드를 짧고 동일하게 유지하기 위한 공통 부분입니다.

코드 박스: ch03_5_heart_training_optimization.ipynb · 코드 셀 6 · 원본 · 실행 기록 없음 · 미검증

```python
loss_function = nn.BCEWithLogitsLoss()


def accuracy_from_logits(logits, targets):
    predictions = (
        torch.sigmoid(logits) >= 0.5
    ).float()

    return (
        predictions == targets
    ).float().mean().item()


def train_model(
    model,
    train_features,
    validation_features,
    learning_rate=0.01,
    epochs=600,
    weight_decay=0.0,
):
    optimizer = torch.optim.Adam(
        model.parameters(),
        lr=learning_rate,
        weight_decay=weight_decay,
    )

    history = {
        "train_loss": [],
        "val_loss": [],
        "train_accuracy": [],
        "val_accuracy": [],
    }

    best_val_loss = float("inf")
    best_epoch = 0
    best_state = copy.deepcopy(
        model.state_dict()
    )

    for epoch in range(epochs):
        model.train()

        train_logits = model(
            train_features
        )

        train_loss = loss_function(
            train_logits,
            train_y,
        )

        optimizer.zero_grad()
        train_loss.backward()
        optimizer.step()

        model.eval()

        with torch.no_grad():
            train_logits = model(
                train_features
            )

            val_logits = model(
                validation_features
            )

            current_train_loss = loss_function(
                train_logits,
                train_y,
            ).item()

            current_val_loss = loss_function(
                val_logits,
                val_y,
            ).item()

            current_train_accuracy = (
                accuracy_from_logits(
                    train_logits,
                    train_y,
                )
            )

            current_val_accuracy = (
                accuracy_from_logits(
                    val_logits,
                    val_y,
                )
            )

        history["train_loss"].append(
            current_train_loss
        )

        history["val_loss"].append(
            current_val_loss
        )

        history["train_accuracy"].append(
            current_train_accuracy
        )

        history["val_accuracy"].append(
            current_val_accuracy
        )

        if current_val_loss < best_val_loss:
            best_val_loss = current_val_loss
            best_epoch = epoch + 1

            best_state = copy.deepcopy(
                model.state_dict()
            )

    # 검증 손실이 가장 낮았던 가중치 복원
    model.load_state_dict(best_state)

    return {
        "model": model,
        "history": history,
        "best_epoch": best_epoch,
        "best_val_loss": best_val_loss,
        "learning_rate": learning_rate,
        "weight_decay": weight_decay,
    }
```

### 11. 실험 4: 복잡한 모델과 과적합

복잡한 모델은 은닉층 두 개만 사용해 구조를 단순하게 유지합니다.

```text
입력 27개
→ Linear(27, 32)
→ ReLU
→ Linear(32, 16)
→ ReLU
→ Linear(16, 1)
```

과적합의 대표적인 흐름:

```text
훈련 손실 계속 감소
+
검증 손실 다시 증가
```

### 12. 실험 5: L2 규제

L2 규제는 가중치가 지나치게 커지는 것을 억제합니다.


```text
\mathrm{Total\ Loss}
=
\mathrm{Data\ Loss}
+
\lambda
\sum_i w_i^2
```


PyTorch에서는 Adam의 `weight_decay`로 간단히 적용할 수 있습니다.

차이를 쉽게 관찰하기 위해 `weight_decay=0.01`을 사용합니다.

### 14. 선택된 모델의 테스트 최종 평가

이제 테스트 데이터를 처음 사용합니다.

평가 지표:

- Accuracy(애큐러시, 정확도)
- Precision(프리시전, 정밀도)
- Recall(리콜, 재현율)
- F1 Score(에프원 스코어)
- Confusion Matrix(컨퓨전 매트릭스, 혼동행렬)

코드 박스: ch03_5_heart_training_optimization.ipynb · 코드 셀 18 · 원본 · 실행 기록 없음 · 미검증

```python
selected_model.eval()

with torch.no_grad():
    test_logits = selected_model(
        test_x
    )

    test_probabilities = torch.sigmoid(
        test_logits
    )

    test_predictions = (
        test_probabilities >= 0.5
    ).float()


actual = test_y.reshape(-1)
predicted = test_predictions.reshape(-1)

tp = int(
    ((actual == 1) & (predicted == 1)).sum()
)

tn = int(
    ((actual == 0) & (predicted == 0)).sum()
)

fp = int(
    ((actual == 0) & (predicted == 1)).sum()
)

fn = int(
    ((actual == 1) & (predicted == 0)).sum()
)

accuracy = (
    tp + tn
) / len(actual)

precision = tp / max(
    tp + fp,
    1,
)

recall = tp / max(
    tp + fn,
    1,
)

f1 = (
    2 * precision * recall
    / max(precision + recall, 1e-12)
)

print("선택된 모델:", selected_name)
print(f"Accuracy : {accuracy:.4f}")
print(f"Precision: {precision:.4f}")
print(f"Recall   : {recall:.4f}")
print(f"F1 Score : {f1:.4f}")

print()
print("TN:", tn, "FP:", fp)
print("FN:", fn, "TP:", tp)
```

### 16. 핵심 정리

- 훈련 데이터는 가중치 학습에 사용합니다.
- 훈련 손실이 감소해도 검증 손실이 증가하면 과적합 가능성이 있습니다.
- 최종 모델은 훈련 정확도가 아니라 검증 성능을 기준으로 선택합니다.

- 이 페이지의 실행 결과와 그림은 **원본 노트북에 저장된 기록**이며, 이번 정리 과정에서 다시 실행하지 않았습니다(재실행 미검증).
- 모델 파일 이름 대응: 모델을 저장·불러오는 노트북은 파일 이름의 장 번호를 새 순번으로 함께 바꾸고, 저장하는 노트북과 불러오는 노트북의 이름이 같은지 스크립트로 확인했습니다(통과). 모델 파일을 쓰지 않는 노트북은 해당 없음입니다.
- 노트북 안의 설명·코드·출력 순서는 원본을 그대로 따릅니다(STANDARD 8절: 코드·이미지·절 순서 임의 변경 금지).

**완료 기준:** 노트북을 순서대로 실행해 오류 없이 끝나고, 손실 감소와 평가 지표가 원본 기록과 비슷한 범위로 나오는지 확인합니다.
