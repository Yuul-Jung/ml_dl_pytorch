## 배경 개념

학습한 모델을 다시 쓰려면 가중치(`state_dict`, 층 이름별 가중치 사전)와 추론에 필요한 정보(클래스 이름·전처리·기준 출력)를 함께 저장하고, 복원한 모델이 같은 출력을 내는지 비교해야 합니다.

ONNX(Open Neural Network Exchange, 오닉스 — 신경망 교환 형식)는 PyTorch 모델을 프레임워크와 무관한 형식으로 내보내는 표준입니다. ONNX Runtime(오닉스 런타임, ONNX 모델 실행기)으로 추론한 결과와 PyTorch 결과를 비교해 배포용 변환이 맞는지 검증합니다.

## 전체 실습 흐름

개념 흐름도 — 이 장 노트북의 공통 학습 절차 (개념도, 이름은 실제 코드 기준):

```flow
5장 전이학습 모델 `load_state_dict` 복원
`torch.save` 가중치·추론 정보 저장 → 복원 출력 비교
`torch.onnx.export` ONNX 내보내기
`onnx.checker` 모델 검사
`onnxruntime.InferenceSession` 추론 → PyTorch 출력·Top-5 비교
```

- 학습 코드는 다시 작성하지 않습니다.
- 모델 생성 함수는 하나만 사용합니다.
- 단일 추론과 배치 추론은 같은 함수로 처리합니다.
- 배포에 필요하지 않은 Optimizer(옵티마이저, 가중치 갱신 알고리즘) 상태는 저장하지 않습니다.
- 복잡한 자동 분기보다 설정값을 명확하게 표시합니다.

| 저장 방식 | 저장 내용 | 사용 목적 |
|---|---|---|
| `state_dict` | Weight(웨이트, 가중치), Bias(바이어스, 편향), Buffer(버퍼, 계층 상태값) | 가장 기본적인 모델 저장 |
| Checkpoint(체크포인트) | `state_dict` + 모델 정보 + 클래스 + 전처리 | 재현 가능한 추론·배포 |
| 전체 모델 객체 | Python 모델 객체 전체 | 코드 경로 의존성이 커서 기본 방식으로 권장하지 않음 |

```text
→ 모델 상태 + Optimizer 상태 + Epoch 정보
```

```python
def create_resnet18(num_classes=1000, pretrained=False):
    """출력 클래스 수에 맞는 ResNet18을 생성합니다."""
    selected_weights = weights if pretrained else None
    model = resnet18(weights=selected_weights)

    if num_classes != 1000:
        model.fc = nn.Linear(model.fc.in_features, num_classes)

    return model
```

#### 6) 데이터 구조 확인

`state_dict()`는 다음과 같은 Dictionary(딕셔너리, 키와 값의 묶음)입니다.

```text
Key
→ 계층과 파라미터 이름

Value
→ 실제 Tensor(텐서, 다차원 수치 배열)
```

저장 전 기준 출력은 다음과 같습니다.


```math
\mathbf{y}_{ref}=f_{\theta}(\mathbf{x})
```


- `$\mathbf{x}$`: 기준 입력
- `$f_{\theta}$`: 가중치 `$\theta$`를 가진 모델
- `$\mathbf{y}_{ref}$`: 저장 전 모델의 기준 출력

#### 9) 저장·복원 결과 비교

복원한 모델 출력:


```math
\mathbf{y}_{load}=f_{\hat{\theta}}(\mathbf{x})
```


최대 절대 오차:


```math
E_{\max}
=
\max_i
\left|
y_{ref,i}-y_{load,i}
\right|
```


가중치가 정확히 복원되면 `$E_{\max}$`는 0 또는 매우 작은 값입니다.

코드 박스: ch06_1_model_save_load_inference.ipynb · 코드 셀 11 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
# 검증용 입력을 CPU로 이동합니다.
cpu_input = sample_input.detach().cpu()

# 원본 모델과 동일한 구조의 CPU 모델을 만듭니다.
reference_model_cpu = create_resnet18(
    num_classes=num_classes
)

# 저장 직전 원본 모델의 가중치를 CPU 모델에 복사합니다.
reference_model_cpu.load_state_dict(
    model.state_dict()
)

reference_model_cpu.eval()

# 원본 가중치와 복원 가중치를 
# 동일한 CPU 환경에서 각각 추론합니다.
with torch.inference_mode():
    reference_cpu = reference_model_cpu(cpu_input)
    restored_output = restored_model(cpu_input)

# 두 결과의 최대 차이를 확인합니다.
max_error = (
    reference_cpu - restored_output
).abs().max().item()

# 같은 장치에서 동일한 가중치로 계산했으므로
# 엄격한 기준으로 비교할 수 있습니다.
torch.testing.assert_close(
    reference_cpu,
    restored_output,
    rtol=1e-5,
    atol=1e-6,
)

print(f"최대 절대 오차: {max_error:.8f}")
```

- Dropout(드롭아웃, 일부 뉴런을 임시로 끄는 정규화)을 추론 방식으로 전환합니다.

- Gradient(그래디언트, 기울기) 계산을 중지합니다.
- 추론에 필요하지 않은 계산 그래프 생성을 줄입니다.

```python
model.eval()

```

두 기능은 역할이 다르므로 추론할 때 함께 사용합니다.

분류 모델은 Logit(로짓, 확률 변환 전 점수)을 출력합니다.


```math
p_i
=
\frac{e^{z_i}}
{\sum_{j=1}^{C}e^{z_j}}
```


- `$z_i$`: `$i$`번째 클래스의 Logit
- `$p_i$`: `$i$`번째 클래스의 예측 확률
- `$C$`: 전체 클래스 수

단일 이미지는 `(C, H, W)`, 배치 이미지는 `(N, C, H, W)` Shape를 사용합니다.

코드 박스: ch06_1_model_save_load_inference.ipynb · 코드 셀 12 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
def predict(model, input_tensor, class_names, device, top_k=5):
    model = model.to(device).eval()

    if input_tensor.ndim == 3:
        input_tensor = input_tensor.unsqueeze(0)

    input_tensor = input_tensor.to(device)

    with torch.inference_mode():
        logits = model(input_tensor)
        probabilities = torch.softmax(logits, dim=1)
        top_probs, top_indices = probabilities.topk(
            k=min(top_k, probabilities.shape[1]),
            dim=1,
        )

    batch_results = []

    for sample_probs, sample_indices in zip(
        top_probs.cpu(), top_indices.cpu()
    ):
        sample_results = []

        for probability, class_index in zip(
            sample_probs, sample_indices
        ):
            index = int(class_index)
            sample_results.append({
                "class_index": index,
                "class_name": class_names[index],
                "probability": float(probability),
            })

        batch_results.append(sample_results)

    return batch_results
```

#### 16) 평균 추론 시간 측정


```math
T_{latency}
=
\frac{t_{end}-t_{start}}{N}
```


- `$N$`: 반복 추론 횟수
- `$T_{latency}$`: 한 번 추론하는 데 걸리는 평균 시간

GPU에서는 연산이 비동기로 실행될 수 있으므로 측정 전후에 동기화합니다.

코드 박스: ch06_1_model_save_load_inference.ipynb · 코드 셀 18 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
def measure_latency(model, input_tensor, device, warmup=5, repeat=20):
    model = model.to(device).eval()
    input_tensor = input_tensor.to(device)

    with torch.inference_mode():
        for _ in range(warmup):
            model(input_tensor)

        if device.type == "cuda":
            torch.cuda.synchronize()

        start = time.perf_counter()

        for _ in range(repeat):
            model(input_tensor)

        if device.type == "cuda":
            torch.cuda.synchronize()

    return (time.perf_counter() - start) / repeat

timing_input = torch.randn(1, 3, 224, 224)

average_seconds = measure_latency(
    restored_model,
    timing_input,
    device,
)

print("측정 장치      :", device)

print(f"평균 추론 시간: {average_seconds * 1000:.3f} ms")
```

|---|---|
| PyTorch Model | Python에서 정의하고 학습한 신경망 |

| ONNX Runtime | ONNX 모델을 읽고 추론하는 실행 엔진 |
| Execution Provider(이그제큐션 프로바이더) | CPU·GPU·NPU 등 실제 실행 장치와 연결 |

```text
PyTorch Model
→ ONNX Exporter
→ model.onnx
→ ONNX Runtime
→ CPU·GPU·가속기
```

ONNX 파일을 생성했다고 해서 자동으로 추론되는 것은 아닙니다. ONNX 파일을 읽고 실행하는 Runtime이 필요합니다.

코랩에서는 다음 세 패키지만 준비하면 됩니다.

```text

onnxscript

→ ONNX 모델 추론
```

CPU 실습에서는 `onnxruntime`을 사용합니다. GPU 실행은 환경에 맞는 별도 ONNX Runtime GPU 패키지가 필요하므로 이번 기본 실습에서는 다루지 않습니다.

#### 8) PyTorch·ONNX 출력 비교

최대 절대 오차:


```math
E_{\max}
=
\max_i
\left|
y_{PT,i}-y_{ORT,i}
\right|
```


평균 절대 오차:


```math
E_{\mathrm{mean}}
=
\frac{1}{C}
\sum_{i=1}^{C}
\left|
y_{PT,i}-y_{ORT,i}
\right|
```


- `$C$`: 전체 클래스 수
- 값이 작을수록 두 Runtime의 출력이 가깝습니다.
- 부동소수점 연산 순서가 달라 매우 작은 오차는 발생할 수 있습니다.

코드 박스: ch06_2_onnx_export_runtime_inference.ipynb · 코드 셀 11 · 원본 · 실행 기록 있음 · 재실행 미검증

#### 9) Top-5 결과 비교

분류 모델의 Logit을 Softmax(소프트맥스, 여러 클래스 점수를 확률로 변환하는 함수)로 변환합니다.


```math
p_i
=
\frac{e^{z_i}}
{\sum_{j=1}^{C}e^{z_j}}
```


PyTorch와 ONNX Runtime의 Top-5 클래스 순서와 확률을 비교합니다.

코드 박스: ch06_2_onnx_export_runtime_inference.ipynb · 코드 셀 12 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
def print_top5(title, logits, class_names):
    probabilities = torch.softmax(torch.as_tensor(logits), dim=1)
    top_probs, top_indices = probabilities.topk(5, dim=1)

    print(title)
    for rank, (probability, class_index) in enumerate(
        zip(top_probs[0], top_indices[0]),
        start=1,
    ):
        index = int(class_index)
        print(
            f"{rank}. {class_names[index]:25s}"
            f" - {float(probability) * 100:6.2f}%"
        )

    return top_indices

pytorch_top5 = print_top5(
    "===== PyTorch Top-5 =====",
    pytorch_logits.detach().cpu(),
    class_names,
)

print()

onnx_top5 = print_top5(
    "===== ONNX Runtime Top-5 =====",
    onnx_logits,
    class_names,
)

print()

print("Top-5 순서 일치:", torch.equal(pytorch_top5, onnx_top5))
```
