## 배경 개념

ResNet(레즈넷, 잔차 신경망)은 Residual Connection(레지듀얼 커넥션, 잔차 연결)으로 입력을 출력에 더해 깊은 층에서도 기울기가 잘 전달되게 만든 CNN 구조입니다. 먼저 ResNet18을 CIFAR-10에 맞춰 학습·평가합니다.

Transfer Learning(트랜스퍼 러닝, 전이학습)은 ImageNet(이미지넷, 대규모 이미지 데이터셋)으로 미리 학습한 가중치를 가져와 마지막 분류층을 새 클래스 수에 맞게 바꾼 뒤 학습하는 방법으로, 적은 학습으로도 높은 성능을 얻습니다.

일반적인 CNN Block(씨엔엔 블록, 합성곱 계층 묶음)은 입력 `\mathbf{x}`를 여러 계층에 통과시킨 결과 `F(\mathbf{x})`를 다음 계층으로 전달합니다.

```text
일반 블록
x → Conv → BatchNorm → ReLU → Conv → BatchNorm → F(x)
```

Residual Block(레지듀얼 블록, 잔차 블록)은 원래 입력 `\mathbf{x}`를 변환 결과에 더합니다.

```text
 ┌──────────── x ────────────┐
 │ ↓
x → Conv → BN → ReLU → Conv → BN → F(x) → F(x) + x → ReLU
```


```text
\mathbf{y}=F(\mathbf{x};\mathbf{W})+\mathbf{x}
```


- `\mathbf{x}`: 블록에 들어온 원래 특징
- `F(\mathbf{x};\mathbf{W})`: 합성곱 계층이 가중치 `\mathbf{W}`로 학습한 변화량
- `\mathbf{y}`: 기존 특징과 새 특징을 더한 출력

> **ResNet은 출력 전체를 새로 만드는 대신, 입력에 더할 변화량을 학습합니다.**

입력과 `F(\mathbf{x})`의 Shape(셰이프, 텐서 크기)가 다르면 바로 더할 수 없습니다. 이때 Downsample(다운샘플, 크기와 채널을 맞추는 변환)이 입력의 Shape를 조정합니다.

#### 9) 배치 데이터 확인

정규화된 이미지는 그대로 표시하면 색상이 어색하게 보입니다.

정규화 식은 다음과 같습니다.


```text
\mathbf{x}_{norm}=\frac{\mathbf{x}-\boldsymbol{\mu}}{\boldsymbol{\sigma}}
```


화면에 표시할 때는 역변환합니다.


```text
\mathbf{x}=\mathbf{x}_{norm}\boldsymbol{\sigma}+\boldsymbol{\mu}
```


- `\boldsymbol{\mu}`: 채널별 평균
- `\boldsymbol{\sigma}`: 채널별 표준편차

#### 10) 모델 구성

기본 `resnet18()`은 ImageNet(이미지넷, 대규모 이미지 데이터셋)의 큰 이미지를 기준으로 설계되었습니다.

```text
기본 입력부
7×7 Conv, stride=2
→ 3×3 MaxPool, stride=2
```

32×32 CIFAR-10 이미지에 그대로 적용하면 공간 크기가 초반에 너무 빠르게 줄어듭니다.

```text
CIFAR-10용 입력부
3×3 Conv, stride=1
→ MaxPool 제거
```

마지막 출력층은 CIFAR-10의 10개 클래스에 맞춥니다.

`weights=None`은 사전학습 가중치를 사용하지 않고 처음부터 학습한다는 뜻입니다.

```python
def create_cifar10_resnet18(num_classes=10):
    model = resnet18(weights=None, num_classes=num_classes)

    # CIFAR-10의 32×32 이미지에 맞게 입력부 수정
    model.conv1 = nn.Conv2d(
        3, 64, kernel_size=3, stride=1, padding=1, bias=False
    )
    model.maxpool = nn.Identity()

    return model

model = create_cifar10_resnet18().to(device)

print(model)
```

#### 11) 모델 파라미터 확인

ResNet18의 첫 번째 BasicBlock(베이식 블록, 기본 잔차 블록)은 입력과 출력 Shape가 같으므로 입력을 그대로 더합니다.

#### 12) 학습 함수 정의

모델은 각 클래스의 Logit(로짓, 정규화되지 않은 원시 점수)을 출력합니다.

`nn.CrossEntropyLoss()`는 Logit과 정답 클래스 번호를 받아 다중분류 손실을 계산합니다. 모델 출력에 Softmax(소프트맥스, 점수를 확률로 변환하는 함수)를 미리 적용하지 않습니다.


```text
L=-\frac{1}{N}\sum_{i=1}^{N}\log p_{i,y_i}
```


- `N`: 미니배치의 이미지 수
- `y_i`: `i`번째 이미지의 실제 클래스
- `p_{i,y_i}`: 실제 클래스에 대한 예측 확률

정확도는 전체 이미지 중 정답을 맞힌 비율입니다.


```text
\text{Accuracy}
=\frac{\text{Correct Predictions}}{\text{Total Samples}}
```


```text
model.train()
→ Forward
→ Loss 계산
→ 기울기 초기화
→ Backpropagation
→ 가중치 갱신
```

```text
model.eval()
→ torch.inference_mode()
→ Forward
→ Loss·Accuracy 계산
```

코드 박스: ch05_1_cifar10_resnet18_training_evaluation.ipynb · 코드 셀 14 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
def train_one_epoch(model, data_loader, loss_function, optimizer):
    model.train()

    total_loss = 0.0
    total_correct = 0
    total_samples = 0

    for images, labels in data_loader:
        images = images.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()

        logits = model(images)
        loss = loss_function(logits, labels)

        loss.backward()
        optimizer.step()

        batch_size = labels.size(0)
        total_loss += loss.item() * batch_size
        total_correct += (logits.argmax(dim=1) == labels).sum().item()
        total_samples += batch_size

    average_loss = total_loss / total_samples
    accuracy = total_correct / total_samples

    return average_loss, accuracy
```

#### 20) Confusion Matrix 준비

Confusion Matrix(컨퓨전 매트릭스, 혼동행렬)는 실제 클래스와 예측 클래스의 관계를 나타냅니다.

```text
행 → 실제 클래스
열 → 예측 클래스
```

- 대각선: 올바르게 분류한 이미지 수
- 대각선 이외: 다른 클래스로 잘못 분류한 이미지 수

클래스별 정확도는 다음과 같습니다.


```text
\text{Class Accuracy}_k
=\frac{\text{Class }k\text{ Correct}}{\text{Class }k\text{ Total}}
```

코드 박스: ch05_1_cifar10_resnet18_training_evaluation.ipynb · 코드 셀 22 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
def build_confusion_matrix(true_labels, predicted_labels, num_classes=10):
    matrix = torch.zeros(num_classes, num_classes, dtype=torch.int64)

    for true_label, predicted_label in zip(true_labels, predicted_labels):
        matrix[true_label, predicted_label] += 1

    return matrix
```

#### 1) 실행 장치 확인

```text
ImageNet 사전학습 ResNet18
→ CIFAR-10용 fc 교체
→ 1단계: fc만 학습
→ 2단계: layer4 + fc 미세조정
→ 시험 성능 비교
→ 혼동행렬과 오답 분석
→ 모델 저장·복원
```

| 단계 | 학습 범위 | 목적 |
|---|---|---|
| Feature Extraction | `fc` | 기존 특징을 그대로 사용하여 빠르게 분류 |
| Fine-Tuning | `layer4 + fc` | 고급 특징을 CIFAR-10에 맞게 조정 |

ResNet18의 앞쪽 계층은 선, 경계, 색상처럼 여러 이미지에 공통으로 나타나는 특징을 학습합니다. 뒤쪽 계층은 사물의 형태처럼 더 복잡한 특징을 학습합니다.

```text
입력 이미지
→ 앞쪽 계층: 선·경계·색상
→ 중간 계층: 질감·부분 형태
→ 뒤쪽 계층: 복잡한 객체 특징
→ fc: 최종 클래스 분류
```


```text
\mathbf{z}=f_{\theta}(\mathbf{x})
```



```text
\hat{\mathbf{y}}=g_{\phi}(\mathbf{z})
```


- `f_{\theta}`: 사전학습된 특징 추출부
- `g_{\phi}`: 새로 교체한 분류층
- Feature Extraction에서는 `\theta`를 고정하고 `\phi`만 학습합니다.


```text
(\theta_{4},\phi)
\leftarrow
(\theta_{4},\phi)
-\eta\nabla_{(\theta_{4},\phi)}\mathcal{L}
```


- `\theta_{4}`: `layer4`의 가중치
- `\phi`: `fc`의 가중치
- `\eta`: Learning Rate(러닝 레이트, 학습률)
- `\mathcal{L}`: 손실함수

Fine-Tuning에서는 뒤쪽 특징 추출부와 분류층을 함께 조금씩 조정합니다.

코랩에서 위에서부터 순서대로 실행합니다. GPU(지피유, 그래픽 처리 장치)가 있으면 자동으로 사용합니다.

#### 12) Loss 함수와 Optimizer 설정

다중분류에서는 Cross Entropy Loss(크로스 엔트로피 로스, 다중분류 손실함수)를 사용합니다.


```text
\mathcal{L}
=
-\frac{1}{N}
\sum_{i=1}^{N}
\log p_{i,y_i}
```


- `N`: 미니배치 이미지 수
- `p_{i,y_i}`: `i`번째 이미지의 정답 클래스 확률

동결된 Batch Normalization(배치 노멀라이제이션, 미니배치 정규화) 계층은 평가 모드로 유지하여 기존 평균과 분산이 바뀌지 않도록 합니다.

```python
def set_training_mode(model):
    model.train()

    # 동결된 BatchNorm의 평균과 분산은 변경하지 않습니다.
    for module in model.modules():
        if isinstance(module, nn.BatchNorm2d):
            if not module.weight.requires_grad:
                module.eval()
```

#### 14) 학습 함수 정의

코드 박스: ch05_2_resnet18_transfer_learning.ipynb · 코드 셀 16 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
def run_one_epoch(model, data_loader, optimizer=None):
    is_training = optimizer is not None

    if is_training:
        set_training_mode(model)
    else:
        model.eval()

    total_loss = 0.0
    total_correct = 0
    total_samples = 0

    context = torch.enable_grad() if is_training else torch.inference_mode()

    with context:
        for images, labels in data_loader:
            images = images.to(device)
            labels = labels.to(device)

            if is_training:
                optimizer.zero_grad()

            logits = model(images)
            loss = loss_function(logits, labels)

            if is_training:
                loss.backward()
                optimizer.step()

            predictions = logits.argmax(dim=1)
            batch_size = labels.size(0)

            total_loss += loss.item() * batch_size
            total_correct += (predictions == labels).sum().item()
            total_samples += batch_size

    average_loss = total_loss / total_samples
    accuracy = total_correct / total_samples

    return average_loss, accuracy
```

#### 15) 모델 학습

같은 학습 함수를 Feature Extraction과 Fine-Tuning에 재사용합니다.

```text
훈련 1 Epoch
→ 검증
→ 최고 검증 정확도 확인
→ 최고 모델 상태 보관
```

복잡한 Scheduler(스케줄러, 학습률 자동 변경)와 Early Stopping(얼리 스토핑, 조기 종료)은 제외하고 전이학습의 핵심 흐름에 집중합니다.

코드 박스: ch05_2_resnet18_transfer_learning.ipynb · 코드 셀 17 · 원본 · 실행 기록 있음 · 재실행 미검증

```python
def fit(model, train_loader, validation_loader, optimizer, epochs, phase_name):
    history = {
        "train_loss": [],
        "train_accuracy": [],
        "validation_loss": [],
        "validation_accuracy": [],
    }

    best_accuracy = 0.0
    best_state = copy.deepcopy(model.state_dict())
    start_time = time.time()

    for epoch in range(1, epochs + 1):
        train_loss, train_accuracy = run_one_epoch(
            model,
            train_loader,
            optimizer,
        )

        validation_loss, validation_accuracy = run_one_epoch(
            model,
            validation_loader,
        )

        history["train_loss"].append(train_loss)
        history["train_accuracy"].append(train_accuracy)
        history["validation_loss"].append(validation_loss)
        history["validation_accuracy"].append(validation_accuracy)

        if validation_accuracy > best_accuracy:
            best_accuracy = validation_accuracy
            best_state = copy.deepcopy(model.state_dict())

        print(
            f"[{phase_name}] Epoch {epoch}/{epochs} | "
            f"Train Acc {train_accuracy * 100:.2f}% | "
            f"Val Acc {validation_accuracy * 100:.2f}%"
        )

    elapsed_time = time.time() - start_time

    return history, best_state, best_accuracy, elapsed_time
```

```python
def make_confusion_matrix(labels, predictions, number_of_classes=10):
    matrix = torch.zeros(
        number_of_classes,
        number_of_classes,
        dtype=torch.int64,
    )

    for true_label, predicted_label in zip(labels, predictions):
        matrix[true_label, predicted_label] += 1

    return matrix
```

- 이 페이지의 실행 결과와 그림은 **원본 노트북에 저장된 기록**이며, 이번 정리 과정에서 다시 실행하지 않았습니다(재실행 미검증).
- 모델 파일 이름 대응: 모델을 저장·불러오는 노트북은 파일 이름의 장 번호를 새 순번으로 함께 바꾸고, 저장하는 노트북과 불러오는 노트북의 이름이 같은지 스크립트로 확인했습니다(통과). 모델 파일을 쓰지 않는 노트북은 해당 없음입니다.
- 노트북 안의 설명·코드·출력 순서는 원본을 그대로 따릅니다(STANDARD 8절: 코드·이미지·절 순서 임의 변경 금지).
- 실행 결과 안에 찍힌 모델 저장 경로(예: `models/ch04_5_best_...`)는 원본 실행 당시의 옛 순번입니다. 코드는 새 순번으로 바꿨으므로 다시 실행하면 새 이름으로 저장됩니다.

**완료 기준:** 노트북을 순서대로 실행해 오류 없이 끝나고, 손실 감소와 평가 지표가 원본 기록과 비슷한 범위로 나오는지 확인합니다.
