## 배경 개념

MNIST는 28×28 흑백 손글씨 숫자 이미지 7만 장으로 된 10클래스 분류 데이터입니다. MLP는 이미지를 784개 숫자로 펼친(`Flatten`) 뒤 `Linear`·`ReLU` 층으로 처리하고, 마지막 10개 로짓을 `CrossEntropyLoss()`에 넣습니다.

데이터가 많아지면 `DataLoader`로 묶음(배치) 단위로 학습합니다. 배치·반복(Iteration, 가중치 갱신 1회)·에폭(Epoch, 전체 데이터 1회) 관계와, 검증 데이터로 가장 좋은 모델을 고르는 방법이 중요해집니다. 이어서 SGD·Momentum·Adam의 차이, Dropout으로 과적합 줄이기, 저장한 모델의 오분류 분석을 다룹니다.

⟪box:쉽게 이해하기⟫

6만 장을 한 번에 보는 대신 64장씩 나눠 보며 조금씩 고치는 것이 미니배치 학습입니다. 문제집을 한 번에 다 풀고 채점하는 대신, 몇 문제씩 풀고 바로 채점해 고치는 편이 훨씬 빨리 실력이 느는 것과 같습니다.

⟪/box⟫

⟪box:꼭 기억할 점⟫

- 배치 크기와 데이터 수로 에폭당 갱신 횟수가 정해집니다(55,000 ÷ 64 → 860번).
- Optimizer를 비교할 때는 초기 가중치와 배치 순서를 똑같이 맞춥니다.
- Dropout은 학습 때만 동작하므로 평가·예측 전에 반드시 `model.eval()`을 호출합니다.

⟪/box⟫

- Batch Size(배치 사이즈): 64

### 7. Batch·Iteration·Epoch 관계


### 8. MLP 모델 구성

```text
입력 이미지 [배치, 1, 28, 28]
→ Flatten
→ [배치, 784]
→ Linear(784, 128)
→ ReLU
→ Dropout(0.2)
→ Linear(128, 10)
→ 숫자별 로짓 10개
```

- `Flatten`: 28×28 이미지를 784개 값으로 펼침
- `Linear(784, 128)`: 784개 픽셀을 128개 특징으로 조합
- `ReLU`: 비선형성 추가
- `Dropout(0.2)`: 학습 중 일부 출력을 무작위로 0으로 설정
- `Linear(128, 10)`: 숫자 0~9의 로짓 10개 출력

코드 박스: ch02_1_mnist_mlp_classification.ipynb · 셀 7 · 미검증

```python
torch.manual_seed(RANDOM_SEED)

model = nn.Sequential(
    nn.Flatten(),
    nn.Linear(28 * 28, 128),
    nn.ReLU(),
    nn.Dropout(0.2),
    nn.Linear(128, 10),
).to(device)

print(model)
```

실행 결과: 셀 7 · 원본 실행 기록

```text
Sequential(
  (0): Flatten(start_dim=1, end_dim=-1)
  (1): Linear(in_features=784, out_features=128, bias=True)
  (2): ReLU()
  (3): Dropout(p=0.2, inplace=False)
  (4): Linear(in_features=128, out_features=10, bias=True)
)
```

⟪box:코드 풀이⟫

이미지를 분류하는 MLP를 만듭니다.
- `nn.Flatten()` — `[1, 28, 28]` 이미지를 784개 숫자로 펼칩니다.
- `nn.Linear(784, 128)` → `ReLU` → `Dropout(0.2)` → `nn.Linear(128, 10)` — 숫자 0~9 점수 10개를 냅니다.
- `nn.Dropout(0.2)` — 학습 중 뉴런 20%를 무작위로 끄는 과적합 방지 장치입니다.
- `.to(device)` — 모델 가중치를 선택한 장치로 옮깁니다.

⟪/box⟫

### 10. 손실함수와 Optimizer

```python
loss_function = nn.CrossEntropyLoss()
```

### 11. 공통 평가 함수

검증과 테스트의 계산 절차가 같으므로 하나의 함수로 정리합니다.

함수의 역할:

1. 평가 모드 전환
2. 기울기 계산 중지
3. 평균 손실 계산
4. 정확도 계산

코드 박스: ch02_1_mnist_mlp_classification.ipynb · 셀 10 · 미검증

```python
def evaluate_model(data_loader):
    model.eval()

    loss_sum = 0.0
    correct = 0
    total = 0

    with torch.no_grad():
        for images, labels in data_loader:
            images = images.to(device)
            labels = labels.to(device)

            logits = model(images)

            loss = loss_function(
                logits,
                labels,
            )

            predictions = logits.argmax(
                dim=1
            )

            loss_sum += (
                loss.item()
                * images.size(0)
            )

            correct += (
                predictions == labels
            ).sum().item()

            total += labels.size(0)

    average_loss = loss_sum / total
    accuracy = correct / total

    return average_loss, accuracy
```

⟪box:코드 풀이⟫

검증·테스트에 함께 쓰는 평가 함수입니다.
- `model.eval()`과 `torch.no_grad()` — Dropout을 끄고 기울기 계산 없이 예측만 합니다.
- `loss.item() * images.size(0)` — 배치 평균 손실에 배치 크기를 곱해 합산합니다. 마지막 배치가 작아도 전체 평균이 정확해집니다.


훈련 성능과 검증 성능을 함께 기록합니다.

```python
train_loss_history = []
train_accuracy_history = []

validation_loss_history = []
validation_accuracy_history = []

for epoch in range(
    1,
    NUMBER_OF_EPOCHS + 1,
):
    model.train()

    loss_sum = 0.0
    correct = 0
    total = 0

    for images, labels in train_loader:
        images = images.to(device)
        labels = labels.to(device)

        # 1. 이전 기울기 초기화
        optimizer.zero_grad()

        # 2. 순전파
        logits = model(images)

        # 3. 손실 계산
        loss = loss_function(
            logits,
            labels,
        )

        # 4. 역전파
        loss.backward()

        # 5. 가중치 갱신
        optimizer.step()

        predictions = logits.argmax(
            dim=1
        )

        loss_sum += (
            loss.item()
            * images.size(0)
        )

        correct += (
            predictions == labels
        ).sum().item()

        total += labels.size(0)

    train_loss = loss_sum / total
    train_accuracy = correct / total

    validation_loss, validation_accuracy = (
        evaluate_model(validation_loader)
    )

    train_loss_history.append(
        train_loss
    )

    train_accuracy_history.append(
        train_accuracy
    )

    validation_loss_history.append(
        validation_loss
    )

    validation_accuracy_history.append(
        validation_accuracy
    )

    print(
        f"Epoch {epoch}/{NUMBER_OF_EPOCHS} | "
        f"Train Loss {train_loss:.4f} | "
        f"Train Accuracy {train_accuracy:.4f} | "
        f"Validation Loss {validation_loss:.4f} | "

    )
```

### 18. MLP의 한계
MLP는 이미지를 `Flatten`하여 784개 숫자로 펼칩니다.

```text
2차원 이미지
→ 1차원 벡터
→ 픽셀의 위치 관계를 직접 활용하기 어려움
```

CNN(씨엔엔, 합성곱 신경망)은 이미지의 가로·세로 위치 관계를 유지하면서 특징을 찾습니다.

```text
MLP : MNIST → Flatten → Linear
CNN : MNIST → Conv2d → ReLU → Pooling
```

> **MLP는 픽셀을 긴 벡터로 보고, CNN은 이미지의 지역적 패턴을 학습합니다.**

### SGD·Momentum·Adam의 학습 차이 확인하기

### 개요

- Optimizer(옵티마이저, 가중치 갱신 방법)의 역할을 이해합니다.
- 선택된 모델만 테스트 데이터로 최종 평가합니다.

### 1. Optimizer 비교 조건

```text
같은 데이터
+ 같은 모델 구조
+ 같은 초기 가중치
+ 같은 미니배치 순서
+ 같은 Epoch 수
→ Optimizer만 변경
```

이 조건을 유지해야 결과 차이를 Optimizer의 영향으로 해석할 수 있습니다.

### 2. 비교할 Optimizer

| Optimizer | 시작 설정 | 쉬운 해석 |
|---|---|---|
| SGD | `lr=0.1` | 현재 기울기 방향으로 이동 |
| SGD + Momentum | `lr=0.1`, `momentum=0.9` | 이전 이동 방향을 함께 반영 |
| Adam | `lr=0.001` | 매개변수마다 이동 크기를 조절 |

**모든 Optimizer에 같은 학습률을 적용하는 실험이 아닙니다.**

각 Optimizer에 일반적으로 사용하는 시작 설정을 적용하여, 입문 실습에서의 학습 특성을 비교합니다.

### 7. Optimizer 설정

손실함수는 세 실험 모두 `CrossEntropyLoss()`로 고정합니다.

Optimizer와 학습률만 다음과 같이 바꿉니다.

코드 박스: ch02_2_mnist_optimizer_comparison.ipynb · 셀 5 · 미검증

```python
loss_function = nn.CrossEntropyLoss()

optimizer_settings = {
    "SGD": {
        "learning_rate": 0.1,
        "momentum": 0.0,
    },
    "SGD + Momentum": {
        "learning_rate": 0.1,
        "momentum": 0.9,
    },
    "Adam": {
        "learning_rate": 0.001,
    },
}


def make_optimizer(
    optimizer_name,
    model,
):
    settings = optimizer_settings[
        optimizer_name
    ]

    if optimizer_name == "Adam":
        return torch.optim.Adam(
            model.parameters(),
            lr=settings["learning_rate"],
        )

    return torch.optim.SGD(
        model.parameters(),
        lr=settings["learning_rate"],
        momentum=settings["momentum"],
    )


for name, settings in optimizer_settings.items():
    print(name, "→", settings)
```

실행 결과: 셀 5 · 원본 실행 기록

```text
SGD → {'learning_rate': 0.1, 'momentum': 0.0}
SGD + Momentum → {'learning_rate': 0.1, 'momentum': 0.9}
Adam → {'learning_rate': 0.001}
```

⟪box:코드 풀이⟫

비교할 세 가지 설정을 사전으로 정리하고, 이름에 맞는 Optimizer를 만드는 함수를 정의합니다.
- `SGD` — 기울기 방향으로 일정하게 이동.
- `SGD + Momentum` — 이전 이동 방향을 0.9만큼 이어받아 관성처럼 더 빠르고 부드럽게 이동.
- `Adam` — 매개변수마다 이동 폭을 자동 조절. 학습률 0.001이 흔히 쓰는 기본값입니다.

### 8. 공통 평가 함수

검증 데이터와 테스트 데이터는 같은 방식으로 평가합니다.

- 평균 손실
- 정확도

검증과 테스트에서는 기울기를 계산하지 않습니다.

코드 박스: ch02_2_mnist_optimizer_comparison.ipynb · 셀 6 · 미검증

```python
def evaluate_model(
    model,
    data_loader,
):
    model.eval()

    loss_sum = 0.0
    correct = 0
    total = 0

    with torch.no_grad():
        for images, labels in data_loader:
            images = images.to(device)
            labels = labels.to(device)

            logits = model(images)

            loss = loss_function(
                logits,
                labels,
            )

            predictions = logits.argmax(
                dim=1
            )

            loss_sum += (
                loss.item()
                * images.size(0)
            )

            correct += (
                predictions == labels
            ).sum().item()

            total += labels.size(0)

    average_loss = loss_sum / total
    accuracy = correct / total

    return average_loss, accuracy
```

⟪box:코드 풀이⟫

모델과 DataLoader를 받아 평균 손실과 정확도를 돌려주는 평가 함수입니다.

### 9. Optimizer 하나를 학습하는 함수

각 Optimizer는 다음 순서로 학습합니다.

```text
같은 초기 가중치 적용
→ 같은 미니배치 순서 사용
→ 5 Epoch 학습
→ 매 Epoch 검증
→ 최고 검증 정확도 가중치 저장
```

검증 정확도가 같으면 검증 손실이 더 낮은 Epoch를 선택합니다.

코드 박스: ch02_2_mnist_optimizer_comparison.ipynb · 셀 7 · 미검증

```python
def run_experiment(
    optimizer_name,
):
    model = make_model().to(device)

    # 같은 초기 가중치 적용
    model.load_state_dict(
        initial_state
    )

    train_loader = make_train_loader()

    optimizer = make_optimizer(
        optimizer_name,
        model,
    )

    train_loss_history = []
    validation_loss_history = []
    validation_accuracy_history = []

    best_validation_accuracy = -1.0
    best_validation_loss = float("inf")
    best_epoch = 0

    best_state = copy.deepcopy(
        model.state_dict()
    )

    print()
    print(f"[{optimizer_name}] 학습 시작")

    for epoch in range(
        1,
        NUMBER_OF_EPOCHS + 1,
    ):
        model.train()

        train_loss_sum = 0.0
        train_total = 0

        for images, labels in train_loader:
            images = images.to(device)
            labels = labels.to(device)

            optimizer.zero_grad()

            logits = model(images)

            loss = loss_function(
                logits,
                labels,
            )

            loss.backward()
            optimizer.step()

            train_loss_sum += (
                loss.item()
                * images.size(0)
            )

            train_total += images.size(0)

        train_loss = (
            train_loss_sum
            / train_total
        )

        validation_loss, validation_accuracy = (
            evaluate_model(
                model,
                validation_loader,
            )
        )

        train_loss_history.append(
            train_loss
        )

        validation_loss_history.append(
            validation_loss
        )

        validation_accuracy_history.append(
            validation_accuracy
        )

        is_better = (
            validation_accuracy
            > best_validation_accuracy
            or (
                validation_accuracy
                == best_validation_accuracy
                and validation_loss
                < best_validation_loss
            )
        )

        if is_better:
            best_validation_accuracy = (
                validation_accuracy
            )

            best_validation_loss = (
                validation_loss
            )

            best_epoch = epoch

            best_state = copy.deepcopy(
                model.state_dict()
            )

        print(
            f"Epoch {epoch}/{NUMBER_OF_EPOCHS} | "
            f"Train Loss {train_loss:.4f} | "
            f"Validation Loss {validation_loss:.4f} | "
            f"Validation Accuracy {validation_accuracy:.4f}"
        )

    # 최고 검증 성능의 가중치 복원
    model.load_state_dict(
        best_state
    )

    return {
        "model": model,
        "train_loss": train_loss_history,
        "validation_loss": validation_loss_history,
        "validation_accuracy": validation_accuracy_history,
        "best_epoch": best_epoch,
        "best_validation_loss": best_validation_loss,
        "best_validation_accuracy": best_validation_accuracy,
    }
```

⟪box:코드 풀이⟫

Optimizer 하나로 처음부터 끝까지 학습하는 실험 함수입니다.
- `model.load_state_dict(initial_state)` — 저장해 둔 같은 초기 가중치로 시작합니다.
- 에폭마다 검증 정확도가 가장 높았던(같으면 손실이 낮은) 상태를 `best_state`에 복사해 두고, 학습이 끝나면 그 가중치로 되돌립니다.

### 17. 결과 해석

일반적으로 짧은 MNIST MLP 실습에서는 다음 경향을 관찰할 수 있습니다.

- SGD: 구조가 단순하지만 초반 학습이 느릴 수 있음
- SGD + Momentum: SGD보다 빠르고 안정적으로 수렴할 수 있음
- Adam: 짧은 Epoch에서도 빠르게 높은 정확도에 도달하는 경우가 많음

그러나 이번 실행에서 Adam이 가장 높게 나오더라도 항상 모든 문제에서 Adam이 가장 좋다는 의미는 아닙니다.

모델 구조·데이터·학습률·Epoch 수가 달라지면 결과도 달라질 수 있습니다.

### 19. 핵심 정리

- Optimizer는 계산된 기울기를 이용해 가중치를 갱신합니다.
- Optimizer별 일반적인 시작 학습률을 사용한 실용적 비교입니다.
- 하나의 실험 결과만으로 특정 Optimizer가 항상 최고라고 결론 내리지 않습니다.


MNIST는 비교적 쉬운 데이터입니다.

과적합을 더 쉽게 관찰하기 위해:

- 전체 60,000개 중 훈련 데이터 8,000개만 사용
- 은닉층을 비교적 크게 구성

실제 프로젝트에서 데이터를 일부러 줄이는 것은 과적합 해결 방법이 아닙니다.

| 상태 | 훈련 성능 | 검증 성능 | 해석 |
|---|---|---|---|
| 과소적합 | 낮음 | 낮음 | 모델 또는 학습이 부족 |
| 적정 학습 | 높음 | 높음 | 새로운 데이터에도 잘 일반화 |
| 과적합 | 매우 높음 | 상대적으로 낮음 | 훈련 데이터를 지나치게 암기 |

과적합의 대표적인 흐름:

```text
훈련 손실은 계속 감소
+
검증 손실은 정체하거나 증가
+
훈련 정확도와 검증 정확도의 차이가 커짐
→ 과적합 가능성
```

일반화 간격:

```text
일반화 간격 = 훈련 정확도 - 검증 정확도
```

일반화 간격이 클수록 훈련 데이터에 지나치게 맞춰졌을 가능성이 있습니다.

```python
def evaluate_model(
    model,
    data_loader,
):
    model.eval()

    loss_sum = 0.0
    correct = 0
    total = 0

    with torch.no_grad():
        for images, labels in data_loader:
            images = images.to(device)
            labels = labels.to(device)

            logits = model(images)

            loss = loss_function(
                logits,
                labels,
            )

            predictions = logits.argmax(
                dim=1
            )

            loss_sum += (
                loss.item()
                * images.size(0)
            )

            correct += (
                predictions == labels
            ).sum().item()

            total += labels.size(0)

    average_loss = loss_sum / total
    accuracy = correct / total

    return average_loss, accuracy
```

#### 7) 모델 학습

각 모델은 같은 절차로 학습합니다.

```text

→ 같은 미니배치 순서 사용
```

코드 박스: ch02_3_mnist_mlp_overfitting_dropout.ipynb · 셀 9 · 미검증

```python
def train_model(
    model,
    model_name,
):
    train_loader = make_train_loader()

    optimizer = torch.optim.Adam(
        model.parameters(),
        lr=0.001,
    )

    history = {
        "train_loss": [],
        "validation_loss": [],
        "train_accuracy": [],
        "validation_accuracy": [],
    }

    best_validation_accuracy = -1.0
    best_validation_loss = float("inf")
    best_epoch = 0

    best_state = copy.deepcopy(
        model.state_dict()
    )

    print()
    print(f"[{model_name}] 학습 시작")

    for epoch in range(
        1,
        NUMBER_OF_EPOCHS + 1,
    ):
        model.train()

        loss_sum = 0.0
        correct = 0
        total = 0

        for images, labels in train_loader:
            images = images.to(device)
            labels = labels.to(device)

            optimizer.zero_grad()

            logits = model(images)

            loss = loss_function(
                logits,
                labels,
            )

            loss.backward()
            optimizer.step()

            predictions = logits.argmax(
                dim=1
            )

            loss_sum += (
                loss.item()
                * images.size(0)
            )

            correct += (
                predictions == labels
            ).sum().item()

            total += labels.size(0)

        train_loss = loss_sum / total
        train_accuracy = correct / total

        validation_loss, validation_accuracy = (
            evaluate_model(
                model,
                validation_loader,
            )
        )

        history["train_loss"].append(
            train_loss
        )

        history["validation_loss"].append(
            validation_loss
        )

        history["train_accuracy"].append(
            train_accuracy
        )

        history["validation_accuracy"].append(
            validation_accuracy
        )

        is_better = (
            validation_accuracy
            > best_validation_accuracy
            or (
                validation_accuracy
                == best_validation_accuracy
                and validation_loss
                < best_validation_loss
            )
        )

        if is_better:
            best_validation_accuracy = (
                validation_accuracy
            )

            best_validation_loss = (
                validation_loss
            )

            best_epoch = epoch

            best_state = copy.deepcopy(
                model.state_dict()
            )

        print(
            f"Epoch {epoch:>2d}/{NUMBER_OF_EPOCHS} | "
            f"Train Loss {train_loss:.4f} | "
            f"Train Accuracy {train_accuracy:.4f} | "
            f"Validation Loss {validation_loss:.4f} | "
            f"Validation Accuracy {validation_accuracy:.4f}"
        )

    model.load_state_dict(
        best_state
    )

    return {
        "model": model,
        "history": history,
        "best_epoch": best_epoch,
        "best_validation_loss": best_validation_loss,
        "best_validation_accuracy": best_validation_accuracy,
    }
```

#### 9) Dropout MLP 학습

모델 구조와 학습 조건은 그대로 유지하고 Dropout 비율만 `0.3`으로 변경합니다.

#### 14) 결과 요약 함수

비교 항목:

- 최고 검증 정확도
- 최고 검증 Epoch
- 마지막 훈련 정확도
- 마지막 검증 정확도
- 마지막 일반화 간격

Dropout의 목적은 훈련 정확도를 최대화하는 것이 아니라 새로운 데이터에 대한 일반화를 개선하는 것입니다.

코드 박스: ch02_3_mnist_mlp_overfitting_dropout.ipynb · 셀 16 · 미검증

```python
def summarize_result(
    model_name,
    result,
):
    history = result["history"]

    final_train_accuracy = history[
        "train_accuracy"
    ][-1]

    final_validation_accuracy = history[
        "validation_accuracy"
    ][-1]

    final_gap = (
        final_train_accuracy
        - final_validation_accuracy
    )

    return {
        "model_name": model_name,
        "best_epoch": result["best_epoch"],
        "best_validation_loss": result[
            "best_validation_loss"
        ],
        "best_validation_accuracy": result[
            "best_validation_accuracy"
        ],
        "final_train_accuracy": (
            final_train_accuracy
        ),
        "final_validation_accuracy": (
            final_validation_accuracy
        ),
        "final_gap": final_gap,
    }
```

⟪box:코드 풀이⟫

학습 결과에서 최고 검증 성능과 마지막 에폭의 정확도·일반화 간격을 뽑아 요약하는 함수입니다.

#### 17) train()과 eval()에서 Dropout 동작 비교

같은 이미지를 여러 번 입력합니다.

- `model.train()`: Dropout이 동작하므로 출력이 달라질 수 있음
- `model.eval()`: Dropout이 꺼지므로 출력이 같음

평가 전에 `model.eval()`을 호출하지 않으면 예측 결과가 불안정해질 수 있습니다.

코드 박스: ch02_3_mnist_mlp_overfitting_dropout.ipynb · 셀 19 · 미검증

```python
sample_images, _ = next(
    iter(validation_loader)
)

sample_image = sample_images[:1].to(device)

selected_dropout_model = dropout_result[
    "model"
]

selected_dropout_model.train()

train_output_1 = selected_dropout_model(
    sample_image
).detach().cpu()

train_output_2 = selected_dropout_model(
    sample_image
).detach().cpu()

selected_dropout_model.eval()

with torch.no_grad():
    eval_output_1 = selected_dropout_model(
        sample_image
    ).cpu()

    eval_output_2 = selected_dropout_model(
        sample_image
    ).cpu()

print(
    "train() 출력이 같은가?:",
    torch.allclose(
        train_output_1,
        train_output_2,
    ),
)

print(
    "eval() 출력이 같은가?:",
    torch.allclose(
        eval_output_1,
        eval_output_2,
    ),
)
```

실행 결과: 셀 19 · 원본 실행 기록

```text

eval() 출력이 같은가?: True
```

⟪box:코드 풀이⟫

같은 이미지를 두 번 넣어 Dropout의 동작을 확인합니다.
- `train()` 모드에서는 매번 다른 뉴런이 꺼지므로 두 출력이 다릅니다(`False`).
- `eval()` 모드에서는 Dropout이 꺼져 두 출력이 같습니다(`True`). 예측할 때 `model.eval()`이 필요한 이유입니다.

```python
            images.to(device)

    image_batches
)

    label_batches
)

all_logits = torch.cat(
    logit_batches
)

    all_logits,
    dim=1
)

all_confidences, all_predictions = (
    all_probabilities.max(dim=1)
)

print("정답 shape:", all_labels.shape)
```

#### 14) 숫자별 정확도 계산

숫자별 정확도는 혼동행렬의 각 행에서 계산할 수 있습니다.

```text
숫자별 정확도
→ 해당 숫자를 맞힌 개수
÷ 해당 숫자의 전체 개수
```

전체 정확도만으로는 알 수 없었던 약한 숫자를 찾을 수 있습니다.

코드 박스: ch02_4_mnist_prediction_error_analysis.ipynb · 셀 16 · 미검증

```python
class_correct = confusion_matrix.diag()

class_total = confusion_matrix.sum(
    dim=1
)

class_accuracy = (
    class_correct.float()
    / class_total
)

for digit in range(10):
    print(
        f"숫자 {digit} | "
        f"정확도 {class_accuracy[digit].item():.4f} | "
        f"{class_correct[digit].item()}"
        f"/{class_total[digit].item()}"
    )

lowest_class = torch.argmin(
    class_accuracy
).item()

highest_class = torch.argmax(
    class_accuracy
).item()

print()

print("가장 낮은 정확도의 숫자:", lowest_class)

print("가장 높은 정확도의 숫자:", highest_class)
```

#### 20) 직접 그린 숫자 전처리 함수

일반적인 그림과 MNIST의 차이:

```text
일반 그림
흰 배경 + 검은 숫자

MNIST
검은 배경 + 밝은 숫자
```

필요한 전처리:

```text
흑백 변환
→ 필요하면 색상 반전
→ 숫자 영역 자르기
→ 비율을 유지하며 20×20 안에 맞추기
→ 28×28 검은 화면 중앙에 배치
→ Tensor 변환
→ 학습과 같은 정규화
```

단순히 28×28로 강제 변환하면 숫자의 비율이 찌그러질 수 있습니다.

코드 박스: ch02_4_mnist_prediction_error_analysis.ipynb · 셀 22 · 미검증

```python
def preprocess_digit_image(image):
    grayscale = image.convert("L")

    image_array = np.array(
        grayscale
    )

    # 흰 배경이면 MNIST처럼 반전
    if image_array.mean() > 127:
        image_array = 255 - image_array

    # 약한 배경 잡음 제거
    image_array[
        image_array < 30
    ] = 0

    foreground_y, foreground_x = np.where(
        image_array > 0
    )

    if len(foreground_x) == 0:
        raise ValueError(
            "숫자 영역을 찾지 못했습니다."
        )

    left = foreground_x.min()
    right = foreground_x.max() + 1
    top = foreground_y.min()
    bottom = foreground_y.max() + 1

    cropped = Image.fromarray(
        image_array[
            top:bottom,
            left:right
        ]
    )

    scale = 20 / max(
        cropped.size
    )

    resized_size = (
        max(1, round(cropped.width * scale)),
        max(1, round(cropped.height * scale))
    )

    resized = cropped.resize(
        resized_size,
        Image.Resampling.LANCZOS
    )

    canvas = Image.new(
        "L",
        (28, 28),
        0
    )

    paste_position = (
        (28 - resized.width) // 2,
        (28 - resized.height) // 2
    )

    canvas.paste(
        resized,
        paste_position
    )

    tensor = transforms.ToTensor()(
        canvas
    )

    normalized_tensor = transforms.Normalize(
        (normalization_mean,),
        (normalization_std,)
    )(tensor)

    return canvas, normalized_tensor.unsqueeze(0)
```

⟪box:코드 풀이⟫

직접 그린 숫자 이미지를 MNIST 형식으로 바꾸는 전처리 함수입니다.
- 흑백 변환 → 흰 배경이면 반전(MNIST는 검은 배경에 흰 글씨) → 약한 잡음 제거.
- 숫자가 있는 영역만 잘라 긴 변을 20픽셀로 줄이고, 28×28 검은 캔버스 가운데에 붙입니다(MNIST와 같은 배치).
- 마지막으로 `ToTensor`와 학습 때와 같은 `Normalize`를 적용하고, `unsqueeze(0)`으로 배치 차원을 붙여 `[1, 1, 28, 28]`로 돌려줍니다.
