## 배경 개념

합성곱 신경망(CNN)은 이미지를 펼치지 않고 `Conv2d` 필터로 주변 픽셀의 패턴을 찾은 뒤, 풀링(Pooling)으로 크기를 줄입니다. MLP와 다른 곳은 **앞부분의 특징 추출**뿐이고, 마지막 10개 로짓과 `CrossEntropyLoss()`는 같습니다.

학습된 필터와 특징맵(Feature Map)을 직접 그려 CNN이 무엇을 보는지 확인한 뒤, 32×32 컬러 이미지 CIFAR-10에서 기본 CNN과 깊은 CNN(배치 정규화, 데이터 증강, 학습률 스케줄러, 조기 종료)을 비교합니다.

⟪box:쉽게 이해하기⟫

CNN의 필터는 이미지 위를 미끄러지며 '여기에 세로선이 있나?', '여기에 둥근 모서리가 있나?'를 묻는 작은 돋보기입니다. 같은 돋보기를 이미지 전체에 돌려 쓰기 때문에 물체가 조금 움직여도 같은 특징을 찾아내고, 파라미터도 훨씬 적게 듭니다.

⟪/box⟫

⟪box:꼭 기억할 점⟫

- `Conv2d`의 `padding=1`은 크기를 유지하고, `MaxPool2d(2, 2)`는 크기를 절반으로 줄입니다.
- CNN은 필터를 공유해 MLP보다 적은 파라미터로 더 높은 정확도를 냅니다.
- 데이터 증강은 학습 데이터에만 적용하고, 검증·테스트는 원본으로 평가합니다.

⟪/box⟫

#### 6) 모델 구성

아래 CNN 구조를 실제 데이터에 적용합니다.

```text
입력 [N, 1, 28, 28]

→ Conv2d(1, 8, 3, padding=1)
→ ReLU
→ MaxPool2d(2, 2)
→ [N, 8, 14, 14]

→ Conv2d(8, 16, 3, padding=1)
→ ReLU
→ MaxPool2d(2, 2)
→ [N, 16, 7, 7]

→ Flatten
→ [N, 784]

→ Linear(784, 10)
→ [N, 10]
```

별도의 사용자 정의 모델 클래스 없이 `nn.Sequential`을 사용합니다.

코드 박스: ch04_1_fashion_mnist_cnn_training_evaluation.ipynb · 셀 8 · 미검증

```python
def make_cnn():
    return nn.Sequential(
        nn.Conv2d(
            1,
            8,
            kernel_size=3,
            padding=1
        ),
        nn.ReLU(),
        nn.MaxPool2d(
            kernel_size=2,
            stride=2
        ),

        nn.Conv2d(
            8,
            16,
            kernel_size=3,
            padding=1
        ),
        nn.ReLU(),
        nn.MaxPool2d(
            kernel_size=2,
            stride=2
        ),

        nn.Flatten(start_dim=1),
        nn.Linear(
            16 * 7 * 7,
            10
        )
    )

torch.manual_seed(RANDOM_SEED)

model = make_cnn().to(device)

print(model)
```

실행 결과: 셀 8 · 원본 실행 기록

```text
Sequential(
  (0): Conv2d(1, 8, kernel_size=(3, 3), stride=(1, 1), padding=(1, 1))
  (1): ReLU()
  (2): MaxPool2d(kernel_size=2, stride=2, padding=0, dilation=1, ceil_mode=False)
  (3): Conv2d(8, 16, kernel_size=(3, 3), stride=(1, 1), padding=(1, 1))
  (4): ReLU()
  (5): MaxPool2d(kernel_size=2, stride=2, padding=0, dilation=1, ceil_mode=False)
  (6): Flatten(start_dim=1, end_dim=-1)
  (7): Linear(in_features=784, out_features=10, bias=True)
)
```

⟪box:코드 풀이⟫

합성곱 신경망(CNN)을 정의합니다.
- `nn.Conv2d(1, 8, kernel_size=3, padding=1)` — 3×3 필터 8개로 이미지를 훑어 특징맵 8장을 만듭니다. `padding=1`이라 크기 28×28이 유지됩니다.
- `nn.MaxPool2d(2, 2)` — 2×2 영역에서 가장 큰 값만 남겨 가로·세로를 절반으로 줄입니다(28 → 14 → 7).
- 마지막에 `16 × 7 × 7 = 784`개 특징을 펼쳐 `nn.Linear`로 클래스 10개의 점수를 냅니다.

#### 11) 학습 함수 정의

 MLP 함수와 구조는 같습니다.

차이는 `model(images)` 내부에서 합성곱 필터가 먼저 특징을 추출한다는 점입니다.

코드 박스: ch04_1_fashion_mnist_cnn_training_evaluation.ipynb · 셀 13 · 미검증

```python
def train_one_epoch(
    model,
    data_loader
):
    model.train()

    loss_sum = 0.0
    correct = 0
    total = 0

    for images, labels in data_loader:
        images = images.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()

        logits = model(images)

        loss = loss_function(
            logits,
            labels
        )

        loss.backward()
        optimizer.step()

        predictions = logits.argmax(
            dim=1
        )

        loss_sum += (
            loss.item()
            * images.size(0)
        )

        correct += (
            predictions == labels
        ).sum().item()

        total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )
```

⟪box:코드 풀이⟫

한 에폭 동안 모든 배치를 학습하고 평균 손실과 정확도를 돌려주는 함수입니다.

```python
def evaluate_model(
    model,
    data_loader
):
    model.eval()

    loss_sum = 0.0
    correct = 0
    total = 0

    with torch.no_grad():
        for images, labels in data_loader:
            images = images.to(device)
            labels = labels.to(device)

            logits = model(images)

            loss = loss_function(
                logits,
                labels
            )

            predictions = logits.argmax(
                dim=1
            )

            loss_sum += (
                loss.item()
                * images.size(0)
            )

            correct += (
                predictions == labels
            ).sum().item()

            total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )
```

#### 28) 2픽셀 이동 민감도

MLP에도 같은 실험을 적용합니다.

```text
원본 이미지
→ 오른쪽으로 2픽셀 이동
→ 새로 생긴 왼쪽 영역은 0으로 채움
```

사람에게는 같은 의류이지만 모델의 예측이 얼마나 바뀌는지 확인합니다.

코드 박스: ch04_1_fashion_mnist_cnn_training_evaluation.ipynb · 셀 30 · 미검증

```python
def shift_right(
    images,
    pixels=2
):
    shifted = torch.zeros_like(
        images
    )

    shifted[
        :,
        :,
        :,
        pixels:
    ] = images[
        :,
        :,
        :,
        :-pixels
    ]

    return shifted
```

⟪box:코드 풀이⟫

이미지를 오른쪽으로 2픽셀 미는 함수입니다. 앞 장 MLP와 같은 실험을 CNN에 적용합니다.

#### 29) 이동 이미지로 테스트

코드 박스: ch04_1_fashion_mnist_cnn_training_evaluation.ipynb · 셀 31 · 미검증

```python
shifted_correct = 0

prediction_changed = 0

total = 0

model.eval()

with torch.no_grad():
    for images, labels in test_loader:
        images = images.to(device)
        labels = labels.to(device)

        shifted_images = shift_right(
            images,
            pixels=2
        )

        original_predictions = model(
            images
        ).argmax(dim=1)

        shifted_predictions = model(
            shifted_images
        ).argmax(dim=1)

        shifted_correct += (
            shifted_predictions == labels
        ).sum().item()

        prediction_changed += (
            shifted_predictions
            != original_predictions
        ).sum().item()

        total += labels.size(0)

shifted_accuracy = (
    shifted_correct / total
)

prediction_change_rate = (
    prediction_changed / total
)

accuracy_drop = (
    test_accuracy - shifted_accuracy
)

print(f"원본 정확도: {test_accuracy:.4f}")
```

#### 5) 계층별 출력을 모으는 함수

`model(image)`는 최종 로짓만 반환합니다.

중간 특징맵을 확인하기 위해 각 계층을 순서대로 직접 통과시킵니다.

`nn.Sequential`의 계층 번호:

```text
model[0] → Conv1
model[1] → ReLU1
model[2] → Pool1
model[3] → Conv2
model[4] → ReLU2
model[5] → Pool2
model[6] → Flatten
model[7] → Linear
```

코드 박스: ch04_2_cnn_filter_feature_map_visualization.ipynb · 셀 7 · 미검증

```python
def get_cnn_stages(model, images):
    conv1 = model[0](images)
    relu1 = model[1](conv1)
    pool1 = model[2](relu1)

    conv2 = model[3](pool1)
    relu2 = model[4](conv2)
    pool2 = model[5](relu2)

    flattened = model[6](pool2)
    logits = model[7](flattened)

    return {
        "conv1": conv1,
        "relu1": relu1,
        "pool1": pool1,
        "conv2": conv2,
        "relu2": relu2,
        "pool2": pool2,
        "logits": logits,
    }
```

⟪box:코드 풀이⟫

층을 하나씩 직접 호출해 **중간 결과를 모두** 사전으로 돌려주는 함수입니다.
- `model(images)`는 최종 출력만 주지만, `model[0](images)`처럼 층을 번호로 꺼내 차례로 호출하면 각 단계의 특징맵을 볼 수 있습니다.

#### 10) ReLU 전후 비교

ReLU(렐루, 음수를 0으로 만드는 활성화 함수)는 Shape를 바꾸지 않습니다.

```python
                    prediction_value

            if (
```

```text
→ 대표 Conv2 특징맵 3개
```

코드 박스: ch04_2_cnn_filter_feature_map_visualization.ipynb · 셀 19 · 미검증

```python
def show_example_features(
    model,
    example,
    title
):
    image, true_label, predicted_label = example

    image_input = image.unsqueeze(
        0
    ).to(device)

    with torch.no_grad():
        stages = get_cnn_stages(
            model,
            image_input
        )

    feature_maps = stages[
        "relu2"
    ].detach().cpu()

    scores = feature_maps[0].mean(
        dim=(1, 2)
    )

    top_channels = torch.topk(
        scores,
        k=3
    ).indices

    plt.figure(figsize=(10, 3))

    plt.subplot(1, 4, 1)
    plt.imshow(
        image.squeeze(),
        cmap="gray"
    )
    plt.title(
        f"{title}\n"
        f"A:{class_names_ko[true_label]}\n"
        f"P:{class_names_ko[predicted_label]}"
    )
    plt.axis("off")

    for plot_index, channel in enumerate(
        top_channels,
        start=2
    ):
        plt.subplot(1, 4, plot_index)

        plt.imshow(
            feature_maps[0, channel],
            cmap="gray"
        )

        plt.title(
            f"Conv2 Map {channel.item() + 1}"
        )

        plt.axis("off")

    plt.tight_layout()
    plt.show()
```

⟪box:코드 풀이⟫

한 사례의 원본 이미지와, 두 번째 층에서 반응이 가장 강한 특징맵 3장을 나란히 그리는 함수입니다.
- `torch.topk(scores, k=3).indices` — 평균 반응이 큰 채널 3개의 번호.

#### 6) 정규화 되돌리기 함수

정규화된 이미지는 화면에 표시할 때만 원래 범위에 가깝게 복원합니다.

```text
정규화된 Tensor
→ 표준편차 곱하기
→ 평균 더하기
→ 0~1 범위로 제한
```

코드 박스: ch04_3_cifar10_basic_cnn_training_evaluation.ipynb · 셀 8 · 미검증

```python
def denormalize_image(image):
    mean = torch.tensor(
        CIFAR10_MEAN,
        dtype=image.dtype
    ).view(3, 1, 1)

    std = torch.tensor(
        CIFAR10_STD,
        dtype=image.dtype
    ).view(3, 1, 1)

    return (
        image.cpu() * std + mean
    ).clamp(0, 1)
```

⟪box:코드 풀이⟫

정규화를 되돌려 원래 색으로 표시하는 함수입니다.
- `.view(3, 1, 1)` — 채널별 값 3개를 `[3, 1, 1]` 모양으로 바꿔, `[3, 32, 32]` 이미지의 각 채널에 브로드캐스팅되게 합니다.

#### 10) 모델 구성

```text
입력 [N, 3, 32, 32]

→ Conv2d(3, 32)
→ ReLU
→ MaxPool2d
→ [N, 32, 16, 16]

→ Conv2d(32, 64)
→ ReLU
→ MaxPool2d
→ [N, 64, 8, 8]

→ Flatten
→ [N, 4096]

→ Linear(4096, 128)
→ ReLU
→ Linear(128, 10)
→ [N, 10]
```

이 모델을 Baseline(베이스라인, 기준 모델)으로 사용합니다.

다음 기능은 아직 사용하지 않습니다.

- 데이터 증강
- Batch Normalization(배치 노멀라이제이션)
- Dropout
- 깊은 CNN

코드 박스: ch04_3_cifar10_basic_cnn_training_evaluation.ipynb · 셀 12 · 미검증

```python
def make_basic_cnn():
    return nn.Sequential(
        nn.Conv2d(
            3,
            32,
            kernel_size=3,
            padding=1
        ),
        nn.ReLU(),
        nn.MaxPool2d(
            kernel_size=2,
            stride=2
        ),

        nn.Conv2d(
            32,
            64,
            kernel_size=3,
            padding=1
        ),
        nn.ReLU(),
        nn.MaxPool2d(
            kernel_size=2,
            stride=2
        ),

        nn.Flatten(start_dim=1),
        nn.Linear(
            64 * 8 * 8,
            128
        ),
        nn.ReLU(),
        nn.Linear(
            128,
            10
        )
    )
```

- 입력 채널 3(컬러) → 32 → 64로 늘리고, 크기는 풀링으로 32 → 16 → 8로 줄입니다.
- `64 × 8 × 8 = 4,096`개 특징을 펼쳐 은닉층 128개를 거쳐 클래스 10개 점수를 냅니다.

#### 14) 학습 함수 정의

학습 함수는 동일한 구조를 사용하며, CNN 내부만 RGB 입력용으로 구성합니다.

코드 박스: ch04_3_cifar10_basic_cnn_training_evaluation.ipynb · 셀 16 · 미검증

```python
def train_one_epoch(
    model,
    data_loader
):
    model.train()

    loss_sum = 0.0
    correct = 0
    total = 0

    for images, labels in data_loader:
        images = images.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()

        logits = model(images)

        loss = loss_function(
            logits,
            labels
        )

        loss.backward()
        optimizer.step()

        predictions = logits.argmax(
            dim=1
        )

        loss_sum += (
            loss.item()
            * images.size(0)
        )

        correct += (
            predictions == labels
        ).sum().item()

        total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )
```

⟪box:코드 풀이⟫

한 에폭 학습 함수입니다.

```python
def evaluate_model(
    model,
    data_loader
):
    model.eval()

    loss_sum = 0.0
    correct = 0
    total = 0

    with torch.no_grad():
        for images, labels in data_loader:
            images = images.to(device)
            labels = labels.to(device)

            logits = model(images)

            loss = loss_function(
                logits,
                labels
            )

            predictions = logits.argmax(
                dim=1
            )

            loss_sum += (
                loss.item()
                * images.size(0)
            )

            correct += (
                predictions == labels
            ).sum().item()

            total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )
```

#### 3) 학습용 증강과 평가용 변환

```text

```


검증과 테스트 데이터에는 무작위 변형을 적용하지 않습니다.

코드 박스: ch04_4_cifar10_deep_cnn_improvement_comparison.ipynb · 셀 5 · 미검증

```python

    [
        transforms.RandomCrop(
            size=32,
            padding=4
        ),
        transforms.RandomHorizontalFlip(
            p=0.5
        ),
        transforms.ToTensor(),
        transforms.Normalize(
            mean=CIFAR10_MEAN,
            std=CIFAR10_STD
        )
    ]
)

evaluation_transform = transforms.Compose(
    [
        transforms.ToTensor(),
        transforms.Normalize(
            mean=CIFAR10_MEAN,
            std=CIFAR10_STD
        )
    ]
)
```

⟪box:코드 풀이⟫

학습용과 평가용 변환을 따로 만듭니다.
- `RandomCrop(32, padding=4)` — 가장자리에 4픽셀을 덧댄 뒤 무작위 위치에서 32×32를 잘라 위치를 조금씩 바꿉니다.
- `RandomHorizontalFlip(p=0.5)` — 절반 확률로 좌우를 뒤집습니다.
- 이런 **데이터 증강**은 학습에만 적용하고, 검증·테스트는 원본 그대로 평가합니다.

#### 4) 증강을 분리한 데이터 분할

훈련 데이터와 검증 데이터는 서로 다른 Transform을 사용해야 합니다.

따라서 같은 CIFAR-10 원본을 두 번 불러온 뒤, 같은 인덱스를 적용합니다.

```text
같은 원본 50,000개
├─ 훈련용 데이터셋: 데이터 증강 적용
└─ 검증용 데이터셋: 평가 전처리 적용

같은 고정 인덱스
├─ 학습 45,000개
└─ 검증 5,000개
```

코드 박스: ch04_4_cifar10_deep_cnn_improvement_comparison.ipynb · 셀 6 · 미검증

```python
train_source_dataset = datasets.CIFAR10(

)

    train=False,
    download=True,

    len(train_source_dataset),
    generator=index_generator
```

#### 6) 정규화 되돌리기 함수

같은 이미지도 훈련할 때마다 조금씩 다르게 보일 수 있습니다.

- 위치가 조금 이동함
- 가장자리 일부가 잘림
- 좌우가 반전됨

클래스는 그대로 유지하면서 다양한 입력을 만드는 것이 목적입니다.

코드 박스: ch04_4_cifar10_deep_cnn_improvement_comparison.ipynb · 셀 8 · 미검증

```python
def denormalize_image(image):
    mean = torch.tensor(
        CIFAR10_MEAN,
        dtype=image.dtype
    ).view(3, 1, 1)

    std = torch.tensor(
        CIFAR10_STD,
        dtype=image.dtype
    ).view(3, 1, 1)

    return (
        image.cpu() * std + mean
    ).clamp(0, 1)
```

⟪box:코드 풀이⟫

정규화를 되돌려 원래 색으로 표시하는 함수입니다.

```python
def make_basic_cnn():
    return nn.Sequential(
        nn.Conv2d(
            3,
            32,
            kernel_size=3,
            padding=1
        ),
        nn.ReLU(),
        nn.MaxPool2d(2, 2),

        nn.Conv2d(
            32,
            64,
            kernel_size=3,
            padding=1
        ),
        nn.ReLU(),
        nn.MaxPool2d(2, 2),

        nn.Flatten(start_dim=1),
        nn.Linear(
            64 * 8 * 8,
            128
        ),
        nn.ReLU(),
        nn.Linear(
            128,
            10
        )
    )
```

#### 11) Deep CNN 구성

복잡한 사용자 정의 모델 클래스 없이 중첩된 `nn.Sequential`로 구성합니다.

```text
Block1: Conv 2개 → Pool
Block2: Conv 2개 → Pool
Block3: Conv 1개 → Pool
Block4: Conv 1개 → Pool
Block5: Conv 1개 → Pool
분류부: Flatten → Linear → Dropout → Linear
```

```python
def make_deep_cnn():
    return nn.Sequential(
        # Block 1: 32×32 → 16×16
        nn.Sequential(
            nn.Conv2d(
                3,
                32,
                kernel_size=3,
                padding=1,
                bias=False
            ),
            nn.BatchNorm2d(32),
            nn.ReLU(),

            nn.Conv2d(
                32,
                32,
                kernel_size=3,
                padding=1,
                bias=False
            ),
            nn.BatchNorm2d(32),
            nn.ReLU(),

            nn.MaxPool2d(2, 2),
            nn.Dropout2d(0.10)
        ),

        # Block 2: 16×16 → 8×8
        nn.Sequential(
            nn.Conv2d(
                32,
                64,
                kernel_size=3,
                padding=1,
                bias=False
            ),
            nn.BatchNorm2d(64),
            nn.ReLU(),

            nn.Conv2d(
                64,
                64,
                kernel_size=3,
                padding=1,
                bias=False
            ),
            nn.BatchNorm2d(64),
            nn.ReLU(),

            nn.MaxPool2d(2, 2),
            nn.Dropout2d(0.15)
        ),

        # Block 3: 8×8 → 4×4
        nn.Sequential(
            nn.Conv2d(
                64,
                128,
                kernel_size=3,
                padding=1,
                bias=False
            ),
            nn.BatchNorm2d(128),
            nn.ReLU(),
            nn.MaxPool2d(2, 2),
            nn.Dropout2d(0.20)
        ),

        # Block 4: 4×4 → 2×2
        nn.Sequential(
            nn.Conv2d(
                128,
                128,
                kernel_size=3,
                padding=1,
                bias=False
            ),
            nn.BatchNorm2d(128),
            nn.ReLU(),
            nn.MaxPool2d(2, 2),
            nn.Dropout2d(0.25)
        ),

        # Block 5: 2×2 → 1×1
        nn.Sequential(
            nn.Conv2d(
                128,
                256,
                kernel_size=3,
                padding=1,
                bias=False

            nn.BatchNorm2d(256),
```

⟪box:코드 풀이⟫

성능을 높인 Deep CNN을 블록 단위로 정의합니다.
- `Conv2d(..., bias=False)` + `BatchNorm2d` — 배치마다 출력을 정규화해 학습을 안정시킵니다. BatchNorm이 편향 역할을 하므로 합성곱의 편향은 끕니다.
- 블록 5개를 거치며 `MaxPool2d`로 크기를 절반씩 줄이고(32 → 16 → 8 → 4 → 2 → 1) 채널은 32 → 64 → 128 → 256으로 늘립니다. 마지막에 256개 특징을 `Linear(256, 128)` → `Linear(128, 10)`으로 분류합니다.
- `Dropout2d` — 특징맵 채널을 통째로 무작위로 꺼서 과적합을 줄입니다. 깊은 블록일수록 비율을 높였고(0.10 → 0.30), 분류부에는 일반 `Dropout(0.5)`를 씁니다.

#### 14) Loss 함수 설정

| 개선 기법 | 역할 |
|---|---|
| 데이터 증강 | 다양한 위치와 방향의 입력 생성 |

#### 15) 학습 함수 정의

코드 박스: ch04_4_cifar10_deep_cnn_improvement_comparison.ipynb · 셀 17 · 미검증

```python
def train_one_epoch(
    model,
    data_loader,
    optimizer
):
    model.train()

    loss_sum = 0.0
    correct = 0
    total = 0

    for images, labels in data_loader:
        images = images.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()

        logits = model(images)

        loss = loss_function(
            logits,
            labels
        )

        loss.backward()
        optimizer.step()

        predictions = logits.argmax(
            dim=1
        )

        loss_sum += (
            loss.item()
            * images.size(0)
        )

        correct += (
            predictions == labels
        ).sum().item()

        total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )
```

```python
for epoch in range(
    1,
    NUMBER_OF_EPOCHS + 1
):
    train_loss, train_accuracy = train_one_epoch(
        deep_model,
        train_loader,
        optimizer
    )

    validation_loss, validation_accuracy = (
        evaluate_model(
            deep_model,
            validation_loader
        )
    )

    is_better = (
        validation_accuracy
        > best_validation_accuracy
        or (
            validation_accuracy
            == best_validation_accuracy
            and validation_loss
            < best_validation_loss
        )
    )

    if is_better:
        best_validation_accuracy = (
            validation_accuracy
        )

        best_validation_loss = (
            validation_loss
        )

        best_epoch = epoch

        best_model_state = copy.deepcopy(
            deep_model.state_dict()
        )

        epochs_without_improvement = 0

    else:
        epochs_without_improvement += 1

    scheduler.step(
        validation_loss
    )

    current_learning_rate = optimizer.param_groups[
        0
    ]["lr"]

    history["train_loss"].append(
        train_loss
    )

    history["train_accuracy"].append(
        train_accuracy
    )

    history["validation_loss"].append(
        validation_loss
    )

    history["validation_accuracy"].append(
        validation_accuracy
    )

    history["learning_rate"].append(
        current_learning_rate
    )

    print(
        f"Epoch {epoch:>2d}/{NUMBER_OF_EPOCHS} | "
        f"Train Loss {train_loss:.4f} | "
        f"Train Accuracy {train_accuracy:.4f} | "
        f"Validation Loss {validation_loss:.4f} | "
        f"Validation Accuracy {validation_accuracy:.4f} | "
        f"LR {current_learning_rate:.6f}"

    if (
        epochs_without_improvement
        >= EARLY_STOPPING_PATIENCE

            f"{EARLY_STOPPING_PATIENCE} Epoch 동안 "
```

- 개선 없음이 6 에폭에 이르면 조기 종료합니다.

#### 28) 예측 결과 수집 함수

혼동행렬과 오답 비교에서 모델을 반복 실행하지 않도록 테스트 결과를 한 번에 모읍니다.

코드 박스: ch04_4_cifar10_deep_cnn_improvement_comparison.ipynb · 셀 30 · 미검증

```python
def collect_predictions(
    model,
    data_loader
):
    model.eval()

    image_batches = []
    label_batches = []
    prediction_batches = []

    with torch.no_grad():
        for images, labels in data_loader:
            logits = model(
                images.to(device)
            )

            predictions = logits.argmax(
                dim=1
            ).cpu()

            image_batches.append(images)
            label_batches.append(labels)
            prediction_batches.append(
                predictions
            )

    return (
        torch.cat(image_batches),
        torch.cat(label_batches),
        torch.cat(prediction_batches)
    )
```

⟪box:코드 풀이⟫

모델로 데이터 전체를 예측해 이미지·정답·예측을 모아 돌려주는 함수입니다.
