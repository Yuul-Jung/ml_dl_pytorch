#### 8) 학습 함수 정의

같은 절차이므로 설명은 줄이고 함수로 정리합니다.

```text
학습
→ train()
→ 순전파
→ 손실
→ 역전파
→ 가중치 갱신

평가
→ eval()
→ no_grad()
→ 손실과 정확도 계산
```

파일명: `ch03_1_fashion_mnist_mlp_training_evaluation.ipynb` · 코드 셀 10 · Python · 원본 실행 기록 포함

```python
def train_one_epoch(model, data_loader):
    model.train()

    loss_sum = 0.0
    correct = 0
    total = 0

    for images, labels in data_loader:
        images = images.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()

        logits = model(images)

        loss = loss_function(
            logits,
            labels
        )

        loss.backward()
        optimizer.step()

        predictions = logits.argmax(dim=1)

        loss_sum += (
            loss.item() * images.size(0)
        )

        correct += (
            predictions == labels
        ).sum().item()

        total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )
```

#### 9) 평가 함수 정의

파일명: `ch03_1_fashion_mnist_mlp_training_evaluation.ipynb` · 코드 셀 11 · Python · 원본 실행 기록 포함

```python
def evaluate_model(model, data_loader):
    model.eval()

    loss_sum = 0.0
    correct = 0
    total = 0

    with torch.no_grad():
        for images, labels in data_loader:
            images = images.to(device)
            labels = labels.to(device)

            logits = model(images)

            loss = loss_function(
                logits,
                labels
            )

            predictions = logits.argmax(dim=1)

            loss_sum += (
                loss.item() * images.size(0)
            )

            correct += (
                predictions == labels
            ).sum().item()

            total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )
```

#### 11) 모델 학습

파일명: `ch03_1_fashion_mnist_mlp_training_evaluation.ipynb` · 코드 셀 13 · Python · 원본 실행 기록 포함

```python
for epoch in range(
    1,
    NUMBER_OF_EPOCHS + 1
):
    train_loss, train_accuracy = train_one_epoch(
        model,
        train_loader
    )

    validation_loss, validation_accuracy = (
        evaluate_model(
            model,
            validation_loader
        )
    )

    history["train_loss"].append(
        train_loss
    )

    history["train_accuracy"].append(
        train_accuracy
    )

    history["validation_loss"].append(
        validation_loss
    )

    history["validation_accuracy"].append(
        validation_accuracy
    )

    is_better = (
        validation_accuracy
        > best_validation_accuracy
        or (
            validation_accuracy
            == best_validation_accuracy
            and validation_loss
            < best_validation_loss
        )
    )

    if is_better:
        best_validation_accuracy = (
            validation_accuracy
        )

        best_validation_loss = (
            validation_loss
        )

        best_epoch = epoch

        best_model_state = copy.deepcopy(
            model.state_dict()
        )

    print(
        f"Epoch {epoch:>2d}/{NUMBER_OF_EPOCHS} | "
        f"Train Loss {train_loss:.4f} | "
        f"Train Accuracy {train_accuracy:.4f} | "
        f"Validation Loss {validation_loss:.4f} | "
        f"Validation Accuracy {validation_accuracy:.4f}"
    )
```

#### 24) 이미지 위치를 2픽셀 이동하기

사람에게는 같은 의류이지만, 이미지의 위치가 달라지면 MLP에는 다른 픽셀 위치가 활성화됩니다.

```text
원본 이미지
→ 오른쪽으로 2픽셀 이동
→ 새로 생긴 왼쪽 영역은 0으로 채움
```

파일명: `ch03_1_fashion_mnist_mlp_training_evaluation.ipynb` · 코드 셀 26 · Python · 원본 실행 기록 포함

```python
def shift_right(images, pixels=2):
    shifted = torch.zeros_like(
        images
    )

    shifted[
        :,
        :,
        :,
        pixels:
    ] = images[
        :,
        :,
        :,
        :-pixels
    ]

    return shifted
```

작은 위치 변화에도 결과가 크게 달라진다면 MLP가 위치 변화에 민감하다는 의미입니다.

파일명: `ch03_1_fashion_mnist_mlp_training_evaluation.ipynb` · 코드 셀 28 · Python · 원본 실행 기록 포함

```python
model.eval()

shifted_correct = 0

prediction_changed = 0

total = 0

with torch.no_grad():
    for images, labels in test_loader:
        images = images.to(device)
        labels = labels.to(device)

        shifted_images = shift_right(
            images,
            pixels=2
        )

        original_predictions = model(
            images
        ).argmax(dim=1)

        shifted_predictions = model(
            shifted_images
        ).argmax(dim=1)

        shifted_correct += (
            shifted_predictions == labels
        ).sum().item()

        prediction_changed += (
            shifted_predictions
            != original_predictions
        ).sum().item()

        total += labels.size(0)

shifted_accuracy = (
    shifted_correct / total
)

prediction_change_rate = (
    prediction_changed / total
)

accuracy_drop = (
    test_accuracy - shifted_accuracy
)

print(f"원본 정확도: {test_accuracy:.4f}")
```

 모델을 다시 학습하지 않습니다.

→ Fashion-MNIST 테스트 데이터 준비
→ 이미지 한 장 선택
→ Batch 차원 추가
→ 로짓 계산
→ Softmax 확률 계산
→ 예측 결과 확인

#### 6) Batch 차원 추가

테스트 이미지 한 장의 shape:

```text
[1, 28, 28]
```

모델은 여러 이미지를 한 번에 받는 형태를 사용하므로 Batch(배치, 데이터 묶음) 차원을 추가합니다.

```text
[1, 28, 28]
→ unsqueeze(0)
→ [1, 1, 28, 28]
```

맨 앞의 `1`은 이미지가 한 장이라는 뜻입니다.

파일명: `ch03_2_fashion_mnist_simple_prediction.ipynb` · 코드 셀 8 · Python · 원본 실행 기록 포함

```python
input_image = image.unsqueeze(
    0
).to(device)

print(

    input_image.shape
)
```

#### 7) 데이터 구조 확인

예측 순서:

```text
이미지
→ MLP
→ 의류별 로짓 10개
→ Softmax
→ 의류별 확률
→ argmax
→ 최종 예측
```

예측에서는 기울기가 필요하지 않으므로 `torch.no_grad()`를 사용합니다.

파일명: `ch03_2_fashion_mnist_simple_prediction.ipynb` · 코드 셀 9 · Python · 원본 실행 기록 포함

```python
with torch.no_grad():
    logits = model(
        input_image
    )

    probabilities = torch.softmax(
        logits,
        dim=1
    )

    predicted_label = logits.argmax(
        dim=1
    ).item()

    predicted_probability = probabilities[
        0,
        predicted_label
    ].item()

print("로짓 shape:", logits.shape)

print(
    "실제 의류:",
    class_names_ko[true_label]
)

print(
    "예측 의류:",
    class_names_ko[predicted_label]
)

print(
    f"예측 확률: "
    f"{predicted_probability * 100:.2f}%"
)

print(
    "예측 결과:",
    "정답" if predicted_label == true_label else "오답"
)
```

#### 11) Tensor 만들기와 구조 확인

테스트 데이터의 앞부분 8개를 한 번에 예측합니다.

한 장을 예측할 때와 차이는 Batch 크기뿐입니다.

```text
이미지 한 장
→ [1, 1, 28, 28]

이미지 여덟 장
→ [8, 1, 28, 28]
```

파일명: `ch03_2_fashion_mnist_simple_prediction.ipynb` · 코드 셀 13 · Python · 원본 실행 기록 포함

```python
images = torch.stack(
    [
        test_dataset[index][0]
        for index in range(8)
    ]
)

labels = torch.tensor(
    [
        test_dataset[index][1]
        for index in range(8)
    ]
)

with torch.no_grad():
    batch_logits = model(
        images.to(device)
    )

    batch_probabilities = torch.softmax(
        batch_logits,
        dim=1
    )

    batch_confidences, batch_predictions = (
        batch_probabilities.max(dim=1)
    )

batch_predictions = batch_predictions.cpu()

batch_confidences = batch_confidences.cpu()
```

- 여러 이미지 예측도 한 장 예측과 같은 흐름으로 수행합니다.
