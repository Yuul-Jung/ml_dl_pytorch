#### 8) 학습 함수 정의

같은 절차이므로 설명은 줄이고 함수로 정리합니다.

```text
학습
→ train()
→ 순전파
→ 손실
→ 역전파
→ 가중치 갱신

평가
→ eval()
→ no_grad()
→ 손실과 정확도 계산
```

코드 박스: ch03_1_fashion_mnist_mlp_training_evaluation.ipynb · 셀 10 · 미검증

```python
def train_one_epoch(model, data_loader):
    model.train()

    loss_sum = 0.0
    correct = 0
    total = 0

    for images, labels in data_loader:
        images = images.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()

        logits = model(images)

        loss = loss_function(
            logits,
            labels
        )

        loss.backward()
        optimizer.step()

        predictions = logits.argmax(dim=1)

        loss_sum += (
            loss.item() * images.size(0)
        )

        correct += (
            predictions == labels
        ).sum().item()

        total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )
```

⟪box:코드 풀이⟫

한 에폭 동안 모든 배치를 학습하고 평균 손실과 정확도를 돌려주는 함수입니다.

#### 9) 평가 함수 정의

코드 박스: ch03_1_fashion_mnist_mlp_training_evaluation.ipynb · 셀 11 · 미검증

```python
def evaluate_model(model, data_loader):
    model.eval()

    loss_sum = 0.0
    correct = 0
    total = 0

    with torch.no_grad():
        for images, labels in data_loader:
            images = images.to(device)
            labels = labels.to(device)

            logits = model(images)

            loss = loss_function(
                logits,
                labels
            )

            predictions = logits.argmax(dim=1)

            loss_sum += (
                loss.item() * images.size(0)
            )

            correct += (
                predictions == labels
            ).sum().item()

            total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )
```

모델과 DataLoader를 받아 기울기 없이 평균 손실과 정확도를 계산하는 평가 함수입니다.

```python
    1,
    NUMBER_OF_EPOCHS + 1
):
    train_loss, train_accuracy = train_one_epoch(
        model,
        train_loader
    )

    validation_loss, validation_accuracy = (
        evaluate_model(
            model,
            validation_loader
        )
    )

    history["train_loss"].append(

        validation_loss

    history["validation_accuracy"].append(

    )

    is_better = (
        validation_accuracy
        > best_validation_accuracy
        or (
            validation_accuracy
            == best_validation_accuracy
            and validation_loss
            < best_validation_loss
        )
    )

    if is_better:
        best_validation_accuracy = (
            validation_accuracy
        )

        best_validation_loss = (
            validation_loss
        )

        best_model_state = copy.deepcopy(
            model.state_dict()
        )

        f"Train Loss {train_loss:.4f} | "
        f"Train Accuracy {train_accuracy:.4f} | "
```

#### 24) 이미지 위치를 2픽셀 이동하기

사람에게는 같은 의류이지만, 이미지의 위치가 달라지면 MLP에는 다른 픽셀 위치가 활성화됩니다.

```text
원본 이미지
→ 오른쪽으로 2픽셀 이동
→ 새로 생긴 왼쪽 영역은 0으로 채움
```

코드 박스: ch03_1_fashion_mnist_mlp_training_evaluation.ipynb · 셀 26 · 미검증

```python
def shift_right(images, pixels=2):
    shifted = torch.zeros_like(
        images
    )

    shifted[
        :,
        :,
        :,
        pixels:
    ] = images[
        :,
        :,
        :,
        :-pixels
    ]

    return shifted
```

⟪box:코드 풀이⟫

이미지를 오른쪽으로 2픽셀 미는 함수입니다.
- `[:, :, :, pixels:] = [:, :, :, :-pixels]` — 마지막 차원(가로)에서 왼쪽 부분을 오른쪽으로 옮겨 붙이고, 빈 왼쪽 두 열은 0(검은색)으로 둡니다.

⟪/box⟫

#### 26) 이동 이미지로 테스트

- 원본 정확도
- 2픽셀 이동 정확도
- 정확도 감소
- 예측 클래스 변경 비율

작은 위치 변화에도 결과가 크게 달라진다면 MLP가 위치 변화에 민감하다는 의미입니다.

코드 박스: ch03_1_fashion_mnist_mlp_training_evaluation.ipynb · 셀 28 · 미검증

```python
model.eval()

shifted_correct = 0

prediction_changed = 0

total = 0

with torch.no_grad():
    for images, labels in test_loader:
        images = images.to(device)
        labels = labels.to(device)

        shifted_images = shift_right(
            images,
            pixels=2
        )

        original_predictions = model(
            images
        ).argmax(dim=1)

        shifted_predictions = model(
            shifted_images
        ).argmax(dim=1)

        shifted_correct += (
            shifted_predictions == labels
        ).sum().item()

        prediction_changed += (
            shifted_predictions
            != original_predictions
        ).sum().item()

        total += labels.size(0)

shifted_accuracy = (
    shifted_correct / total
)

prediction_change_rate = (
    prediction_changed / total
)

accuracy_drop = (
    test_accuracy - shifted_accuracy
)

print(f"원본 정확도: {test_accuracy:.4f}")
```

실행 결과: 셀 28 · 원본 실행 기록


- MLP는 이미지를 784개 숫자로 펼쳐 **픽셀 위치별로** 가중치를 배우기 때문에, 조금만 움직여도 예측이 바뀔 수 있습니다. 다음 장의 CNN이 이 문제를 줄입니다.

#### 6) Batch 차원 추가

테스트 이미지 한 장의 shape:


#### 7) 이미지 한 장 예측

예측 순서:

```text
이미지
→ MLP
→ 의류별 로짓 10개
→ Softmax
→ 의류별 확률
→ argmax
→ 최종 예측
```

예측에서는 기울기가 필요하지 않으므로 `torch.no_grad()`를 사용합니다.

코드 박스: ch03_2_fashion_mnist_simple_prediction.ipynb · 셀 9 · 미검증

```python
with torch.no_grad():
    logits = model(
        input_image
    )

    probabilities = torch.softmax(
        logits,
        dim=1
    )

    predicted_label = logits.argmax(
        dim=1
    ).item()

    predicted_probability = probabilities[
        0,
        predicted_label
    ].item()

print("로짓 shape:", logits.shape)

print(
    "실제 의류:",
    class_names_ko[true_label]
)

print(
    "예측 의류:",
    class_names_ko[predicted_label]
)

print(
    f"예측 확률: "
    f"{predicted_probability * 100:.2f}%"
)

print(
    "예측 결과:",
    "정답" if predicted_label == true_label else "오답"
)
```

⟪box:코드 풀이⟫

로짓 → Softmax 확률 → 가장 높은 클래스와 그 확률을 구하고, 정답인지 출력합니다.

#### 11) 8장을 묶어 한 번에 예측

테스트 데이터의 앞부분 8개를 한 번에 예측합니다.

한 장을 예측할 때와 차이는 Batch 크기뿐입니다.

```text
이미지 한 장
→ [1, 1, 28, 28]

이미지 여덟 장
→ [8, 1, 28, 28]
```

코드 박스: ch03_2_fashion_mnist_simple_prediction.ipynb · 셀 13 · 미검증

```python
images = torch.stack(
    [
        test_dataset[index][0]
        for index in range(8)
    ]
)

labels = torch.tensor(
    [
        test_dataset[index][1]
        for index in range(8)
    ]
)

with torch.no_grad():
    batch_logits = model(
        images.to(device)
    )

    batch_probabilities = torch.softmax(
        batch_logits,
        dim=1
    )

    batch_confidences, batch_predictions = (
        batch_probabilities.max(dim=1)
    )

batch_predictions = batch_predictions.cpu()

batch_confidences = batch_confidences.cpu()
```

⟪box:코드 풀이⟫

테스트 이미지 8장을 `torch.stack`으로 묶어 한 번에 예측합니다. 여러 장을 배치로 묶으면 한 장씩 예측하는 것보다 빠릅니다.

```python
for index in range(8):
```
