## 배경 개념

Object Detection(객체 탐지) 모델 YOLO로 가는 첫 단계는 이미지 안에 객체가 **하나**일 때 그 위치를 맞히는 Single Object Localization(단일 객체 위치 추정)입니다. CNN이 클래스 Logit과 함께 Bounding Box(경계 상자) 좌표 4개를 출력하고, 분류 손실과 좌표 회귀 손실을 함께 학습합니다.

### 개요

기존 CNN(Classification, 분류)은 **이미지가 무엇인지** 예측한다.

이번 단계에서는 CNN에 Bounding Box(바운딩 박스, 객체 위치) 예측을 추가하여 다음 두 가지를 동시에 학습한다.

```text
① What?  → Class
② Where? → Bounding Box
```

전체 학습 흐름:

```text
CNN Classification
        ↓
Single Object Localization
        ↓
Object Detection
        ↓
YOLO
```

이번 노트북은 학습 흐름이 숨겨지지 않도록 **데이터 준비 → 모델 → Loss → 학습 → 검증 → 예측**을 위에서 아래로 직접 실행한다.

```python
# 04. Single Object Localization용 Dataset 정의

class LocalizedMNIST(Dataset):

    def __init__(
        self,
        base_dataset,
        canvas_size=64,
        random_position=True
    ):
        self.base_dataset = base_dataset
        self.canvas_size = canvas_size
        self.random_position = random_position
        self.to_tensor = transforms.ToTensor()

    def __len__(self):
        return len(self.base_dataset)

    def __getitem__(self, idx):

        image, label = self.base_dataset[idx]

        # PIL Image → Tensor
        digit = self.to_tensor(image)

        # 실제 숫자가 존재하는 픽셀 영역 찾기
        mask = digit[0] > 0.05
        ys, xs = torch.where(mask)

        y1 = ys.min().item()
        y2 = ys.max().item() + 1
        x1 = xs.min().item()
        x2 = xs.max().item() + 1

        # 숫자 주변의 빈 공간 제거
        digit = digit[:, y1:y2, x1:x2]

        h = digit.shape[1]
        w = digit.shape[2]

        max_x = self.canvas_size - w
        max_y = self.canvas_size - h

        # Train: 숫자 위치를 계속 변경
        if self.random_position:
            x0 = random.randint(0, max_x)
            y0 = random.randint(0, max_y)

        # Validation: 같은 idx는 항상 같은 위치
        else:
            generator = torch.Generator()
            generator.manual_seed(idx + 1000)

            x0 = torch.randint(
                0, max_x + 1, (1,),
                generator=generator
            ).item()

            y0 = torch.randint(
                0, max_y + 1, (1,),
                generator=generator
            ).item()

        # 64 × 64 검은 배경
        canvas = torch.zeros(
            1,
            self.canvas_size,
            self.canvas_size
        )

        # 숫자를 임의 위치에 삽입
        canvas[:, y0:y0 + h, x0:x0 + w] = digit

        # Bounding Box 중심 좌표와 크기 정규화
        cx = (x0 + w / 2) / self.canvas_size
        cy = (y0 + h / 2) / self.canvas_size
        bw = w / self.canvas_size
        bh = h / self.canvas_size

        bbox = torch.tensor(
            [cx, cy, bw, bh],
            dtype=torch.float32
        )

        return canvas, label, bbox
```

#### 코드 풀이 — Dataset에서 무엇이 달라졌는가

기존 CNN Dataset:

```text
Image + Label
```

이번 Localization Dataset:

```text
Image + Label + Bounding Box
```

핵심은 마지막 반환값이다.

```python
return canvas, label, bbox
```

`bbox`는 다음 순서로 저장한다.

```text
[cx, cy, w, h]

cx → 객체 중심의 x 위치
cy → 객체 중심의 y 위치
w  → 객체의 폭
h  → 객체의 높이
```

모든 값은 `0 ~ 1` 범위로 정규화한다. 이 형식은 이후 YOLO의 Bounding Box 개념과 직접 연결된다.

```python
# 08. Bounding Box 표시 함수

def draw_box(
    ax,
    box,
    canvas_size,
    label,
    edgecolor,
    linestyle="-"
):

    cx, cy, w, h = box.tolist()

    # 0 ~ 1 정규화 좌표 → Pixel 좌표
    cx *= canvas_size
    cy *= canvas_size
    w *= canvas_size
    h *= canvas_size

    # 중심 좌표 → 왼쪽 위 좌표
    x1 = cx - w / 2
    y1 = cy - h / 2

    rectangle = Rectangle(
        (x1, y1),
        w,
        h,
        fill=False,
        edgecolor=edgecolor,
        linewidth=2,
        linestyle=linestyle
    )

    ax.add_patch(rectangle)

    ax.text(
        x1,
        max(y1 - 1.5, 1),
        label,
        color=edgecolor,
        fontsize=9,
        bbox={
            "facecolor": "black",
            "alpha": 0.5,
            "pad": 1
        }
    )
```

```python
# 10. CNN + Class Head + Box Head 모델 정의

class LocalizationCNN(nn.Module):

    def __init__(self):
        super().__init__()

        # CNN Feature Extraction
        self.features = nn.Sequential(

            nn.Conv2d(
                1, 16,
                kernel_size=3,
                padding=1
            ),
            nn.ReLU(),
            nn.MaxPool2d(
                kernel_size=2,
                stride=2
            ),

            nn.Conv2d(
                16, 32,
                kernel_size=3,
                padding=1
            ),
            nn.ReLU(),
            nn.MaxPool2d(
                kernel_size=2,
                stride=2
            ),

            nn.Conv2d(
                32, 64,
                kernel_size=3,
                padding=1
            ),
            nn.ReLU(),
            nn.MaxPool2d(
                kernel_size=2,
                stride=2
            )
        )

        # 공통 Feature
        self.shared = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 8 * 8, 128),
            nn.ReLU()
        )

        # 무엇인가? → 숫자 0 ~ 9
        self.class_head = nn.Linear(
            128,
            10
        )

        # 어디에 있는가? → cx, cy, w, h
        self.box_head = nn.Sequential(
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 4),
            nn.Sigmoid()
        )

    def forward(self, x):

        x = self.features(x)
        feature = self.shared(x)

        class_logits = self.class_head(
            feature
        )

        pred_boxes = self.box_head(
            feature
        )

        return class_logits, pred_boxes
```

#### 코드 풀이 — 기존 CNN에서 무엇이 추가되었는가

기존 CNN:

```text
Image
 ↓
CNN
 ↓
Class
```

이번 모델:

```text
                CNN
                 ↓
          Shared Feature
                 │
        ┌────────┴────────┐
        ↓                 ↓
   Class Head          Box Head
        ↓                 ↓
     숫자 0~9        cx, cy, w, h
```

핵심은 **CNN으로 추출한 공통 Feature를 두 개의 출력 Head가 함께 사용한다는 것**이다.

- `class_head` → 무엇인가?
- `box_head` → 어디에 있는가?

`box_head` 마지막의 `Sigmoid()`는 예측 좌표를 `0 ~ 1` 범위로 제한한다.

### 11. CNN Feature Map 크기 변화

```text
입력       → [N, 1, 64, 64]
Conv/Pool  → [N, 16, 32, 32]
Conv/Pool  → [N, 32, 16, 16]
Conv/Pool  → [N, 64, 8, 8]
```

마지막 Feature Map을 Flatten하면:

```text
64 × 8 × 8
→ 4096개 Feature
```

가 되고, 이를 `128`개의 공통 Feature로 줄인 뒤 Class Head와 Box Head로 전달한다.

#### 코드 풀이 — 왜 Loss가 두 개인가

이번 모델은 두 문제를 동시에 푼다.

```text
Class
→ Classification
→ CrossEntropyLoss
```

```text
Bounding Box
→ Regression
→ SmoothL1Loss
```

학습할 때 두 Loss를 하나로 합친다.

```text
Total Loss
→ Class Loss + 5 × Box Loss
```

`BOX_WEIGHT = 5.0`은 위치 Loss의 영향도를 조절하기 위한 초기값이다.

파일명: `ch07_1_cnn_to_yolo_single_object_localization.ipynb` · 코드 셀 13 · Python · 원본 실행 기록 포함

```python
# 14. Bounding Box 좌표 형식 변환
# [cx, cy, w, h] → [x1, y1, x2, y2]

def xywh_to_xyxy(boxes):

    cx = boxes[:, 0]
    cy = boxes[:, 1]
    w = boxes[:, 2]
    h = boxes[:, 3]

    x1 = cx - w / 2
    y1 = cy - h / 2
    x2 = cx + w / 2
    y2 = cy + h / 2

    return torch.stack(
        [x1, y1, x2, y2],
        dim=1
    )
```

#### 코드 풀이

학습에서는 중심 좌표 형식인 `[cx, cy, w, h]`를 사용한다.

IoU 계산에서는 다음 형식이 편하다.

```text
[x1, y1, x2, y2]

x1, y1 → 왼쪽 위
x2, y2 → 오른쪽 아래
```

파일명: `ch07_1_cnn_to_yolo_single_object_localization.ipynb` · 코드 셀 14 · Python · 원본 실행 기록 포함

```python
# 15. IoU 계산 함수

def calculate_iou(
    pred_boxes,
    target_boxes
):

    pred = xywh_to_xyxy(
        pred_boxes
    )

    target = xywh_to_xyxy(
        target_boxes
    )

    inter_x1 = torch.maximum(
        pred[:, 0], target[:, 0]
    )
    inter_y1 = torch.maximum(
        pred[:, 1], target[:, 1]
    )
    inter_x2 = torch.minimum(
        pred[:, 2], target[:, 2]
    )
    inter_y2 = torch.minimum(
        pred[:, 3], target[:, 3]
    )

    inter_w = (
        inter_x2 - inter_x1
    ).clamp(min=0)

    inter_h = (
        inter_y2 - inter_y1
    ).clamp(min=0)

    intersection = inter_w * inter_h

    pred_area = (
        (pred[:, 2] - pred[:, 0]).clamp(min=0)
        *
        (pred[:, 3] - pred[:, 1]).clamp(min=0)
    )

    target_area = (
        (target[:, 2] - target[:, 0]).clamp(min=0)
        *
        (target[:, 3] - target[:, 1]).clamp(min=0)
    )

    union = (
        pred_area
        + target_area
        - intersection
    )

    iou = intersection / (
        union + 1e-6
    )

    return iou
```

#### 코드 풀이 — IoU

IoU(Intersection over Union, 두 박스의 겹침 비율)는 예측 Box가 정답 Box와 얼마나 잘 겹치는지 평가한다.

```text
          겹친 면적
IoU = ───────────────
       두 Box의 합집합
```

```text
IoU → 1 : 거의 정확하게 겹침
IoU → 0 : 거의 겹치지 않음
```

기존 CNN에서는 Accuracy를 주로 확인했지만, Localization에서는 **Accuracy + IoU**를 함께 본다.

```python
EPOCHS = 5

for epoch in range(EPOCHS):

    model.train()

    train_loss_sum = 0.0
    train_class_loss_sum = 0.0
    train_box_loss_sum = 0.0

    train_correct = 0
    train_total = 0

    for images, labels, boxes in train_loader:

        images = images.to(device)
        labels = labels.to(device)
        boxes = boxes.to(device)

        # 이전 Gradient 초기화
        optimizer.zero_grad()

        # Forward
        class_logits, pred_boxes = model(
            images
        )

        # 무엇인가? → Class Loss
        class_loss = class_loss_function(
            class_logits,
            labels
        )

        # 어디인가? → Box Loss
        box_loss = box_loss_function(
            pred_boxes,
            boxes
        )

        # 두 Loss를 하나로 결합
        loss = (
            class_loss
            + BOX_WEIGHT * box_loss
        )

        # Backpropagation
        loss.backward()

        # Weight Update
        optimizer.step()

        batch_size = images.size(0)

        train_loss_sum += (
            loss.item() * batch_size
        )

        train_class_loss_sum += (
            class_loss.item() * batch_size
        )

        train_box_loss_sum += (
            box_loss.item() * batch_size
        )

        predictions = class_logits.argmax(
            dim=1
        )

        train_correct += (
            predictions == labels
        ).sum().item()

        train_total += batch_size

    train_loss = train_loss_sum / train_total
    train_class_loss = train_class_loss_sum / train_total
    train_box_loss = train_box_loss_sum / train_total
    train_accuracy = train_correct / train_total

    print(
        f"Epoch {epoch + 1}/{EPOCHS} | "
        f"Total Loss: {train_loss:.4f} | "
        f"Class Loss: {train_class_loss:.4f} | "
        f"Box Loss: {train_box_loss:.4f} | "
```

```python
# 04. Single Object Localization용 Dataset

class LocalizedMNIST(Dataset):

    def __init__(
        self,
        base_dataset,
        canvas_size=64,
        random_position=True
    ):
        self.base_dataset = base_dataset
        self.canvas_size = canvas_size
        self.random_position = random_position
        self.to_tensor = transforms.ToTensor()

    def __len__(self):
        return len(self.base_dataset)

    def __getitem__(self, idx):
        image, label = self.base_dataset[idx]
        digit = self.to_tensor(image)

        # 실제 숫자가 있는 픽셀 영역 찾기
        mask = digit[0] > 0.05
        ys, xs = torch.where(mask)

        y1 = ys.min().item()
        y2 = ys.max().item() + 1
        x1 = xs.min().item()
        x2 = xs.max().item() + 1

        # 숫자 주변 빈 공간 제거
        digit = digit[:, y1:y2, x1:x2]
        h = digit.shape[1]
        w = digit.shape[2]

        max_x = self.canvas_size - w
        max_y = self.canvas_size - h

        if self.random_position:
            x0 = random.randint(0, max_x)
            y0 = random.randint(0, max_y)
        else:
            # Validation은 같은 idx에서 항상 같은 위치
            generator = torch.Generator()
            generator.manual_seed(idx + 1000)

            x0 = torch.randint(
                0, max_x + 1, (1,), generator=generator
            ).item()

            y0 = torch.randint(
                0, max_y + 1, (1,), generator=generator
            ).item()

        # 64×64 캔버스 생성 후 숫자 삽입
        canvas = torch.zeros(
            1, self.canvas_size, self.canvas_size
        )

        canvas[:, y0:y0+h, x0:x0+w] = digit

        # YOLO와 연결되는 중심좌표 기반 Bounding Box
        cx = (x0 + w / 2) / self.canvas_size
        cy = (y0 + h / 2) / self.canvas_size
        bw = w / self.canvas_size
        bh = h / self.canvas_size

        bbox = torch.tensor(
            [cx, cy, bw, bh],
            dtype=torch.float32
        )

        return canvas, label, bbox
```

```python
# 05. DataLoader 생성 함수

def create_dataloaders(
    mnist_train,
    mnist_test,
    batch_size=64,
    train_size=20000,
    val_size=5000,
    canvas_size=64,
    seed=42
):
    generator = torch.Generator().manual_seed(seed)

    train_indices = torch.randperm(
        len(mnist_train), generator=generator
    )[:train_size]

    val_indices = torch.arange(
        min(val_size, len(mnist_test))
    )

    train_base = Subset(mnist_train, train_indices)
    val_base = Subset(mnist_test, val_indices)

    train_dataset = LocalizedMNIST(
        train_base,
        canvas_size=canvas_size,
        random_position=True
    )

    val_dataset = LocalizedMNIST(
        val_base,
        canvas_size=canvas_size,
        random_position=False
    )

    train_loader = DataLoader(
        train_dataset,
        batch_size=batch_size,
        shuffle=True
    )

    val_loader = DataLoader(
        val_dataset,
        batch_size=batch_size,
        shuffle=False
    )

    return train_loader, val_loader
```

```python
# 07. Localization CNN

class LocalizationCNN(nn.Module):

    def __init__(self):
        super().__init__()

        self.features = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),

            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),

            nn.Conv2d(32, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2)
        )

        self.shared = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 8 * 8, 128),
            nn.ReLU()
        )

        # 무엇인가?
        self.class_head = nn.Linear(128, 10)

        # 어디에 있는가?
        self.box_head = nn.Sequential(
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 4),
            nn.Sigmoid()
        )

    def forward(self, x):
        x = self.features(x)
        feature = self.shared(x)

        class_logits = self.class_head(feature)
        pred_boxes = self.box_head(feature)

        return class_logits, pred_boxes
```

### 5. Bounding Box 변환과 IoU

모델 출력 `[cx, cy, w, h]`를 IoU 계산용 `[x1, y1, x2, y2]`로 변환한다.

파일명: `ch07_2_cnn_to_yolo_single_object_localization_main.ipynb` · 코드 셀 8 · Python · 원본 실행 기록 포함

```python
# 08. Bounding Box 변환 + IoU

def xywh_to_xyxy(boxes):
    cx = boxes[:, 0]
    cy = boxes[:, 1]
    w = boxes[:, 2]
    h = boxes[:, 3]

    x1 = cx - w / 2
    y1 = cy - h / 2
    x2 = cx + w / 2
    y2 = cy + h / 2

    return torch.stack(
        [x1, y1, x2, y2], dim=1
    )


def calculate_iou(pred_boxes, target_boxes):
    pred = xywh_to_xyxy(pred_boxes)
    target = xywh_to_xyxy(target_boxes)

    inter_x1 = torch.maximum(pred[:, 0], target[:, 0])
    inter_y1 = torch.maximum(pred[:, 1], target[:, 1])
    inter_x2 = torch.minimum(pred[:, 2], target[:, 2])
    inter_y2 = torch.minimum(pred[:, 3], target[:, 3])

    inter_w = (inter_x2 - inter_x1).clamp(min=0)
    inter_h = (inter_y2 - inter_y1).clamp(min=0)
    intersection = inter_w * inter_h

    pred_area = (
        (pred[:, 2] - pred[:, 0]).clamp(min=0)
        * (pred[:, 3] - pred[:, 1]).clamp(min=0)
    )

    target_area = (
        (target[:, 2] - target[:, 0]).clamp(min=0)
        * (target[:, 3] - target[:, 1]).clamp(min=0)
    )

    union = pred_area + target_area - intersection

    return intersection / (union + 1e-6)
```

### 6. Loss Function과 Optimizer

```text
Class → CrossEntropyLoss
Box   → SmoothL1Loss

Total Loss
→ Class Loss + BOX_WEIGHT × Box Loss
```

파일명: `ch07_2_cnn_to_yolo_single_object_localization_main.ipynb` · 코드 셀 9 · Python · 원본 실행 기록 포함

```python
# 09. 학습 구성요소 생성 함수

def create_training_components(
    model,
    learning_rate=0.001
):
    class_loss_function = nn.CrossEntropyLoss()
    box_loss_function = nn.SmoothL1Loss()

    optimizer = torch.optim.Adam(
        model.parameters(),
        lr=learning_rate
    )

    return (
        class_loss_function,
        box_loss_function,
        optimizer
    )
```

### 7. 학습 함수

`train_one_epoch()`는 한 Epoch만 담당하고, `train_model()`은 Epoch 반복만 관리한다.

파일명: `ch07_2_cnn_to_yolo_single_object_localization_main.ipynb` · 코드 셀 10 · Python · 원본 실행 기록 포함

```python
# 10. 한 Epoch 학습 함수

def train_one_epoch(
    model,
    data_loader,
    class_loss_function,
    box_loss_function,
    optimizer,
    device,
    box_weight=5.0
):
    model.train()

    loss_sum = 0.0
    class_loss_sum = 0.0
    box_loss_sum = 0.0
    correct = 0
    total = 0

    for images, labels, boxes in data_loader:
        images = images.to(device)
        labels = labels.to(device)
        boxes = boxes.to(device)

        optimizer.zero_grad()

        class_logits, pred_boxes = model(images)

        class_loss = class_loss_function(
            class_logits, labels
        )

        box_loss = box_loss_function(
            pred_boxes, boxes
        )

        loss = class_loss + box_weight * box_loss

        loss.backward()
        optimizer.step()

        batch_size = images.size(0)

        loss_sum += loss.item() * batch_size
        class_loss_sum += class_loss.item() * batch_size
        box_loss_sum += box_loss.item() * batch_size

        predictions = class_logits.argmax(dim=1)
        correct += (predictions == labels).sum().item()
        total += batch_size

    return {
        "loss": loss_sum / total,
        "class_loss": class_loss_sum / total,
        "box_loss": box_loss_sum / total,
        "accuracy": correct / total
    }


def train_model(
    model,
    train_loader,
    class_loss_function,
    box_loss_function,
    optimizer,
    device,
    epochs=5,
    box_weight=5.0
):
    history = []

    for epoch in range(epochs):
        metrics = train_one_epoch(
            model,
            train_loader,
            class_loss_function,
            box_loss_function,
            optimizer,
            device,
            box_weight
        )

        history.append(metrics)

        print(
            f"Epoch {epoch + 1}/{epochs} | "
            f"Total Loss: {metrics['loss']:.4f} | "
            f"Class Loss: {metrics['class_loss']:.4f} | "
            f"Box Loss: {metrics['box_loss']:.4f} | "
            f"Accuracy: {metrics['accuracy']:.4f}"
        )

    return history
```

### 8. Validation 함수

Classification은 Accuracy, 위치는 Mean IoU로 평가한다.

파일명: `ch07_2_cnn_to_yolo_single_object_localization_main.ipynb` · 코드 셀 11 · Python · 원본 실행 기록 포함

```python
# 11. Validation 함수

def validate_model(model, data_loader, device):
    model.eval()

    correct = 0
    total = 0
    iou_sum = 0.0

    with torch.no_grad():
        for images, labels, boxes in data_loader:
            images = images.to(device)
            labels = labels.to(device)
            boxes = boxes.to(device)

            class_logits, pred_boxes = model(images)
            predictions = class_logits.argmax(dim=1)

            correct += (predictions == labels).sum().item()
            total += labels.size(0)

            iou = calculate_iou(pred_boxes, boxes)
            iou_sum += iou.sum().item()

    return {
        "accuracy": correct / total,
        "mean_iou": iou_sum / total
    }
```
