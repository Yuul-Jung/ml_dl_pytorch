## 배경 개념

객체 탐지 모델 YOLO(You Only Look Once)로 가는 첫 단계는 이미지에 물체가 **하나**일 때 그 위치를 맞히는 단일 객체 위치 추정(Single Object Localization)입니다. CNN이 클래스 로짓과 함께 상자(Bounding Box) 좌표 4개를 내고, 분류 손실과 좌표 회귀 손실을 함께 줄이도록 학습합니다.

예측 상자와 정답 상자가 얼마나 겹치는지는 IoU(Intersection over Union, 겹친 넓이 ÷ 합친 넓이)로 평가합니다. 두 번째 노트북은 같은 실습을 함수와 `main()` 구조로 다시 정리해, 노트북 코드를 스크립트로 옮기는 방법을 보여 줍니다.

⟪box:쉽게 이해하기⟫

분류 CNN이 '무엇인가?'만 답했다면, 위치 추정 CNN은 '무엇이 어디에 있는가?'에 함께 답합니다. 같은 특징 추출기 뒤에 답안지를 두 장(클래스, 상자 좌표) 붙이고 두 채점 결과를 더해 함께 고치는 구조입니다.

⟪/box⟫

⟪box:꼭 기억할 점⟫

- 상자 좌표는 YOLO와 같은 `[cx, cy, w, h]` 형식을 0~1로 정규화해 씁니다.
- 분류 손실과 좌표 손실의 크기가 다르므로 가중치(`BOX_WEIGHT`)로 균형을 맞춥니다.
- 분류는 정확도로, 위치는 IoU로 따로 평가합니다.

⟪/box⟫

### 개요

기존 CNN(Classification, 분류)은 **이미지가 무엇인지** 예측한다.

이번 단계에서는 CNN에 Bounding Box(바운딩 박스, 객체 위치) 예측을 추가하여 다음 두 가지를 동시에 학습한다.

```text
① What?  → Class
② Where? → Bounding Box
```

전체 학습 흐름:

```text
CNN Classification
        ↓
Single Object Localization
        ↓
Object Detection
        ↓
YOLO
```

이번 노트북은 학습 흐름이 숨겨지지 않도록 **데이터 준비 → 모델 → Loss → 학습 → 검증 → 예측**을 위에서 아래로 직접 실행한다.

```python
# 04. Single Object Localization용 Dataset 정의

class LocalizedMNIST(Dataset):

    def __init__(
        self,
        base_dataset,
        canvas_size=64,
        random_position=True
    ):
        self.base_dataset = base_dataset
        self.canvas_size = canvas_size
        self.random_position = random_position
        self.to_tensor = transforms.ToTensor()

    def __len__(self):
        return len(self.base_dataset)

    def __getitem__(self, idx):

        image, label = self.base_dataset[idx]

        # PIL Image → Tensor
        digit = self.to_tensor(image)

        # 실제 숫자가 존재하는 픽셀 영역 찾기
        mask = digit[0] > 0.05
        ys, xs = torch.where(mask)

        y1 = ys.min().item()
        y2 = ys.max().item() + 1
        x1 = xs.min().item()
        x2 = xs.max().item() + 1

        # 숫자 주변의 빈 공간 제거
        digit = digit[:, y1:y2, x1:x2]

        h = digit.shape[1]
        w = digit.shape[2]

        max_x = self.canvas_size - w
        max_y = self.canvas_size - h

        # Train: 숫자 위치를 계속 변경
        if self.random_position:
            x0 = random.randint(0, max_x)
            y0 = random.randint(0, max_y)

        # Validation: 같은 idx는 항상 같은 위치
        else:
            generator = torch.Generator()
            generator.manual_seed(idx + 1000)

            x0 = torch.randint(
                0, max_x + 1, (1,),
                generator=generator
            ).item()

            y0 = torch.randint(
                0, max_y + 1, (1,),
                generator=generator
            ).item()

        # 64 × 64 검은 배경
        canvas = torch.zeros(
            1,
            self.canvas_size,
            self.canvas_size
        )

        # 숫자를 임의 위치에 삽입
        canvas[:, y0:y0 + h, x0:x0 + w] = digit

        # Bounding Box 중심 좌표와 크기 정규화
        cx = (x0 + w / 2) / self.canvas_size
        cy = (y0 + h / 2) / self.canvas_size
        bw = w / self.canvas_size
        bh = h / self.canvas_size

        bbox = torch.tensor(
            [cx, cy, bw, bh],
            dtype=torch.float32
        )

        return canvas, label, bbox
```

#### 코드 풀이 — Dataset에서 무엇이 달라졌는가

기존 CNN Dataset:

```text
Image + Label
```

이번 Localization Dataset:

```text
Image + Label + Bounding Box
```

핵심은 마지막 반환값이다.

```python
return canvas, label, bbox
```

`bbox`는 다음 순서로 저장한다.

```text
[cx, cy, w, h]

cx → 객체 중심의 x 위치
cy → 객체 중심의 y 위치
w  → 객체의 폭
h  → 객체의 높이
```

모든 값은 `0 ~ 1` 범위로 정규화한다. 이 형식은 이후 YOLO의 Bounding Box 개념과 직접 연결된다.

```python
# 08. Bounding Box 표시 함수

def draw_box(
    ax,
    box,
    canvas_size,
    label,
    edgecolor,
    linestyle="-"
):

    cx, cy, w, h = box.tolist()

    # 0 ~ 1 정규화 좌표 → Pixel 좌표
    cx *= canvas_size
    cy *= canvas_size
    w *= canvas_size
    h *= canvas_size

    # 중심 좌표 → 왼쪽 위 좌표
    x1 = cx - w / 2
    y1 = cy - h / 2

    rectangle = Rectangle(
        (x1, y1),
        w,
        h,
        fill=False,
        edgecolor=edgecolor,
        linewidth=2,
        linestyle=linestyle
    )

    ax.add_patch(rectangle)

    ax.text(
        x1,
        max(y1 - 1.5, 1),
        label,
        color=edgecolor,
        fontsize=9,
        bbox={
            "facecolor": "black",
            "alpha": 0.5,
            "pad": 1
        }
    )
```

```python
# 10. CNN + Class Head + Box Head 모델 정의

class LocalizationCNN(nn.Module):

    def __init__(self):
        super().__init__()

        # CNN Feature Extraction
        self.features = nn.Sequential(

            nn.Conv2d(
                1, 16,
                kernel_size=3,
                padding=1
            ),
            nn.ReLU(),
            nn.MaxPool2d(
                kernel_size=2,
                stride=2
            ),

            nn.Conv2d(
                16, 32,
                kernel_size=3,
                padding=1
            ),
            nn.ReLU(),
            nn.MaxPool2d(
                kernel_size=2,
                stride=2
            ),

            nn.Conv2d(
                32, 64,
                kernel_size=3,
                padding=1
            ),
            nn.ReLU(),
            nn.MaxPool2d(
                kernel_size=2,
                stride=2
            )
        )

        # 공통 Feature
        self.shared = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 8 * 8, 128),
            nn.ReLU()
        )

        # 무엇인가? → 숫자 0 ~ 9
        self.class_head = nn.Linear(
            128,
            10
        )

        # 어디에 있는가? → cx, cy, w, h
        self.box_head = nn.Sequential(
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 4),
            nn.Sigmoid()
        )

    def forward(self, x):

        x = self.features(x)
        feature = self.shared(x)

        class_logits = self.class_head(
            feature
        )

        pred_boxes = self.box_head(
            feature
        )

        return class_logits, pred_boxes
```

#### 코드 풀이 — 기존 CNN에서 무엇이 추가되었는가

기존 CNN:

```text
Image
 ↓
CNN
 ↓
Class
```

이번 모델:

```text
                CNN
                 ↓
          Shared Feature
                 │
        ┌────────┴────────┐
        ↓                 ↓
   Class Head          Box Head
        ↓                 ↓
     숫자 0~9        cx, cy, w, h
```

핵심은 **CNN으로 추출한 공통 Feature를 두 개의 출력 Head가 함께 사용한다는 것**이다.

- `class_head` → 무엇인가?
- `box_head` → 어디에 있는가?

`box_head` 마지막의 `Sigmoid()`는 예측 좌표를 `0 ~ 1` 범위로 제한한다.

### 11. CNN Feature Map 크기 변화

```text
입력       → [N, 1, 64, 64]
Conv/Pool  → [N, 16, 32, 32]
Conv/Pool  → [N, 32, 16, 16]
Conv/Pool  → [N, 64, 8, 8]
```

마지막 Feature Map을 Flatten하면:

```text
64 × 8 × 8
→ 4096개 Feature
```

가 되고, 이를 `128`개의 공통 Feature로 줄인 뒤 Class Head와 Box Head로 전달한다.

```python
# 14. Bounding Box 좌표 형식 변환
# [cx, cy, w, h] → [x1, y1, x2, y2]

def xywh_to_xyxy(boxes):

    cx = boxes[:, 0]
    cy = boxes[:, 1]
    w = boxes[:, 2]
    h = boxes[:, 3]

    x1 = cx - w / 2
    y1 = cy - h / 2
    x2 = cx + w / 2
    y2 = cy + h / 2

    return torch.stack(
        [x1, y1, x2, y2],
        dim=1
    )
```

#### 코드 풀이

학습에서는 중심 좌표 형식인 `[cx, cy, w, h]`를 사용한다.

IoU 계산에서는 다음 형식이 편하다.

```text
[x1, y1, x2, y2]

x1, y1 → 왼쪽 위
x2, y2 → 오른쪽 아래
```

코드 박스: ch07_1_cnn_to_yolo_single_object_localization.ipynb · 셀 14 · 미검증

```python
# 15. IoU 계산 함수

def calculate_iou(
    pred_boxes,
    target_boxes
):

    pred = xywh_to_xyxy(
        pred_boxes
    )

    target = xywh_to_xyxy(
        target_boxes
    )

    inter_x1 = torch.maximum(
        pred[:, 0], target[:, 0]
    )
    inter_y1 = torch.maximum(
        pred[:, 1], target[:, 1]
    )
    inter_x2 = torch.minimum(
        pred[:, 2], target[:, 2]
    )
    inter_y2 = torch.minimum(
        pred[:, 3], target[:, 3]
    )

    inter_w = (
        inter_x2 - inter_x1
    ).clamp(min=0)

    inter_h = (
        inter_y2 - inter_y1
    ).clamp(min=0)

    intersection = inter_w * inter_h

    pred_area = (
        (pred[:, 2] - pred[:, 0]).clamp(min=0)
        *
        (pred[:, 3] - pred[:, 1]).clamp(min=0)
    )

    target_area = (
        (target[:, 2] - target[:, 0]).clamp(min=0)
        *
        (target[:, 3] - target[:, 1]).clamp(min=0)
    )

    union = (
        pred_area
        + target_area
        - intersection
    )

    iou = intersection / (
        union + 1e-6
    )

    return iou
```

#### 코드 풀이 — IoU

IoU(Intersection over Union, 두 박스의 겹침 비율)는 예측 Box가 정답 Box와 얼마나 잘 겹치는지 평가한다.

```text
          겹친 면적
IoU = ───────────────
       두 Box의 합집합
```

```text
IoU → 1 : 거의 정확하게 겹침
IoU → 0 : 거의 겹치지 않음
```

기존 CNN에서는 Accuracy를 주로 확인했지만, Localization에서는 **Accuracy + IoU**를 함께 본다.

```python
# 16. 학습

EPOCHS = 5

for epoch in range(EPOCHS):

    model.train()

    train_loss_sum = 0.0
    train_class_loss_sum = 0.0
    train_box_loss_sum = 0.0

    train_correct = 0
    train_total = 0

    for images, labels, boxes in train_loader:

        images = images.to(device)
        labels = labels.to(device)
        boxes = boxes.to(device)

        # 이전 Gradient 초기화
        optimizer.zero_grad()

        # Forward
        class_logits, pred_boxes = model(
            images
        )

        # 무엇인가? → Class Loss
        class_loss = class_loss_function(
            class_logits,
            labels
        )

        # 어디인가? → Box Loss
        box_loss = box_loss_function(
            pred_boxes,
            boxes
        )

        # 두 Loss를 하나로 결합
        loss = (
            class_loss
            + BOX_WEIGHT * box_loss
        )

        # Backpropagation
        loss.backward()

        # Weight Update
        optimizer.step()

        batch_size = images.size(0)

        train_loss_sum += (
            loss.item() * batch_size
        )

        train_class_loss_sum += (
            class_loss.item() * batch_size
        )

        train_box_loss_sum += (
            box_loss.item() * batch_size
        )

        predictions = class_logits.argmax(
            dim=1
        )

        train_correct += (
            predictions == labels
        ).sum().item()

        train_total += batch_size

    train_loss = train_loss_sum / train_total
    train_class_loss = train_class_loss_sum / train_total
    train_box_loss = train_box_loss_sum / train_total
    train_accuracy = train_correct / train_total

    print(
        f"Epoch {epoch + 1}/{EPOCHS} | "
        f"Total Loss: {train_loss:.4f} | "
        f"Class Loss: {train_class_loss:.4f} | "
        f"Box Loss: {train_box_loss:.4f} | "
        f"Accuracy: {train_accuracy:.4f}"
    )
```

```python
# 04. Single Object Localization용 Dataset

class LocalizedMNIST(Dataset):

    def __init__(
        self,
        base_dataset,
        canvas_size=64,
        random_position=True
    ):
        self.base_dataset = base_dataset
        self.canvas_size = canvas_size
        self.random_position = random_position
        self.to_tensor = transforms.ToTensor()

    def __len__(self):
        return len(self.base_dataset)

    def __getitem__(self, idx):
        image, label = self.base_dataset[idx]
        digit = self.to_tensor(image)

        # 실제 숫자가 있는 픽셀 영역 찾기
        mask = digit[0] > 0.05
        ys, xs = torch.where(mask)

        y1 = ys.min().item()
        y2 = ys.max().item() + 1
        x1 = xs.min().item()
        x2 = xs.max().item() + 1

        # 숫자 주변 빈 공간 제거
        digit = digit[:, y1:y2, x1:x2]
        h = digit.shape[1]
        w = digit.shape[2]

        max_x = self.canvas_size - w
        max_y = self.canvas_size - h

        if self.random_position:
            x0 = random.randint(0, max_x)
            y0 = random.randint(0, max_y)
        else:
            # Validation은 같은 idx에서 항상 같은 위치
            generator = torch.Generator()
            generator.manual_seed(idx + 1000)

            x0 = torch.randint(
                0, max_x + 1, (1,), generator=generator
            ).item()

            y0 = torch.randint(
                0, max_y + 1, (1,), generator=generator
            ).item()

        # 64×64 캔버스 생성 후 숫자 삽입
        canvas = torch.zeros(
            1, self.canvas_size, self.canvas_size
        )

        canvas[:, y0:y0+h, x0:x0+w] = digit

        # YOLO와 연결되는 중심좌표 기반 Bounding Box
        cx = (x0 + w / 2) / self.canvas_size
        cy = (y0 + h / 2) / self.canvas_size
        bw = w / self.canvas_size
        bh = h / self.canvas_size

        bbox = torch.tensor(
            [cx, cy, bw, bh],
            dtype=torch.float32
        )

        return canvas, label, bbox
```

⟪box:코드 풀이⟫

숫자 한 개를 64×64 검은 캔버스의 임의 위치에 놓고, ⟪b⟫숫자 클래스와 위치(Box)⟪/b⟫를 함께 돌려주는 Dataset입니다.
- 숫자가 있는 픽셀 영역만 잘라 빈 여백을 없앤 뒤 캔버스에 붙입니다.
- 학습용은 매번 다른 위치에, 검증용은 `idx`로 시드를 정해 항상 같은 위치에 놓아 결과를 비교할 수 있게 합니다.
- Box는 YOLO와 같은 `[cx, cy, w, h]`(중심 좌표와 너비·높이)를 0~1로 정규화해 저장합니다.

⟪/box⟫

```python
# 07. Localization CNN

class LocalizationCNN(nn.Module):

    def __init__(self):
        super().__init__()

        self.features = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),

            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),

            nn.Conv2d(32, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2)
        )

        self.shared = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 8 * 8, 128),
            nn.ReLU()
        )

        # 무엇인가?
        self.class_head = nn.Linear(128, 10)

        # 어디에 있는가?
        self.box_head = nn.Sequential(
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 4),
            nn.Sigmoid()
        )

    def forward(self, x):
        x = self.features(x)
        feature = self.shared(x)

        class_logits = self.class_head(feature)
        pred_boxes = self.box_head(feature)

        return class_logits, pred_boxes


def inspect_model(model, data_loader, device):
    images, _, _ = next(iter(data_loader))
    images = images.to(device)

    model.eval()

    with torch.no_grad():
        class_logits, pred_boxes = model(images)

    print("class_logits:", class_logits.shape)
    print("pred_boxes  :", pred_boxes.shape)
```

⟪box:코드 풀이⟫

하나의 CNN 특징 추출기에 ⟪b⟫두 개의 출력(head)⟪/b⟫을 붙인 모델입니다.
- `class_head` — 무엇인가? 숫자 0~9의 점수 10개.
- `box_head` — 어디에 있는가? `[cx, cy, w, h]` 4개 값. 마지막 `Sigmoid`로 0~1 범위를 맞춥니다.
- 64×64 입력이 풀링 세 번으로 8×8이 되어 `64 × 8 × 8` 특징이 공통 층으로 들어갑니다.

### 5. Bounding Box 변환과 IoU

모델 출력 `[cx, cy, w, h]`를 IoU 계산용 `[x1, y1, x2, y2]`로 변환한다.

코드 박스: ch07_2_cnn_to_yolo_single_object_localization_main.ipynb · 셀 8 · 미검증

```python
# 08. Bounding Box 변환 + IoU

def xywh_to_xyxy(boxes):
    cx = boxes[:, 0]
    cy = boxes[:, 1]
    w = boxes[:, 2]
    h = boxes[:, 3]

    x1 = cx - w / 2
    y1 = cy - h / 2
    x2 = cx + w / 2
    y2 = cy + h / 2

    return torch.stack(
        [x1, y1, x2, y2], dim=1
    )


def calculate_iou(pred_boxes, target_boxes):
    pred = xywh_to_xyxy(pred_boxes)
    target = xywh_to_xyxy(target_boxes)

    inter_x1 = torch.maximum(pred[:, 0], target[:, 0])
    inter_y1 = torch.maximum(pred[:, 1], target[:, 1])
    inter_x2 = torch.minimum(pred[:, 2], target[:, 2])
    inter_y2 = torch.minimum(pred[:, 3], target[:, 3])

    inter_w = (inter_x2 - inter_x1).clamp(min=0)
    inter_h = (inter_y2 - inter_y1).clamp(min=0)
    intersection = inter_w * inter_h

    pred_area = (
        (pred[:, 2] - pred[:, 0]).clamp(min=0)
        * (pred[:, 3] - pred[:, 1]).clamp(min=0)
    )

    target_area = (
        (target[:, 2] - target[:, 0]).clamp(min=0)
        * (target[:, 3] - target[:, 1]).clamp(min=0)
    )

    union = pred_area + target_area - intersection

    return intersection / (union + 1e-6)
```

⟪box:코드 풀이⟫

Box 형식 변환과 IoU 계산 함수입니다.
- `[cx, cy, w, h]` → `[x1, y1, x2, y2]`(왼쪽 위·오른쪽 아래 모서리)로 바꿔야 겹치는 영역을 계산하기 쉽습니다.
- IoU = 겹친 넓이 ÷ 합친 넓이. 1이면 완전히 일치, 0이면 전혀 겹치지 않습니다.
- `+ 1e-6` — 0으로 나누는 것을 막습니다.

⟪/box⟫

### 7. 학습 함수

`train_one_epoch()`는 한 Epoch만 담당하고, `train_model()`은 Epoch 반복만 관리한다.

코드 박스: ch07_2_cnn_to_yolo_single_object_localization_main.ipynb · 셀 10 · 미검증

```python
# 10. 한 Epoch 학습 함수

def train_one_epoch(
    model,
    data_loader,
    class_loss_function,
    box_loss_function,
    optimizer,
    device,
    box_weight=5.0
):
    model.train()

    loss_sum = 0.0
    class_loss_sum = 0.0
    box_loss_sum = 0.0
    correct = 0
    total = 0

    for images, labels, boxes in data_loader:
        images = images.to(device)
        labels = labels.to(device)
        boxes = boxes.to(device)

        optimizer.zero_grad()

        class_logits, pred_boxes = model(images)

        class_loss = class_loss_function(
            class_logits, labels
        )

        box_loss = box_loss_function(
            pred_boxes, boxes
        )

        loss = class_loss + box_weight * box_loss

        loss.backward()
        optimizer.step()

        batch_size = images.size(0)

        loss_sum += loss.item() * batch_size
        class_loss_sum += class_loss.item() * batch_size
        box_loss_sum += box_loss.item() * batch_size

        predictions = class_logits.argmax(dim=1)
        correct += (predictions == labels).sum().item()
        total += batch_size

    return {
        "loss": loss_sum / total,
        "class_loss": class_loss_sum / total,
        "box_loss": box_loss_sum / total,
        "accuracy": correct / total
    }


def train_model(
    model,
    train_loader,
    class_loss_function,
    box_loss_function,
    optimizer,
    device,
    epochs=5,
    box_weight=5.0
):
    history = []

    for epoch in range(epochs):
        metrics = train_one_epoch(
            model,
            train_loader,
            class_loss_function,
            box_loss_function,
            optimizer,
            device,
            box_weight
        )

        history.append(metrics)

        print(
            f"Epoch {epoch + 1}/{epochs} | "
            f"Total Loss: {metrics['loss']:.4f} | "
            f"Class Loss: {metrics['class_loss']:.4f} | "
            f"Box Loss: {metrics['box_loss']:.4f} | "
            f"Accuracy: {metrics['accuracy']:.4f}"
        )

    return history
```

⟪box:코드 풀이⟫

한 에폭 학습 함수와 여러 에폭을 반복하는 함수입니다.
- 전체 손실 = 클래스 손실 + `box_weight` × Box 손실. 두 손실의 크기가 달라 Box 쪽에 가중치 5를 곱해 균형을 맞춥니다.
- 손실을 하나로 합쳐 `backward()`를 한 번만 호출하면 두 head와 공통 특징 추출기가 함께 학습됩니다.

```python
        optimizer
    ) = create_training_components(
        model,
        learning_rate=LEARNING_RATE
    )

    # -----------------------------
    # 5. 학습
    # -----------------------------
    print("\n[Training]")

    history = train_model(
        model,
        train_loader,
        class_loss_function,
        box_loss_function,
        optimizer,
        device,
        epochs=EPOCHS,
        box_weight=BOX_WEIGHT
    )

    # -----------------------------
    # 6. Validation
    # -----------------------------
    print("\n[Validation]")

    val_metrics = validate_model(
        model, val_loader, device
    )

    print(
        "Validation Accuracy:",
        f"{val_metrics['accuracy']:.4f}"
    )

    print(
        "Mean IoU:",
        f"{val_metrics['mean_iou']:.4f}"
    )

    # -----------------------------
    # 7. 예측 Box 확인
    # -----------------------------
    visualize_predictions(
        model,
        val_loader,
        device,
        canvas_size=CANVAS_SIZE,
        num_samples=9
    )

    return model, history, val_metrics
```

⟪box:코드 풀이⟫

전체 과정을 순서대로 실행하는 `main()` 함수입니다. 설정 → 데이터 → 정답 Box 확인 → 모델 → 손실·Optimizer → 학습 → 검증 → 시각화 순서이며, 설정값을 맨 위에 모아 두어 실험을 바꾸기 쉽습니다.
