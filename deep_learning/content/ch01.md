## 배경 개념

Deep Learning(딥러닝)은 입력과 출력 사이에 Hidden Layer(은닉층)를 여러 층 쌓고, 층 사이에 ReLU(렐루) 같은 비선형 활성화 함수를 넣어 직선 하나로는 표현할 수 없는 관계를 학습합니다.

이 장은 머신러닝 과정 3장의 심장질환 로지스틱 분류를 그대로 두고 **모델만** `Linear → ReLU → Linear → ReLU → Linear` MLP(다층 퍼셉트론)로 바꿉니다. 출력은 여전히 Logit 1개이고 Loss도 `BCEWithLogitsLoss()`이므로, 모델 구조와 학습 설정이 서로 독립적이라는 점을 확인할 수 있습니다. 설정 선택 원리는 [머신러닝 과정 4장](../../machine_learning/dist/ch04_training_setup_guide_v01.html)을 참고합니다.

### 7. 연속형 특성 표준화

연속형 특성은 숫자의 범위가 서로 다릅니다.


```text
x_{\mathrm{scaled}}
=
\frac{x-\mu_{\mathrm{train}}}
{\sigma_{\mathrm{train}}}
```


- 평균과 표준편차는 훈련 데이터에서만 계산
- 테스트 데이터에는 훈련 데이터의 평균과 표준편차 적용
- 이진형과 원핫 인코딩된 열은 0과 1을 그대로 유지

테스트 데이터의 통계량을 미리 사용하면 Data Leakage(데이터 리키지, 데이터 누출)가 발생합니다.

파일명: `ch01_1_heart_disease_dnn_classification.ipynb` · 코드 셀 6 · Python · 원본 실행 기록 포함

### 9. 딥러닝 이진분류 모델

> **(변경)** 기존 `nn.Linear(input_size, 1)` 단일 계층에 Hidden Layer(은닉층)와 ReLU(렐루)를 추가합니다.


```text
\text{Input} \rightarrow \text{Linear} \rightarrow \text{ReLU} \rightarrow \text{Linear} \rightarrow \text{ReLU} \rightarrow \text{Linear} \rightarrow \text{Logit}
```


- **(변경)** 은닉층을 추가하여 여러 특성의 비선형 조합을 학습합니다.
- **(변경)** 은닉층 뒤에 `ReLU()` 활성화 함수를 사용합니다.
- 출력층은 이진분류이므로 Logit(로짓) 1개를 출력합니다.
- 손실함수 `BCEWithLogitsLoss()`는 그대로 사용합니다.
- 예측할 때만 `torch.sigmoid()`를 사용합니다.

파일명: `ch01_1_heart_disease_dnn_classification.ipynb` · 코드 셀 8 · Python · 원본 실행 기록 포함

```python
# ============================================================
# (변경 전) Logistic Regression(로지스틱 회귀) 모델
# 기존 코드는 삭제하지 않고 비교를 위해 주석으로 유지합니다.
# ============================================================
# torch.manual_seed(42)
#
# model = nn.Linear(
#     input_size,
#     1,
# )
#
# loss_function = nn.BCEWithLogitsLoss()
#
# optimizer = torch.optim.SGD(
#     model.parameters(),

# )
#
# print(model)
# print("가중치 shape:", model.weight.shape)
# print("편향 shape:", model.bias.shape)
# ============================================================
# (변경 후) Deep Learning(딥러닝) MLP(다층 퍼셉트론) 모델
# 변경 핵심: Hidden Layer(은닉층) + ReLU(렐루) 추가
# ============================================================
torch.manual_seed(42)

loss_function = nn.BCEWithLogitsLoss()

# Optimizer(옵티마이저)도 기존 구조를 그대로 사용
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.05,
)

print(model)

# (변경) MLP에서는 각 Linear 계층의 shape를 확인
```

### 10. 모델 학습

학습 순서는 와 같습니다.


```text
\text{로짓 계산}
\rightarrow
\text{손실 계산}
\rightarrow
\text{역전파}
\rightarrow
\text{가중치 갱신}
```

파일명: `ch01_1_heart_disease_dnn_classification.ipynb` · 코드 셀 9 · Python · 원본 실행 기록 포함

```python
epochs = 2000
loss_history = []

model.train()

for epoch in range(epochs):
    # 1. 로짓 계산
    logits = model(
        X_train_tensor
    )

    # 2. BCE 손실 계산
    loss = loss_function(
        logits,
        y_train_tensor,
    )

    # 3. 이전 기울기 초기화
    optimizer.zero_grad()

    # 4. 역전파
    loss.backward()

    # 5. 가중치 갱신
    optimizer.step()

    loss_history.append(
        loss.item()
    )

print("처음 Loss:", loss_history[0])
print("마지막 Loss:", loss_history[-1])
```

### 12. 혼동행렬과 평가지표

| 구분 | 의미 |
|---|---|
| TP(티피) | 실제 1을 1로 예측 |
| TN(티엔) | 실제 0을 0으로 예측 |
| FP(에프피) | 실제 0을 1로 잘못 예측 |
| FN(에프엔) | 실제 1을 0으로 잘못 예측 |


```text
\mathrm{Accuracy}
=
\frac{TP+TN}
{TP+TN+FP+FN}
```



```text
\mathrm{Precision}
=
\frac{TP}
{TP+FP}
```



```text
\mathrm{Recall}
=
\frac{TP}
{TP+FN}
```



```text
F1
=
2
\times
\frac{
\mathrm{Precision}
\times
\mathrm{Recall}
}{
\mathrm{Precision}
+
\mathrm{Recall}
}
```


의료 선별 문제에서는 실제 환자를 놓치는 FN을 줄이는 것이 중요하므로 Recall도 함께 확인합니다.

파일명: `ch01_1_heart_disease_dnn_classification.ipynb` · 코드 셀 12 · Python · 원본 실행 기록 포함

```python
def calculate_metrics(
    targets,
    predictions,
):
    targets = targets.reshape(-1)
    predictions = predictions.reshape(-1)

    tp = int(
        ((targets == 1) & (predictions == 1)).sum()
    )

    tn = int(
        ((targets == 0) & (predictions == 0)).sum()
    )

    fp = int(
        ((targets == 0) & (predictions == 1)).sum()
    )

    fn = int(
        ((targets == 1) & (predictions == 0)).sum()
    )

    accuracy = (
        tp + tn
    ) / len(targets)

    precision = tp / max(
        tp + fp,
        1,
    )

    recall = tp / max(
        tp + fn,
        1,
    )

    f1 = (
        2 * precision * recall
        / max(precision + recall, 1e-12)
    )

    return {
        "TP": tp,
        "TN": tn,
        "FP": fp,
        "FN": fn,
        "Accuracy": accuracy,
        "Precision": precision,
        "Recall": recall,
        "F1": f1,
    }


train_metrics = calculate_metrics(
    y_train_tensor,
    train_predictions,
)

test_metrics = calculate_metrics(
    y_test_tensor,
    test_predictions,
)

print("[훈련 데이터]")

for name, value in train_metrics.items():
    print(f"{name:9s}: {value:.4f}")

print()
print("[테스트 데이터]")

for name, value in test_metrics.items():
    print(f"{name:9s}: {value:.4f}")
```

### 14. 임계값에 따른 결과 비교

임계값을 낮추면 클래스 1로 판단하는 경우가 늘어납니다.

- Recall이 높아질 수 있음
- FP도 증가할 수 있음

임계값을 높이면 클래스 1로 판단하는 경우가 줄어듭니다.

- FP가 줄어들 수 있음
- FN이 증가할 수 있음

임계값은 정확도만 보고 결정하지 않고 문제의 목적과 오판 비용을 함께 고려합니다.
